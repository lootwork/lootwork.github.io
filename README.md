# LOOTWORK

Вакансии в геймдеве напрямую от студий: **lootwork.github.io**

Сайт каждый день читает карьерные страницы игровых студий и показывает открытые
вакансии одним списком. Без агентств, без перепостов, без одной и той же вакансии
в пяти местах. Отклик уходит на сайт студии — мы не работодатель и резюме не принимаем.

## Что внутри

- **43 студии**, среди них Riot Games, Epic Games, Wargaming, Larian, Supercell,
  Scopely, Rockstar Games, 2K, Voodoo, 11 bit studios
- Источники: **Greenhouse, Lever, Recruitee, Ashby, Workable, SmartRecruiters**
- Фильтры: роль, специализация, грейд, стек, формат работы, зарплата, студия, локация
- Поиск с подсказками, избранное, скрытые вакансии, жалобы на неактуальные
- Русский и английский, светлая и тёмная тема
- Отдельная страница у каждой вакансии, студии и роли — с разметкой JobPosting

## Как это устроено

Никакого сервера и базы данных. Всё статическое, живёт на GitHub Pages.

```
collect.py     сборщик: ходит по системам найма, чистит данные, раскладывает страницы
companies.json список студий: имя, система найма, адрес доски
jobs.js        собранные вакансии
status.json    итоги последнего сбора
index.html     весь сайт одним файлом
config.js      настройки: формы обратной связи, счётчик
job/ company/ role/ spec/   статические страницы для поисковиков
```

Раз в сутки просыпается GitHub Actions, запускает `collect.py` и коммитит результат.

### Что делает сборщик

1. Забирает вакансии из систем найма, с повторами при обрывах связи
2. Определяет роль, специализацию, грейд, стек, формат удалёнки, зарплату
3. Нормализует локации: `London, UK` и `London, United Kingdom` — одно и то же
4. Проверяет каждую ссылку и выбрасывает закрытые вакансии
5. Раскладывает страницы и обновляет карту сайта

## Запуск у себя

```bash
pip install requests
python collect.py                # обычный сбор
python collect.py --probe        # проверить, отвечают ли доски студий
python collect.py --detect URL   # найти систему найма по странице карьеры
```

## Как добавить студию

Открой карьерную страницу студии и запусти:

```bash
python collect.py --detect https://studio.com/careers
```

Скрипт найдёт систему найма и напечатает готовую строку для `companies.json`.
Или просто напиши через форму на сайте.

## Приватность

Избранное, скрытые вакансии и язык хранятся только в браузере. Резюме и отклики
мы не собираем. Подробности: **lootwork.github.io/privacy**
