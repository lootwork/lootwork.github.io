# Геймдев-вакансии — первая версия

## Что уже есть

- `index.html` — витрина: поиск, фильтры по роли, грейду, удалёнке и наличию вилки,
  кнопка «неактуальна» на каждой карточке. Работает целиком в браузере.
- `jobs.js` — данные. Сейчас в нём **демонстрационные вымышленные вакансии**,
  чтобы можно было оценить интерфейс. Витрина честно предупреждает об этом плашкой.
- `collect.py` — сборщик. Ходит по доскам студий, отбирает геймдев-роли,
  размечает роль и грейд, проверяет живость ссылок, перезаписывает `jobs.js`.
- `companies.json` — список студий. Сейчас в нём две заглушки, его надо наполнить.
- `.github/workflows/collect.yml` — еженедельный автозапуск.

Посмотреть витрину прямо сейчас: скачай папку и открой `index.html` двойным кликом.

---

## Почему так, а не иначе

**Собираем не с сайтов студий, а с систем найма.** Почти все студии не пишут карьерную
страницу руками, а подключают готовую: Greenhouse, Lever, Huntflow, Поток. У этих систем
есть открытый список вакансий в машинном виде — не надо парсить вёрстку, которая
ломается от любого редизайна. Один парсер обслуживает десятки компаний.

**Раз в неделю — этого достаточно.** Вакансия живёт около трёх недель. Недельный цикл
почти ничего не теряет, зато не требует сервера: скрипт просыпается по расписанию
на GitHub, обновляет файл и засыпает. Стоит ноль.

**Проверка живости важнее, чем кажется.** Главная причина, по которой такие сервисы
умирают, — мёртвые ссылки. Поэтому перед каждой публикацией сборщик стучится по каждой
вакансии и выкидывает те, что отвечают ошибкой или показывают «вакансия закрыта».
Это ловит большую часть мертвечины без чьего-либо участия.

**Жалобы — второй слой, а не первый.** Кнопка «неактуальна» нужна для того, чего
автоматика не видит: «уже нашли человека, но объявление висит», «вилка на деле вдвое
ниже», «это агентство, а не студия». Одной жалобы мало — иначе конкуренты и обиженные
кандидаты будут топить вакансии. Порог: три независимые жалобы, дальше проверяешь руками.

## Что делать дальше — по шагам

### Шаг 1. Наполнить `companies.json`

Это главная работа, и её пока не автоматизировать. Формат такой:

```json
[
  { "name": "Название студии", "ats": "greenhouse", "token": "слаг-студии", "enabled": true }
]
```

`token` — это кусок из адреса карьерной страницы студии. Примеры того, как он выглядит:

- `boards.greenhouse.io/НАЗВАНИЕ` → `"ats": "greenhouse"`, `"token": "НАЗВАНИЕ"`
- `jobs.lever.co/НАЗВАНИЕ` → `"ats": "lever"`, `"token": "НАЗВАНИЕ"`

Как искать: открываешь карьерную страницу студии и смотришь, куда ведёт кнопка
«Вакансии». Если адрес содержит `greenhouse` или `lever` — студия нам подходит.
Начни с двадцати студий, которые знаешь лично, — этого хватит для первой версии.

### Шаг 2. Проверить список

Установи Python с python.org, потом в командной строке в папке проекта:

```
pip install requests
python collect.py --probe
```

Скрипт по каждой студии скажет `OK` и число вакансий либо `нет`. Догадки о слагах
почти наверняка подтвердятся не все — это нормально, просто убери неподтверждённые
или поправь их.

### Шаг 3. Первый настоящий сбор

```
python collect.py
```

Перезапишет `jobs.js` настоящими вакансиями и снимет демо-плашку с витрины.
Открой `index.html` и посмотри, что получилось.

### Шаг 4. Выложить в интернет

Создай репозиторий на GitHub, залей туда папку, включи GitHub Pages в настройках
репозитория (Settings → Pages → ветка main). Сайт станет доступен по ссылке,
а `collect.yml` начнёт обновлять его каждый понедельник сам.

## Чего пока нет

**Куда уходят жалобы.** Сейчас кнопка гасит карточку только у нажавшего. Чтобы жалобы
собирались, нужна форма — проще всего Google Forms, ссылку подставим в `REPORT_FORM`
внутри `jobs.js`. Это пять минут, но нужен твой аккаунт.

**Зарплатные вилки.** Greenhouse и Lever не отдают их в списке. Достать можно только
заходя в каждую вакансию отдельно — сделаем, если решишь, что вилка важна.

**Telegram-каналы.** Часть студий публикуется только там. Парсинг каналов требует
отдельных ключей доступа, поэтому это следующий этап, а не первый.

**Российские системы найма** (Huntflow, Поток, Талантикс). Добавлю парсеры, когда
станет понятно, сколько студий из твоего списка сидит именно на них.
