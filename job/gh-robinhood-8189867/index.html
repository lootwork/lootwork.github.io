The Developer Infrastructure org is the engine behind Robinhood's entire engineering organization — a collection of tightly integrated teams whose collective mission is to make every engineer at Robinhood faster, more reliable, and exponentially more productive. The org spans four major teams: DevX (Developer Experience), TestX (Test Infrastructure), Backend Platform, and Mobile Platform. DevX owns Robinhood's monorepo and Bazel-based build infrastructure — the critical layer between a developer writing code and that code being ready to ship — along with the company's full CI/CD pipeline and remote build execution cluster. TestX owns the infrastructure behind Robinhood's entire test experience: the integration test environments, and personal development environments that serve as miniature simulations of the full Robinhood system, giving engineers a safe, isolated space to test their code end-to-end before it ever touches production. Backend Platform and Mobile Platform own the core language runtimes, libraries, IDEs, and developer toolchains across Python, Go, TypeScript, Swift, and Android. Together, these teams share a single north star: leveraging AI and agentic systems to fundamentally transform Robinhood's software development lifecycle — making every engineer dramatically more productive and the entire org a force multiplier for the business.

As the Senior Staff Software Engineer, Developer Infrastructure, you are the technical driver of this entire org — the Uber Tech Lead unifying DevX, TestX, Backend Platform, and Mobile Platform under one cohesive technical vision. Your primary focus will be DevX, owning the technical direction of Robinhood's most critical build and developer infrastructure. But your influence stretches far wider: you will be a driving force in weaving AI and agentic development deeply into every layer of the software development lifecycle — from intelligent code review and automated build pipelines to agentic coding systems that multiply what each engineer can ship. This is a rare opportunity to shape not just how Robinhood builds software today, but what engineering velocity looks like for the entire industry!

This role is based in our New York City or Menlo Park office, with in-person attendance expected at least 3 days per week.

At Robinhood, we believe in the power of in-person work to accelerate progress, spark innovation, and strengthen community. Our office experience is intentional, energizing, and designed to fully support high-performing teams.

  • Lead and evolve Robinhood's Bazel-based monorepo build infrastructure — own the remote build execution cluster, drive language-agnostic build optimization across Python, Go, TypeScript, and more, and ensure fast, stable feedback loops for the entire engineering org
  • Scale CI/CD pipelines to support thousands of daily builds with speed, safety, and reliability — overseeing GitHub repository configurations, pre-merge checks, and test execution infrastructure across the company
  • Drive the vision for TestX — the test infrastructure and environments that power Robinhood's entire test experience, including integration test environments and personal development environments that simulate the full Robinhood system so engineers can test safely and confidently
  • Champion the integration of AI and agentic systems across the full software development lifecycle — driving initiatives that use intelligent automation and coding agents to multiply developer velocity, improve code quality, and accelerate the pace of innovation across the org
  • Set technical standards across Backend Platform and Mobile Platform — owning the vision for core language runtimes, libraries, IDE tooling, and developer environment security across Python, Go, TypeScript, Swift, and Android
  • Partner with engineering leadership and cross-functional stakeholders to define and execute a long-term developer infrastructure roadmap that embeds AI as a force multiplier at every layer of the SDLC
