Visual Concepts China (Shanghai) ищет Senior Full-Stack Server Engineer для неанонсированного проекта. Visual Concepts, дочерняя компания Take-Two Interactive Software, Inc. (TTWO), считается одной из ведущих игровых студий мира и особенно известна спортивными играми, включая NBA 2K — баскетбольную франшизу №1 по рейтингам и продажам.

Кого мы ищем

Нам нужен backend specialist, отвечающий за проектирование, разработку и поддержку надёжных, масштабируемых и безопасных server-side applications и API. Роль требует сильного практического опыта настройки server API и хорошего понимания database storage solutions.

Кто отлично подойдёт

  • Опыт: 8–10 лет professional software development, из них не менее 5 лет — high-scale backend server engineering.
  • Server API: экспертный опыт проектирования, создания, документирования и использования сложных REST/GraphQL API; нужен опыт API gateways и service-to-service communication.
  • Владение основными backend languages, например Python, Java, C++.
  • Databases: сильное понимание relational databases — PostgreSQL, MySQL, MS SQL Server — включая query optimization, indexing и schema design. Хорошее понимание in-memory databases и NoSQL для масштабирования по machine clusters.
  • Cloud: практический опыт deployment и управления приложениями минимум в одном major cloud — AWS, Azure или GCP.
  • Экспертное знание testing methodologies и requirements: unit, integration, BVT, stress и performance testing. Умение создавать testable framework для automation и white-box testing.
  • Bachelor degree или выше либо эквивалент в Computer Science, Computer Engineering или непосредственно смежной области.
  • Любовь к видеоиграм, не только нашим.

Будет плюсом

  • Опыт deployment крупномасштабных microservices и distributed systems.
  • Хорошее понимание networking, data storage и security.
  • Опыт Infrastructure as Code: Terraform, AWS CloudFormation, Google Cloud Deployment Manager или Azure Resource Manager.
  • Понимание сильно регулируемых или высоконагруженных сред — FinTech, e-commerce, telecommunications.
  • Опыт leadership технических проектов и mentoring junior engineers.

Точный уровень позиции и компенсация будут определены в соответствии с релевантным опытом и экспертизой кандидата.
