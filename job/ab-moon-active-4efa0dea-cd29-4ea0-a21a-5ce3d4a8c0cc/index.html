Moon Active — глобальный лидер mobile gaming, создающий entertainment experiences для миллионов игроков по всему миру. Наши игры работают в огромном масштабе, обрабатывая миллиарды событий ежедневно, а engineering teams решают сложные технические задачи, расширяющие границы mobile game development.

В роли Unity Developer вы будете работать над одним из самых сложных и успешных продуктов mobile gaming industry — крупномасштабной, высокооптимизированной Unity codebase, обслуживающей миллионы concurrent users по всему миру. Это не типичный mobile game project, а сложная постоянно развивающаяся система, требующая исключительного architectural thinking, глубокой expertise в performance optimization и способности сохранять качество в масштабе.

Обязанности

  • Вести features от system design и data handling до production deployment.
  • Проектировать architectures и реализовывать end-to-end client-side features, используя LLM от ежедневной разработки до system architecture.
  • Использовать data-driven methods для решения production issues и оптимизации performance на всех устройствах.
  • Управлять интеграцией native plugins и third-party services.

Требования

  • 2+ года профессионального software development.
  • Практический опыт Claude Code, Cursor или аналогов.
  • Опыт object-oriented programming, включая design patterns, algorithms и data structures.
  • Сильное знание OOP-языка (C# или эквивалент) и memory management.
  • Проактивность, самостоятельность и сильные communication skills.
  • Опыт Unity на mobile platforms, включая scripting APIs, profiling tools, UI и animations.
  • Украинский язык — родной.

Преимущества

  • AI engineering — опыт создания agentic и autonomous frameworks.
  • Опыт high-scale data-driven environment: Firebase, analytics, metrics и т. д.
