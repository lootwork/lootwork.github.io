Мы хотим, чтобы вы #JOINTHEREBELLION!

Уже 30 лет мы независимо разрабатываем и издаём невероятные видеоигры в нескольких студиях, основанных Jason и Chris Kingsley, но Rebellion — это не только игры. У нас есть собственная киностудия, мы создаём настольные игры, издаём книги, а через 2000AD — комиксы и graphic novels, включая Judge Dredd.

Мы ищем опытного или senior back-end Online Developer в tech team, который поможет создавать и поддерживать внутренние и внешние web API для команды нашего игрового движка.

Кандидат присоединится к растущей команде и будет использовать экспертизу JavaScript на всём software development lifecycle — от сбора требований и system design до implementation, testing, deployment и maintenance. Вы будете создавать как внутренние инструменты, так и public-facing API.

Это преимущественно back-end роль для разработчика с опытом создания производительных distributed backend API и эффективного использования third-party services. Вы должны уверенно общаться с другими командами при исправлении багов и проблем. Это отличная возможность строить важные для бизнеса системы в команде, которая продолжает расти и развиваться.

Работать можно из студии в Oxford или Warwick. Мы можем предоставить relocation package с помощью при переезде, временным жильём и полной поддержкой.

Ключевые результаты

  • Писать производительный и хорошо документированный код.
  • Успешно разрабатывать и разворачивать новые инструменты для поддержки игровых команд.
  • Оперативно реагировать на баги и проблемы и своевременно их устранять.

Обязанности

  • Проектировать, создавать и разворачивать web applications для поддержки команды собственного движка.
  • Поддерживать и улучшать существующие инструменты.
  • Разрабатывать интеграции с third-party API.
  • Поддерживать deployments приложений.
  • Эффективно сотрудничать и общаться с другими командами.
  • Участвовать в улучшении development practices растущей команды.

Требования

  • Подтверждённый опыт back-end development.
  • Опыт работы в игровой индустрии.
  • Сильный опыт с Node.js, JavaScript и TypeScript.
  • Знание front-end frameworks, например Vue и React.
  • Опыт с базами данных MySQL и NoSQL.
  • Знакомство с AWS или сопоставимыми cloud environments.
  • Опыт с software development tools и version control systems; Git обязателен, Perforce желателен.
  • Доказанная способность быстро осваивать новые технологии.
  • Желательно уверенно модифицировать и поддерживать приложения на других языках, например PHP.
  • Опыт написания serverless functions в AWS Lambda/Azure Functions будет плюсом.
