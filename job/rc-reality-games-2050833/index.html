We Are Looking for a Machine Learning Developer to Join Our Team!

This role will report to the Head of Analytics. This is a full-time, in-office position based in the iconic railway station building in Krakow.

Основные обязанности

  • Design, develop, and optimize machine learning models to enhance game features and player experience
  • Implement and maintain data pipelines for collecting, processing, and analyzing large-scale game data
  • Collaborate with data scientists, game designers, and engineers to integrate ML solutions into the game
  • Improve the performance and scalability of ML systems using cloud-based services
  • Monitor, test, and fine-tune machine learning models to ensure accuracy and efficiency
  • Research and apply the latest advancements in machine learning and artificial intelligence
  • Work with Big Data technologies to process and analyze complex datasets
  • Ensure the security and compliance of data used in machine learning applications
