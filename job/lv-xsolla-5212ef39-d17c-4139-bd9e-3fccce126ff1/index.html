О ВАС

Мы ищем Senior Frontend Software Engineer — инновационного, внимательного к деталям и ориентированного на командную работу специалиста — в Engineering team. Идеальный кандидат уверенно работает в быстром и очень динамичном окружении и хочет создавать высокопроизводительные масштабируемые UI для глобальной экосистемы video game commerce.

Необходима сильная экспертиза React и современной TypeScript-экосистемы. Важно глубоко понимать state management — Redux, Zustand — современные build tools и уметь проектировать чистые сопровождаемые frontend-системы. Поскольку мы работаем в глобальном масштабе, критичны performance optimization, responsive design и cross-browser compatibility. Мы ценим engineers, которые не просто пишут код, а отвечают за весь lifecycle: от проектирования интуитивного UI до устойчивых CI/CD pipelines и бесшовного cloud deployment.

Если вы любите разбираться в сложном поведении систем, менторить коллег и влиять на technical strategy, присоединяйтесь к Xsolla и помогайте создавать digital experience, который позволяет indie и AAA разработчикам финансировать, продвигать и монетизировать игры по всему миру.

О КОМПАНИИ

Xsolla — глобальная commerce компания с инструментами и сервисами для игровой индустрии. Подробнее: xsolla.com.

ОБЯЗАННОСТИ

  • Проектировать и реализовывать новые features и user interfaces.
  • Писать чистый, сопровождаемый и хорошо протестированный код.
  • Оптимизировать приложения по скорости и scalability.
  • Участвовать в code review и поддерживать стандарты качества кода.
  • Находить и устранять проблемы в разных браузерах и устройствах.
  • Создавать и поддерживать CI/CD pipelines frontend-приложений.
  • Тесно работать с глобальными cross-functional teams: developers, QA engineers, project managers.
  • Согласовывать technical strategies с business objectives вместе со стейкхолдерами.
  • Поддерживать эффективную коммуникацию между глобально распределёнными командами.
  • Контролировать весь development lifecycle и своевременную поставку качественных приложений.

КВАЛИФИКАЦИЯ И НАВЫКИ

  • 5+ лет frontend development с сильным фокусом на React.
  • Глубокие знания JavaScript/TypeScript, HTML и CSS.
  • Опыт state management: Redux, Zustand или Context API.
  • Хорошее понимание RESTful APIs и GraphQL.
  • Современные build tools Webpack, Vite и monorepo setups.
  • Отличное понимание responsive design, cross-browser compatibility и performance optimization.
  • Testing frameworks Jest, React Testing Library, Cypress.
  • Hands-on CI/CD: GitHub Actions, GitLab CI, Jenkins или CircleCI.
  • Знакомство с Docker и cloud deployment: GCP, AWS, Firebase.
  • Подтверждённая способность менторить и вести других engineers как senior специалист.
  • Отличные communication/collaboration и problem-solving skills, внимание к деталям.

ПРЕИМУЩЕСТВА

Программа включает unlimited Flexible Time Off и индивидуальную карьерную траекторию. Компания инвестирует в обучение и профессиональное развитие.

Обязанности могут со временем меняться. После финального интервью Xsolla может проводить background checks в рамках закона; персональные данные обрабатываются конфиденциально и защищаются применимым законодательством.
