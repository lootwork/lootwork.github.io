The QA Engineering Team 🧪

The Quality Assurance team, part of Engineering, makes sure that Shift can ship fast and safely. Our AI-driven software is deployed for insurers worldwide, across many multi-tenant environments, and we use Generative AI, LLM agents, and modern automation to solve quality challenges at this scale. Here are just a few of the areas we work on:

  • Release validation: risk-based testing and delivery automation;
  • Automated regression suites and test automation;
  • Functional test coverage and test gap analysis;
  • Test data generation and test environment provisioning;
  • AI-powered QA tooling, built with LLMs and agents, that engineers and QA leads use every day

Working with Engineering teams and QA leads, we replace manual QA effort with intelligent tooling, and we measure the time it saves.

Your key responsibilities🧑‍💻

You’ll own an end-to-end project that moves a real QA bottleneck from manual effort to intelligent tooling. You will build something the QA engineering teams use in their day-to-day work, not a proof of concept that stays on a shelf. Your subject will be defined with you during the selection process, within one of these example missions:

  • AI-driven release validation: build a “release copilot” that analyzes release tickets and code changes to compute risk scores and generate risk-based test plans. It also helps run bug bash sessions (scope, assignment, triage, duplicate detection) and drafts test reports and release notes.
  • Functional coverage and test gap analysis: use code intelligence and LLMs to detect shipped features, feature flags, and endpoints, map them against environment configurations and automated regression suites, and show untested areas in a live coverage dashboard.
  • Synthetic test data and environment provisioning: design a data generation and seeding pipeline (CLI / API) that produces realistic, deterministic, and privacy-compliant datasets, so teams can provision and reset test environments on demand, integrated into CI/CD.

Along the way, you’ll learn how QA, Engineering, and Product work together to ship AI software to insurers around the world. Your project will go beyond a prototype: you will validate it on real releases, hand it over with documentation, and present the results to leadership.
