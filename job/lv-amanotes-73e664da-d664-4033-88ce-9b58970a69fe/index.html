ЦЕЛИ

Мы ищем Fullstack Engineer, который умеет создавать end-to-end features и использовать AI tools для ускорения разработки.

Вы будете работать по всему stack — frontend, backend и integrations — и выпускать product features для game publishing operations. Ожидается эффективное использование AI coding assistants, быстрый темп и самостоятельная доставка production-ready features.

ЧТО ПРЕДСТОИТ ДЕЛАТЬ

  • Создавать и поддерживать web applications на React/Next.js frontend и NestJS/Node.js backend
  • Проектировать и реализовывать RESTful APIs и интегрироваться со сторонними services
  • Работать с databases — PostgreSQL, MongoDB, Redis — создавая data-driven features
  • Вместе с Tech Manager и командой выпускать features в соответствии с business priorities
  • Использовать AI coding tools — GitHub Copilot, Cursor, Claude и др. — для ускорения разработки и повышения code quality
  • Писать clean, testable code с корректным error handling и documentation
  • Участвовать в code review и поддерживать code quality standards
  • Разворачивать и мониторить applications через Docker, CI/CD pipelines и cloud platforms
  • Поддерживать live operations и устранять production issues при необходимости

КВАЛИФИКАЦИИ

ОБЯЗАТЕЛЬНО

Intermediate+ Fullstack Experience

  • 2+ года hands-on опыта создания web applications
  • Сильное владение TypeScript/JavaScript
  • Frontend: React — hooks, state management, component design
  • Backend: Node.js/NestJS или аналоги — Express, Fastify и др.
  • Database: опыт SQL — PostgreSQL — и/или NoSQL — MongoDB

Уверенное использование AI tools

  • Обязательное активное использование AI coding assistants — GitHub Copilot, Cursor, Claude Code и др.
  • Умение эффективно prompt-ить AI tools для generation, debugging и refactoring кода
  • Комфортное быстрое освоение новых tools и libraries с AI assistance
  • Понимание, когда AI output можно использовать, а когда его необходимо вручную проверять

Практические engineering skills

  • RESTful API design и integration
  • Git workflow — branching, PRs, code review
  • Базовые DevOps знания — Docker, environment variables, deployment
  • Problem-solving mindset: быстро выпускать результат и итерировать на основе feedback
  • Хорошая письменная и устная коммуникация

БУДЕТ ПЛЮСОМ

  • Опыт Python для scripting, data processing или backend work
  • Знакомство с cloud platforms — AWS, GCP, Vercel
  • Опыт testing frameworks — Jest, Vitest, Playwright
  • Бэкграунд в mobile game tools, publishing platforms или analytics
  • Знакомство с AI/ML workflows, prompt engineering или fine-tuning

ЧТО МЫ ИЩЕМ

  • Нам важно не только что вы знаете, но и как вы работаете:
  • ✅ Ориентация на delivery: MVP-first mindset, быстро выпускать working features
  • ✅ Самостоятельность: уметь разблокировать себя через docs, AI tools и experimentation
  • ✅ Баланс code quality: писать чистый код, не уходя в over-engineering
  • ✅ AI-native workflow: использовать AI для ускорения, но понимать, когда нужна ручная проверка
  • ✅ Collaboration: ясно коммуницировать, задавать хорошие вопросы и помогать коллегам

ПУТЬ РОСТА

  • Краткосрочно: владеть features end-to-end, наращивать expertise в fullstack и AI tools
  • Среднесрочно: вести technical projects, наставлять junior engineers, влиять на architecture
  • Долгосрочно: вырасти в Tech Lead / Senior Engineer / Specialist roles — AI Platform, DevOps и др.
  • С первого дня у вас будет реальный ownership и impact.
