Задачи

We're hiring a Fullstack Engineer who can build end-to-end features and leverage AI tools to accelerate development.

You'll work across the full stack — frontend, backend, and integrations — to ship product features that serve our game publishing operations. You'll be expected to use AI coding assistants effectively, move fast, and deliver production-ready features with minimal hand-holding.

Что предстоит делать

  • Build and maintain web applications using React/Next.js (frontend) and NestJS/Node.js (backend)
  • Design and implement RESTful APIs and integrate with third-party services
  • Work with databases (PostgreSQL, MongoDB, Redis) to build data-driven features
  • Collaborate with the Tech Manager and team to ship features aligned with business priorities
  • Use AI coding tools (GitHub Copilot, Cursor, Claude, etc.) to accelerate development and improve code quality
  • Write clean, testable code with proper error handling and documentation
  • Participate in code reviews and help maintain code quality standards
  • Deploy and monitor applications using Docker, CI/CD pipelines, and cloud platforms
  • Support live operations and troubleshoot production issues when needed

Требования

  • MUST HAVE (Non-negotiable)

Intermediate+ Fullstack Experience

  • 2+ years of hands-on experience building web applications
  • Strong proficiency in TypeScript/JavaScript
  • Frontend: React (hooks, state management, component design)
  • Backend: Node.js/NestJS or equivalent (Express, Fastify, etc.)
  • Database: Experience with SQL (PostgreSQL) and/or NoSQL (MongoDB)

AI Tool Proficiency

  • Must actively use AI coding assistants (GitHub Copilot, Cursor, Claude Code, etc.)
  • Can prompt AI tools effectively to generate, debug, and refactor code
  • Comfortable learning new tools and libraries quickly with AI assistance
  • Understand when to trust AI output vs. when to verify manually

Practical Engineering Skills

  • RESTful API design and integration
  • Git workflow (branching, PRs, code review)
  • Basic DevOps knowledge (Docker, environment variables, deployment)
  • Problem-solving mindset: ship fast, iterate based on feedback
  • Good communication skills (written and verbal)

Будет плюсом

  • Experience with Python (for scripting, data processing, or backend work)
  • Familiarity with cloud platforms (AWS, GCP, Vercel)
  • Experience with testing frameworks (Jest, Vitest, Playwright)
  • Background in mobile game tools, publishing platforms, or analytics
  • Exposure to AI/ML workflows, prompt engineering, or fine-tuning
  • Side projects, open-source contributions, or hackathon experience

Кого мы ищем

  • We care about how you work, not just what you know:
  • ✅ Bias toward shipping: MVP-first mindset, deliver working features fast
  • ✅ Self-sufficient: Can unblock yourself using docs, AI tools, and experimentation
  • ✅ Code quality balance: Write clean code, but don't over-engineer
  • ✅ AI-native workflow: Use AI to accelerate, but know when to verify
  • ✅ Collaborative: Communicate clearly, ask good questions, help teammates

GROWTH PATH

  • Short-term: Own features end-to-end, build expertise in fullstack + AI tools
  • Mid-term: Lead technical projects, mentor junior engineers, shape architecture
  • Long-term: Grow into Tech Lead / Senior Engineer / Specialist roles (AI Platform, DevOps, etc.)
  • You'll have real ownership and impact from day one.
