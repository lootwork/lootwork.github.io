Описание вакансии

Мы ищем DevOps Engineer уровня Middle, который поможет создавать, поддерживать и масштабировать инфраструктуру game development pipeline. Вы будете тесно работать с программистами, technical artists и QA, чтобы build systems были быстрыми, надёжными и удобными, а команда могла заниматься играми, а не борьбой с инструментами.

Ключевые обязанности

  • Проектировать, создавать и поддерживать CI/CD pipelines для game builds на нескольких платформах — PC, console, mobile
  • Управлять и оптимизировать build farms, automated build systems и nightly/CI build processes
  • Поддерживать source control infrastructure — Perforce, Git/Git LFS — включая branching strategies, repo health и performance tuning
  • Автоматизировать packaging, deployment и distribution в platform storefronts — Steam, console certification tools, app stores — и для внутренних QA builds
  • Отслеживать состояние build pipeline, диагностировать failures и сокращать build/iteration times
  • Поддерживать и улучшать automated testing infrastructure: smoke tests, regression suites, crash reporting integrations
  • Управлять cloud и on-prem infrastructure — AWS/Azure/GCP, Kubernetes/Docker — для build servers, backend services и live-ops tooling
  • Писать и поддерживать внутренние tools/scripts на Python, Bash, PowerShell для упрощения developer workflow
  • Сотрудничать с engineering leads для определения инфраструктурных потребностей будущих проектов и требований платформ
  • Отвечать за incident response при pipeline/build outages, включая root cause analysis и postmortems
  • Документировать процессы и поддерживать/обучать programmers и technical staff, использующих pipeline
  • Координироваться с engine team и technical leads по требуемым функциям и обмену best practices
  • Тесно работать с game development teams над бесшовной интеграцией Unreal Engine features в игры студии, предоставляя технические решения и помощь в troubleshooting
  • Гибко поддерживать команду на критических стадиях разработки, помогая вовремя достигать milestones

Квалификация

Что нужно для успеха

  • 2–3 года опыта DevOps, build engineering или infrastructure; игровой опыт будет большим плюсом
  • Хорошие scripting/programming навыки на Python, C#, Bash или аналогичном языке
  • Опыт CI/CD tools: Jenkins, TeamCity, GitLab CI, Azure DevOps или аналогичных
  • Практический опыт version control systems в масштабе, особенно Perforce и/или Git с Git LFS
  • Знакомство с containerization и orchestration: Docker, Kubernetes
  • Опыт хотя бы одного крупного cloud provider: AWS, Azure, GCP
  • Комфортная cross-functional работа с programmers, artists и producers
  • Сильные troubleshooting skills и стремление автоматизировать повторяющуюся работу

Будет плюсом

  • Опыт Unreal Engine
  • Понимание build processes игровых движков Unity, Unreal или proprietary engines
  • Опыт console certification/submission pipelines PlayStation, Xbox, Switch
  • Знакомство с live-ops backend services и telemetry pipelines
  • Опыт infrastructure-as-code: Terraform, Ansible
  • Опыт масштабирования build infrastructure для live-service или multi-title студии

Что вы получите

  • Наставничество опытных engine programmers
  • Знакомство с реальной AAA-разработкой
  • Практический опыт production-level codebases
  • Возможность вносить вклад в выпущенные игры
  • Возможности networking внутри игровой индустрии
