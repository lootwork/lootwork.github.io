Moon Active — одна из самых быстрорастущих mobile game companies мира, создающая качественные игровые развлечения для миллионов игроков по всему миру. Мы ищем невероятных людей, которые хотят создавать, развивать и выпускать по-настоящему выдающийся game experience. Станьте частью нашей талантливой data-driven команды и присоединяйтесь к Fun side of the Moon!

Мы ищем очень опытного, универсального и увлечённого Technical Artist в растущую команду. Вы будете тесно работать с game design и development team, формируя production pipeline и создавая инновационные playable ads — responsive mini-games — для миллионов пользователей по всему миру.

Обязанности

  • Использовать Cursor и другие AI frameworks для анимации и интеграции 2D/3D assets и visual effects в playable ads, обеспечивая одновременно красоту и performance.
  • Создавать game mechanics и levels с акцентом на «juice», polish, feel и visual feedback.
  • Проектировать и оптимизировать workflows экспорта assets из creative tools (Photoshop, Blender) в playable pipeline.
  • Внедрять advanced optimization techniques: texture packing, draw call reduction, asset compression, чтобы playables укладывались в строгие лимиты 2–5 MB.

Требования

  • Подтверждённый опыт создания animations для mobile games, UI animations, visual effects и character animations.
  • Опыт media creation tools: Adobe Photoshop, After Effects и Blender.
  • Опыт использования AI tools — asset generation, code assistance или automation — для ускорения creative pipeline.
  • Любовь к решению проблем.
  • Самоорганизация, проактивность и способность самостоятельно учиться.
  • Сильный ownership задач и способность работать независимо.
  • Интерес к новым технологиям, особенно mobile.

Преимущества

  • Опыт web development environment: Node.js, Pixi.js, Three.js.
  • Опыт GLSL или custom shaders для web-based visual effects.
