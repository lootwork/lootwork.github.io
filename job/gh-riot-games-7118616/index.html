Инженеры Riot обладают глубокими знаниями в отдельных технических областях, но ценят и возможность работать в широком спектре направлений. В роли Software Engineer вы будете использовать новые и существующие технологии, создавая инновационные решения высоконагруженных задач и принося ценность игрокам.

В роли Principal Software Engineer в League of Legends Quality Team вы будете определять и развивать техническое видение core automation frameworks, обеспечивая высочайшие стандарты качества во всей экосистеме League of Legends. Ваша работа даст инженерам нескольких инициатив — от gameplay mechanics до skin development — надёжные и масштабируемые frameworks для эффективного и устойчивого testing.

Вы будете напрямую подчиняться Engineering Manager и играть ключевую лидерскую роль в cross-team collaboration. Вы будете тесно работать с engineers и QA по всей Riot, согласовывая quality frameworks и workflows, улучшая developer experience и общее качество продуктов.

В основном мы используем C++ для game и tooling logic и Python для test automation и validation systems.

Обязанности

  • Сотрудничать с разными командами, чтобы функции соответствовали ожиданиям по нескольким измерениям: code quality, extensibility, modularity, scalability, security, operational concerns и industry standards/trends.
  • Работать и согласовываться с партнёрами из нескольких команд для поставки отличных функций.
  • Задавать тон, участвовать и определять technical discussions/designs, за которые отвечает команда.
  • Наставничество: помогать сотрудникам Riot получать инструменты и творческую среду для раскрытия потенциала, одновременно сохраняя ответственность за разумные решения и player value.
  • Участвовать в support rotation команды.

Обязательные требования

  • 8+ лет глубокого практического опыта с compiled programming languages: C/C++, Java, Go или C#.
  • 3+ года создания и поддержки automated tests для игр, web, mobile, backend services или desktop applications в зависимости от уровня роли.
  • Широкий опыт C/C++ в разных use cases и платформах.
  • Опыт лидерства organization-sized инициатив продолжительностью 1+ год, включая requirements gathering, planning, testing и release/deployment, с ответственностью за создаваемую ценность.
  • Продвижение software development best practices внутри организации: design/code reviews, coding standards, source control management, testing, delivery performance, scalability и maintainability.
  • Сильная история наставничества по soft и hard skills.

Желательные квалификации

  • Опыт использования machine learning, AI и/или functional testing для улучшения automated testing workflows, включая умную приоритизацию test cases, anomaly detection и adaptive regression coverage сложных игровых систем.
  • 2+ года опыта применения computer vision для automation tests.

Успех в этой роли определяется профессиональной экспертизой, духом сотрудничества и решениями, ставящими удовольствие игроков на первое место. Мы будем учитывать ваше образование, опыт и личные отношения с играми. Если вам близка эмпатия к игрокам и важен их игровой опыт, эта роль может подойти вам.
