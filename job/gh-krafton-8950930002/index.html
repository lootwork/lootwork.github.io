예상을 뛰어넘는 과감한 상상력과 기술로, 전 세계 팬들이 잊지 못할 세상을 만들기 위해 담대하게 도전하고 개척합니다.

우리 팀(프로젝트)을 소개합니다.

  • AI Frontier 본부는 크래프톤의 AI 기술을 실제 제품과 서비스로 연결하고, 새로운 사업 기회를 검증하고 확장하는 조직입니다.
  • 팀은 서비스에 필요한 특화 모델을 직접 만들고 지속적으로 개선합니다. 다양한 규모의 오픈웨이트 모델을 활용해 서비스 요구사항에 맞는 모델을 개발하고, 품질·응답속도·추론 비용을 함께 고려해 최적화합니다.
  • 저희에게 좋은 특화 모델이란 서비스에 필요한 품질을 안정적으로 구현하면서 응답속도와 비용 효율을 함께 확보하는 모델입니다. 프롬프트 개선, 기성 모델 활용, 작은 모델의 파인튜닝 등 문제마다 가장 효율적인 수단을 고르는 것이 이 팀의 핵심 역량입니다.
  • 팀은 제품·서비스 및 연구·인프라 조직과 긴밀히 협업하며, 서비스 요구사항에 맞는 모델 개발과 성능 개선을 담당합니다.
  • AI Frontier 본부 구성원들은 직급과 연차에 상관없이 의견을 내고, 결정하면 빠르게 실행합니다. 실험 결과와 의사결정 과정을 문서로 남기고, 새로운 모델과 기법이 나오면 바로 써보고 실제 서비스에 적용할 방법을 찾는 문화를 지향합니다.

우리 팀과 함께할 미션을 소개합니다.

  • 새로 합류하시는 분은 서비스에 필요한 특화 모델을 만들고, 이를 적용한 뒤 지속적으로 개선하는 End-to-End 업무를 담당합니다.
  • 1. 버티컬별 특화 모델 개발
  • 서비스 요구사항에 맞춰 frontier 모델과 다양한 규모의 오픈웨이트 모델을 동일 기준으로 실측하고, 품질·응답속도·비용 Baseline 수립
  • 프롬프트 개선, 기성 모델 활용, SFT·LoRA·Distillation 등 추가 학습 중 목표 대비 가장 효율적인 개선 방식 선택과 실행
  • 학습 데이터 구성·정제, 합성 데이터 생성, 오류 분석을 통한 빠른 반복 개선
  • 2. 효율적인 서빙을 위한 모델 최적화
  • 양자화·경량화·소형 모델 증류 등을 통해 품질을 유지하면서 응답속도와 추론 비용 개선
  • 서비스별 서빙 요구사항(지연, 처리량, 비용 목표)을 정의하고 유관 조직과 함께 프로덕션 배포까지 연결
  • 요청·토큰 단위 원가를 기준으로 모델 선택과 학습 전략의 효과 측정
  • 3. 모델 평가와 지속 개선
  • 서비스별 평가 기준과 데이터셋 설계, 오프라인 평가와 실사용 지표를 결합한 배포 판단
  • 모델 개선과 검증을 위한 재학습·재평가 파이프라인 구축과 자동화
  • 다양한 서비스 요구사항에 대응할 수 있도록 모델 개발 체계를 표준화
  • 4. 유관 조직과의 협업
  • 제품·서비스 조직과 함께 요구사항을 모델 과제로 구체화하고, 개발 범위·우선순위·평가 기준 협의
  • 연구·인프라 조직과 모델 개선에 필요한 기술 및 적용 방안 협의

이런 경험을 가진 분과 함께 성장하고 싶습니다! (필수요건)

  • Computer Science, Machine Learning, Artificial Intelligence 또는 관련 전공의 학위나 이에 준하는 실무 역량
  • PyTorch 등 딥러닝 프레임워크를 활용해 모델을 학습·평가하고, 실제 서비스나 제품에 적용해 보신 분
  • 오픈웨이트 LLM 또는 딥러닝 모델을 특정 업무나 도메인 데이터에 맞게 파인튜닝(SFT, LoRA 등)하고, 성능을 유의미하게 개선해 보신 분
  • 모델 성능뿐 아니라 응답속도·처리량·추론 비용을 함께 측정하고, 이를 근거로 모델 크기나 개선 방식을 결정해 보신 분
  • 데이터 품질과 구성, 평가 기준이 모델 성능을 좌우한다는 이해를 바탕으로, 학습 데이터 정제·오류 분석·평가 체계 구성을 직접 수행해 보신 분
  • 목표 품질과 응답속도·비용을 종합적으로 고려하며, 제한된 시간과 자원 안에서 결과를 만들어 보신 분
  • 제품·서비스 및 연구·인프라 조직 등 다양한 이해관계자와 요구사항을 맞추고, 실험 결과와 결정 근거를 문서로 공유해 오신 분
  • 해외 출장에 결격 사유가 없는 분

이런 경험들이 있다면 저희가 찾는 그 분입니다! (우대요건)

  • 양자화(FP8/INT4 등), 지식 증류, 소형 모델 전환 등으로 품질 저하를 최소화하면서 추론 비용이나 지연을 크게 줄여 본 경험
  • vLLM·SGLang 등 서빙 엔진으로 모델을 배포하고, 처리량·지연·비용을 측정해 개선해 본 경험
  • 대형 모델을 활용한 합성 데이터 생성, 품질 필터링, Teacher-Student 학습 파이프라인 구축 경험
  • LLM-as-a-Judge, pairwise 비교 등 실제 서비스 품질을 반영하는 평가 체계를 설계하고, 평가 결과를 배포 판단에 활용해 본 경험
  • 모델의 재학습·재배포를 위한 MLOps 파이프라인 구축 및 운영 경험
  • 음성 인식·합성 등 음성 기반 모델이나 서비스 개발 경험
  • 대화형 AI, 에이전트 AI, 게임 등 사용자 상호작용 도메인 데이터를 다뤄 본 경험
  • 개인정보 마스킹, 라이선스 확인 등 데이터 활용에 필요한 법무·보안 요건을 관련 조직과 함께 해결해 본 경험
  • 프롬프트 설계부터 파인튜닝까지 여러 선택지를 비교해 업무별로 최적의 접근을 고른 경험
