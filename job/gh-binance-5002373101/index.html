Binance is a leading global blockchain ecosystem behind the world’s largest cryptocurrency exchange by trading volume and registered users. We are trusted by 300+ million people in 100+ countries for our industry-leading security, user fund transparency, trading engine speed, deep liquidity, and an unmatched portfolio of digital-asset products. Binance offerings range from trading and finance to education, research, payments, institutional services, and more. Our mission is to increase the freedom of money and financial access for people around the world.

Binance Square is Binance’s content community business, covering modules such as Feed recommendation, content publishing, livestreaming, creator center, and content moderation. Since its launch, it has gone through 65 product iterations and currently maintains a release cycle of one version every three weeks. The product spans six platforms: Android, iOS, Web, Admin, Mini Program, and Backend.

You will join a 3-person QA team and participate in the full testing cycle of a real, high-traffic product. The team has already built a relatively complete toolchain, including automated tracking validation, test data generation plugins, regression scripts, and an online test case platform. You will not need to build everything from scratch; instead, you will be able to ramp up quickly within a mature process and make practical contributions.

Обязанности

  • Execute functional and regression testing across multiple platforms (Android / iOS / Web / Admin) based on test cases, and use the team’s existing scripts and online spreadsheets to record execution results.
  • Use the team’s in-house event tracking validation tools to capture and compare logs, determine whether data reporting complies with specifications, and file tickets for any uncovered tracking points.
  • Cross-platform compatibility checks and online issue reproduction
  • Verify differences in how the same feature performs across different platforms and versions, and reproduce and document issues reported from production.
  • Test data preparation - Use the team’s test data generation tools to prepare test accounts and content scenarios.
  • Submit clear and reproducible bug reports, and follow up on fixes through verification until closure.
  • Test case repository maintenance
  • Update test case documentation in sync with requirement changes.

Требования

  • Currently pursuing or recently completed a Bachelor’s degree or above in Computer Science, Software Engineering, Information Management, or a related field
  • Understanding of basic software testing concepts, including test cases, bug lifecycle, and priority classification

Able to use Chrome DevTools to inspect network requests and console logs, with a basic understanding of HTTP and JSON

  • Detail-oriented and patient, with the ability to complete repetitive validation tasks with high quality

Strong written communication skills, with the ability to clearly describe reproduction steps, expected results, and actual results
