О роли

In this role, you will elevate quality standards across multiple concurrent projects with a Quality First mindset as the core mission throughout the full SDLC. Beyond traditional automated testing and test architecture, you will champion next-generation QA by designing and integrating AI Agents, custom Agent Skills, and automated scripts to optimize team processes and improve code quality.

As a Quality Assurance Engineer, you will collaborate closely with project and engineering teams to build resilient, scalable quality systems and bridge the gap between development and quality, ensuring high standards from design to deployment.

Key Responsibilities (Day-to-Day)

  • Test Strategy & Planning: Understand project scopes and design comprehensive, flexible testing activities tailored to specific project needs.
  • Test Architecture Decision-Making: Evaluate and decide the exact types of testing required per project (e.g., API, UI, integration, regression, E2E).
  • Tooling & Infrastructure Development: Work collaboratively with the team to build, scale, and improve our technical toolkit—including continuous integration pipelines, reporting, quality dashboards, and test environments.
  • Multi-Project Ownership: Comfortably balance capacity and switch context across several concurrent projects without sacrificing quality standards.
  • Automation Engineering: Write, maintain, and execute automated test scripts and shell scripts using Java, Python, and Bash.
  • Agile, Process, & Quality First Mentorship: Understand Scrum and broader Agile methodologies across projects; actively guide development teams on a Quality First mindset, quality processes, testing procedures, and best practices within project cycles.
  • AI & Intelligent QA Tooling: Understand, apply, and integrate AI tools, AI agents, and automated scripts into workflows to help engineering teams streamline quality assurance—improving both development process efficiency and overall code quality.

Must-Have Qualifications

  • 3+ years of experience as a Software Engineer in Test (SET), QA Automation Engineer, or similar technical quality role.
  • Containerization & Kubernetes (K8s) : Strong practical understanding of Docker (creating/managing Dockerfiles and Docker Compose) and Kubernetes concepts (pods, deployments, services, helm charts) to execute, scale, and debug tests in containerized environments.
  • Agile/Scrum: Understanding of Agile/Scrum practices (sprint planning, backlog refinement, retrospectives).
  • Solid Git Knowledge: Hands-on experience with version control concepts, branch strategy, PR reviews, and merge conflict resolution.
  • Strong Programming & Scripting: Hands-on proficiency in Java and Python for test framework development, alongside Bash scripting within Unix/Linux environments.
  • Broad Testing & CI/CD Expertise: Strong experience across API, UI, and integration testing, fully integrated into CI/CD pipelines (e.g., Jenkins, GitLab CI).
  • AI Concepts & Ecosystem Knowledge: Understanding of AI Agents, MCP (Model Context Protocol) specifications, Agent Skills/Tools, and prompt engineering to build intelligent test runners or automated quality checks. Context management, including prompt window optimization, knowledge base retrieval strategies, and maintaining session state for complex, multi-turn AI-driven execution.

Nice-to-Have Qualifications

  • Experience managing custom test reporting dashboards (e.g., Snowflake, Grafana).
  • Knowledge of performance and load testing frameworks (e.g., JMeter, Locust, K6).
  • Exposure and understanding of Traçability Matrices in Test Case creation.
