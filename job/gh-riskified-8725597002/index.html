О роли

The Application Security team at Riskified ensures the security of Riskified’s products. In this role you will evaluate security architecture, design and implement technology, processes, and procedures by collaborating closely with developers, product managers, and other members of the security team.

Что предстоит делать

  • Initiate and improve processes, tools, and documentation that will support application security requirements
  • Identify security design gaps in existing and proposed architectures, services and products
  • Evaluate architecture, design, and code to identify and resolve potential vulnerabilities and security risks
  • Work closely with development teams to prioritise and resolve application security issues and implement security best practices, frameworks, etc.
  • Assist in identifying and responding to security issues in Riskified’s environment

Требования

  • 5+ years application security hands-on experience
  • Experience performing security design and code reviews, threat modeling and customizing application security solutions
  • Strong understanding of common security attacks and their remediation
  • Hands-on experience with AI tools and AI-based security solutions
  • Experience performing security design reviews and security testing for AI systems, LLM-based applications, and AI agents
  • Experience with programming languages: Ruby, Scala, Python, JavaScript, etc. (Advantage)
  • Ability to work well with developers and product management
  • Experience working in high scale SaaS environment (Advantage)
  • Knowledge of microservice architecture, web technologies and APIs (Advantage)
  • Ability to explain complex security problems
  • Excellent problem solving skills
