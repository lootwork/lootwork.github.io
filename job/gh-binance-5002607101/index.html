Что предстоит делать

1. Own core mobile modules of Binance Social & Content, in particular the Chat / IM experience (conversations, group chat, VIP service groups, message sync, read state, notifications), from design through release and iteration.

2. Build and evolve the real-time messaging client: WebSocket connection management, message ordering and deduplication, offline sync, local storage (Room / SQLite), and Protobuf-based protocols.

3. Drive performance and stability: startup time, list scrolling and rendering, memory, network efficiency, ANR and crash rate, APK size.

4. Work across the stack when needed. Read and reason about our Java/Spring services and APIs, debug client-server issues end to end, and contribute to backend or BFF changes with the owning team.

5. Raise engineering quality: code reviews, modularisation, automated tests, lint and static analysis, security-minded coding (secure storage, TLS, input validation).

6. Use AI-assisted development tools day to day for coding, testing, debugging and code review, and help the team do the same.

Кого мы ищем

Must have

- 5 years of Android development, with strong Kotlin (coroutines, Flow) and solid Java.

- Experience with modern Android architecture: MVVM / MVI, Hilt/Dagger, multi-module projects, Jetpack (Room, Paging, Lifecycle, Navigation).

- Real-time or IM experience is a strong plus, ideally hands-on with WebSocket, long-lived connections, message reliability (ordering, retry, dedup), and local persistence.

- Proven ability to optimize Android performance: networking, rendering (RecyclerView / Compose), memory, startup, ANR analysis, and tools such as Profiler, Perfetto or LeakCanary.

- Good grasp of UI/UX and a track record of shipping polished, user-centric features.

- Full-stack mindset: comfortable working on backend code (Java/Spring or similar), SQL and Redis basics.

- Hands-on AI coding tools (e.g. Claude Code, Cursor, Copilot) used in real work, and the judgment to review AI-generated code.

- Strong problem-solving in fast-paced, cross-functional teams; fluent in English and Mandarin.

Будет плюсом

- Flutter experience, particularly Flutter-in-native hybrid integration (our app embeds Flutter modules).

- Jetpack Compose; experience migrating View-based screens to Compose.

- Real-time audio/video or live streaming (e.g. Agora, ExoPlayer/Media3).

- Experience with security fundamentals on mobile (TLS configuration, certificate pinning, secure storage, obfuscation).
