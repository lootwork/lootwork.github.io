В Rockstar Games мы создаём развлекательные продукты мирового уровня.

Станьте частью команды, работающей над одними из самых масштабных и вдохновляющих творческих проектов во всей индустрии развлечений — в инклюзивной, мотивированной среде, где можно учиться и сотрудничать с одними из самых талантливых специалистов отрасли.

Rockstar Games ищет Senior Software Engineer в Data Engineering в команду, создающую передовую game analytics platform и инструменты, которые помогут лучше понимать наших игроков и улучшать их опыт в играх.

Идеальный кандидат умеет разрабатывать сложные ingestion и transformation processes с акцентом на надёжность и производительность. В сотрудничестве с Data Engineers, Machine Learning Engineers и другими Software Engineers он будет помогать команде Analysts и Data Scientists предоставлять компании data-driven insights и applications.

Это штатная позиция с полной занятостью и работой из офиса в новой современной студии разработки Rockstar в Карлсбаде, Калифорния.

ЧЕМ МЫ ЗАНИМАЕМСЯ

  • Команда Rockstar Games Online Services создаёт технологическую основу наших игр и обеспечивает player experiences мирового уровня.
  • Data Engineering group управляет данными петабайтного масштаба, интегрируя десятки streaming и batch sources со строгими требованиями к надёжности, compliance и low-latency processing.
  • Мы применяем к data engineering строгость software engineering: clean architecture, modular design и automated testing. Наш фокус — создание масштабируемых переиспользуемых платформ и frameworks, позволяющих партнёрам в Data Science и Game Development получать insights и открывать новые возможности для игроков.

ОБЯЗАННОСТИ

  • Проектировать, создавать и поддерживать high-throughput streaming и batch data processing services с основным фокусом на raw и bronze-level ingestion.
  • Разрабатывать и эксплуатировать stream-based applications для real-time data transformation, enrichment, validation и routing.
  • Отвечать за развитие event schemas и data contracts, включая Avro schemas и governance Schema Registry.
  • Обеспечивать scalability, fault tolerance и performance streaming и ingestion pipelines под высокой нагрузкой.
  • Участвовать в platform-level задачах: deployment automation, observability, operational tooling и CI/CD.
  • Участвовать в проектировании и реализации cloud-native data infrastructure для real-time и batch workloads.

ТРЕБОВАНИЯ

  • 5+ лет профессионального опыта создания production software systems, желательно в distributed или data-intensive environment.
  • Сильный опыт Java и/или Scala, а также Python в backend или data processing applications.
  • Опыт проектирования и эксплуатации streaming systems на Kafka или Kafka Streams либо аналогах.
  • Опыт event-driven architectures, включая schema evolution и compatibility.
  • Опыт построения real-time и/или near-real-time data pipelines в большом масштабе.
  • Сильное понимание distributed systems concepts: partitioning, fault tolerance, backpressure, exactly-once/at-least-once semantics.
  • Знакомство с Avro, Protobuf или аналогичными serialization formats и practices schema governance.

  • Опыт deployment и scaling applications в containerized environments, например Kubernetes, AKS.
  • Опыт с artifact repositories, например Artifactory, ProGet, Maven repositories.
  • Опыт Infrastructure-as-Code, например Terraform, Databricks Asset Bundles.

  • Знакомство с Apache Spark.
  • Знакомство с CI/CD pipelines, automated testing и deployment workflows.
