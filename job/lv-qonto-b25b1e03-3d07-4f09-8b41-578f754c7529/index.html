Join us as a Data Engineer Intern to help build the pipelines and tools that power Qonto's Data Platform. You'll ship a real, end-to-end project that makes data more accessible across the company, working alongside Charles, our Lead Data Engineer, and mentored day-to-day by Michael, Senior Data Engineer.

➡️ What you'll do

  • Build data pipelines: Create and maintain batch and real-time pipelines that move data across Qonto's platform.
  • Connect new data sources: Help ingest data from internal and external systems into our centralized warehouse.
  • Build internal tools: Design web interfaces that make data more accessible to internal stakeholders.
  • Automate and improve: Contribute to the tooling and automation that keeps the data platform reliable.
  • Run your own project: Own an exploration project end-to-end and demo it to the team.

➡️ What we're looking for

  • Python: You write clean, maintainable code and know how to structure a real project, not just scripts.
  • Data modeling: You understand how to structure data with tables, schemas, and SQL.
  • Final-year student: You're in your final year (M2) of a Master's in Data Engineering, Data Science, or Software Engineering.
  • AI-native: You use AI tools daily to learn faster and get more done.
  • Communication: You communicate clearly and work smoothly with stakeholders across different teams.

➡️ What we can offer you

  • Daily mentorship: Hands-on, day-to-day mentorship from a senior Data Engineer on the team.
  • Real ownership: You'll run your own exploration project end-to-end, not just support someone else's.
  • Modern, AI-native stack: Unlimited access to AI tools like Claude Code to accelerate your work.
