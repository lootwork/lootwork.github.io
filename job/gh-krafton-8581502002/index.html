우리는 게이머의 로망을 실현하기 위해, 누구도 가지 않는 길을 갑니다.

예상을 뛰어넘는 과감한 상상력과 기술로, 전 세계 팬들이 잊지 못할 세상을 만들기 위해 담대하게 도전하고 개척합니다.

We pioneer the path to players' dreams.

With bold imagination and breakthrough technology, we create unforgettable worlds for fans across the globe.

우리 팀(프로젝트)을 소개합니다.

KRAFTON 게임의 신뢰할 수 있는 플레이 환경을 만들기 위해 게임 보안 솔루션과 보안 운영 체계를 개발·적용·운영하는 조직입니다. KRAFTON Security Services(이하 KSS)를 중심으로 Anti-Cheat, Anti-Tamper, 보안 운영, 데이터 분석, ML 기반 탐지 등 게임 보안에 필요한 핵심 기능과 서비스를 제공합니다.

KSS는 KRAFTON의 다양한 게임 보안 기술과 운영 역량을 통합한 Game Trust Platform으로, 여러 게임 스튜디오가 빠르고 안정적으로 활용할 수 있는 표준화된 보안 플랫폼으로 발전하고 있습니다.

우리 팀과 함께할 미션을 소개합니다.

KSS가 제공하는 데이터 분석 및 ML 기반 탐지 역량을 고도화하여, 게임 내 비정상 행동과 부정행위를 빠르고 정확하게 탐지·판별하는 모델을 개발합니다. 대용량 게임 로그와 유저 행동 데이터를 분석하고, 탐지 모델의 성능을 개선하며, 탐지 결과가 보안 운영과 제재 대응에 효과적으로 활용될 수 있도록 지원합니다.

  • 게임 내 비정상 유저 행동 및 부정행위 탐지를 위한 ML 모델 개발 및 개선
  • 대용량 게임 로그, 유저 행동 데이터, 보안 이벤트 분석을 통한 이상 징후 탐지
  • 부정행위 패턴 분석, 탐지 피처 발굴, 탐지 로직 설계 및 고도화
  • 보안 운영 및 제재 대응을 위한 데이터 분석 지원
  • KSS 탐지/운영 효율성 향상을 위한 지표 설계 및 시각화
  • 게임 스튜디오, 보안 엔지니어 등과의 협업
  • 탐지 모델의 성능 평가, 오탐/미탐 분석 및 개선

이런 경험을 가진 분과 함께 성장하고 싶습니다! (필수요건)

  • Machine Learning, Deep Learning, Statistics, Computer Science 등 관련 분야의 학위 또는 이에 준하는 실무 경험
  • 이상 탐지, 분류, 예측, 패턴 분석 등 ML 기반 모델링 프로젝트 경험
  • Python, SQL 등을 활용한 대용량 로그/이벤트 데이터 분석 역량
  • 대용량 로그/이벤트 데이터 분석 역량
  • 로그 데이터의 정제, 피처 엔지니어링, 학습 데이터 구성, 모델 평가까지의 데이터 흐름에 대한 이해
  • 머신러닝/딥러닝 모델의 구조를 이해하고 목적에 맞게 모델을 개선한 경험
  • 데이터 품질, 재현성, 확장성을 고려한 피처 엔지니어링 역량
  • 모델 성능 정량적으로 평가하고 오탐/미탐 관점에서 개선 방향을 도출할 수 있는 역량
  • 스스로 문제를 정의하고 데이터 기반으로 개선해 나가는 역량

이런 경험들이 있다면 저희가 찾는 그 분입니다! (우대요건)

  • 게임 데이터를 활용한 Anti-Cheat, 부정행위/어뷰징 탐지, 이상행위 분석 경험
  • FPS/TPS, 배틀로얄, MMORPG 등 다양한 게임 장르에 대한 플레이 경험 또는 데이터 특성 이해
  • 유저 행동 데이터 기반의 비정상 패턴 탐지 및 모델/탐지 로직 개선 경험
  • 대용량 로그 데이터 처리 및 ML 파이프라인 구축/운영 경험
  • Spark, Hadoop 등 대용량 데이터 플랫폼 사용 경험 또는 이에 대한 이해
