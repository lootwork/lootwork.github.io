О Opportunity

We are looking for a Senior Staff Engineer/Engineering Director who will be responsible for the design, deployment, optimisation, and full lifecycle management of enterprise-level cloud database platforms. Lead the implementation of multi-cloud architectures for Alibaba Cloud and AWS databases, ensuring high availability, high performance, and cost optimization.

Что предстоит делать

  • Database Architecture Design & Optimization
  • Design, deploy, and optimize cloud databases on Alibaba Cloud (RDS, PolarDB, Redis, MongoDB) and AWS (RDS, Aurora, ElastiCache, DynamoDB).
  • Select appropriate database types (relational/NoSQL/NewSQL) and service models (managed services vs. self-built clusters) based on business requirements.
  • Operations & Monitoring
  • Implement high availability (HA) and disaster recovery (DR) solutions, such as Alibaba Cloud cross-zone deployments, AWS Multi-AZ, and cross-region replication.
  • Monitor database performance and health using cloud-native tools (Alibaba Cloud CloudMonitor, AWS CloudWatch) and third-party tools (Prometheus, Grafana).
  • Performance Tuning & Incident Resolution
  • Analyze slow queries, lock conflicts, and resource bottlenecks (CPU/IO/memory), optimizing SQL statements and index designs.
  • Rapidly resolve production database incidents (e.g., replication lag, connection pool exhaustion, storage scaling).
  • Security & Compliance
  • Manage database access controls via Alibaba Cloud RAM policies and AWS IAM roles to ensure data security.
  • Perform regular database upgrades and audit log analysis to comply with GDPR, Multi-Tier Cloud Security Certification (MLPS), and other regulations.
  • Automation & Cost Management
  • Automate database deployment and operations using Terraform, Ansible, or cloud-native tools (Alibaba Cloud ROS, AWS CloudFormation).
  • Optimize cloud costs via auto-scaling, reserved instances, and storage tiering (e.g., AWS S3 Glacier).
  • Cross-Team Collaboration
  • Support development teams in database design reviews, SQL code standardization, and DevOps processes (e.g., database change management in CI/CD).
  • Team Management
  • Manage a team of DBAs to ensure timely completion of projects and efficient resolution of incidents.

What We Look For In You

  • Technical Skills
  • Expertise in database services of at least one major public cloud (Alibaba Cloud or AWS), with familiarity in the other.
  • In-depth understanding of core principles of mainstream databases (MySQL, PostgreSQL, Redis) and advanced SQL optimization/troubleshooting skills.
  • Experience with database migration tools (AWS DMS, Alibaba Cloud DTS) and cross-cloud synchronization solutions.
  • Experience Requirements
  • 5+ years of DBA experience, including at least 2 years managing public cloud databases.
  • Hands-on experience with large-scale (TB-level) databases, sharding, and read/write splitting.
  • Experience leading cloud database migrations, DR drills, or hybrid cloud projects is preferred.
  • Soft Skills
  • Strong documentation skills for creating SOPs and contingency plans.
  • Excellent communication skills to coordinate development, operations, and business teams.
  • Certifications & Education
  • Alibaba Cloud ACP/ACE (Database) or AWS Certified Database – Specialty certifications preferred.
  • Bachelor’s degree or higher in Computer Science, Software Engineering, or related fields.
