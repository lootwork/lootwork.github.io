关于 VOODOO

Voodoo 成立于2013年，总部位于法国巴黎，是一家以“用娱乐点亮世界”为使命的全球领先娱乐科技公司。我们通过打造标志性的手机游戏和应用，持续影响全球数亿用户的日常娱乐体验。目前公司在全球范围内拥有约1000名员工，年收入近8亿美元。公司旗下拥有Paper.io http://公司旗下拥有Paper.io、Mob Control、Hole.io http://Hole.io、Marble Sort、Castle Buster等经典爆款游戏，以及BeReal、Wizz等热门社交应用。累计下载量已突破80亿次，每月活跃用户超过2亿，是全球下载量排名第三的移动发行商（仅次于Google和Meta）。

团队介绍

Voodoo 游戏团队汇聚了混合休闲、休闲和中重度游戏领域的专家。其中，“Core ”游戏团队与全球内部及外部工作室合作，创造、开发并发行新的爆款游戏；“Live” 游戏团队则专注于提升现有成功产品的长线运营。

我们正在北京组建一个全新的 4X 游戏工作室。团队小而精，由前后端研发、策划和美术组成，并由 Voodoo 欧洲的工作室和技术团队提供支持，共享代码、工具和经验。你将在项目起步阶段加入，深度参与并影响游戏从 0 到 1 的搭建。

岗位职责

作为游戏开发工程师，你将使用 Unity 开发一款 4X 策略游戏的系统与内容：玩家探索的大世界、建设的城池，以及参与的战斗。

1. 使用 Unity 和 C# 开发玩法系统与内容，包括大地图、城建、兵种、英雄和战斗等；

2. 负责 UI 开发，包括 4X 游戏中大量的功能界面、倒计时及各类队列（建造、训练等）；

3. 与服务端配合，完成客户端与服务端的接口对接与联调；

4. 开发编辑器和工具，帮助策划和美术提升内容生产效率；

5. 负责美术资源和动画的接入；

6. 负责多机型适配与性能优化，保证游戏在各类移动设备上稳定、流畅运行；

7. 逐步参与新功能、长线运营内容和运营活动的开发。

任职要求

1. 本科及以上学历，10年以上Unity开发经验。

2. 有扎实的 Unity 和 C# 开发经验，参与过已上线的SLG/4X 或其他中重度策略游戏项目；

3. 熟悉 Unity 玩法系统、UI 及动画开发，重视移动端性能与内存优化；

4. 有对接服务端权威架构的经验，熟悉接口对接和游戏状态同步；

5. 有良好的团队协作精神，乐于接受反馈，能适应快速迭代；

6. 英语加分但非必需，可全程中文面试。

工作地点

北京，全职线下办公（成都可议）。
