关于 VOODOO

Voodoo 是一家2013年创立于巴黎的消费科技公司，我们的使命只有一个：用娱乐点亮世界。如今我们拥有1000多名员工，年收入超过10亿美元，并持续盈利。旗下游戏和应用累计下载量已突破80亿次，每月活跃用户超过2亿，使 Voodoo 成为全球下载量排名第三的移动发行商，仅次于 Google 和 Meta。一路走来，我们先后获得了高盛（Goldman Sachs）、腾讯（Tencent）和 GBL 的投资。

工作地点：北京（成都可协商），需全职到岗办公。

团队介绍

Voodoo 游戏团队汇聚了混合休闲、休闲和中重度游戏领域的专家。其中，“Core ”游戏团队与全球内部及外部工作室合作，创造、开发并发行新的爆款游戏；“Live” 游戏团队则专注于提升现有成功产品的长线运营。

我们正在北京组建一个全新的中重度游戏工作室。团队小而精，由前后端研发、策划和美术组成，并由 Voodoo 欧洲的工作室和技术团队提供支持，共享代码、工具和经验。你将在项目起步阶段加入，深度参与并影响游戏从 0 到 1 的搭建。

岗位职责

作为客户端开发工程师，你将使用 Unity 开发一款中重度在线手游的玩法、系统与内容。

1. 使用 Unity 和 C# 开发游戏的核心玩法、系统和内容；

2. 负责 UI 开发，搭建数据驱动、实时响应服务端更新的各类功能界面；

3. 与服务端同学共同设计数据结构和接口协议，完成前后端联调与问题排查；

4. 负责状态同步、延迟处理、断线重连等网络相关开发，保证弱网环境下的游戏体验；

5. 开发编辑器和工具，帮助策划和美术提升内容生产效率，并负责美术资源和动画的接入；

6. 负责多机型适配与性能优化（渲染、内存、资源加载等），重点保证低端机上的稳定与流畅；

7. 逐步参与新功能、长线运营内容和运营活动的开发。

任职要求

1. 本科及以上学历，7 年以上 Unity 和 C# 开发经验，至少参与过 1 款已上线的手游项目；

2. 有服务端权威架构的网络游戏开发经验；

3. 前后端对接能力扎实，熟悉状态同步、延迟处理、断线重连及网络异常处理；

4. 有 UI 复杂、数据驱动且需实时响应服务端更新的游戏开发经验；

5. 移动端优化能力扎实，熟悉渲染、内存和资源加载优化，尤其关注低端机表现；

6. 有与服务端紧密协作的经验，能共同定义数据结构和接口协议，并跨前后端排查问题。

加分项

- 有社交和多人玩法系统开发经验，如公会、聊天、排行榜、匹配、实时 PvP 等；

- 有长线运营相关开发经验，如运营活动、远程配置、A/B 测试等；

- 有服务端开发经验，或有兴趣参与服务端工作；

- 日常使用 AI 辅助开发工具（如 Claude Code、Cursor 等）；

- 英语加分但非必需，可全程中文面试。
