Что предстоит делать

- Design and deploy dynamically scalable, self-healing infrastructure and applications in public and private cloud environments.

- Use IaaS automation tools like Terraform, AWS CloudFormation and Ansible.

- Migrate environments from on-premise infrastructure to AWS/GCP environments.

- Handling operational and security alerts and incidents.

- Improving infrastructure, application and security monitoring systems.

- Continuous performance improvement and troubleshooting of critical components.

- Learn from your colleagues and share your knowledge with them. We have to grow as the company grows, and mutual, honest feedback is one of our most reliable weapons.

- The role requires work on shifts, which may include public holidays.

WHAT YOU NEED TO HAVE

- Basic understanding of public cloud - AWS/GCP

- Experience with CI/CD services - GitHub/GitLab or Jenkins

- Basic understanding of containers and container orchestration systems - Docker, Kubernetes

- Previous experience with monitoring and log management systems - Grafana, ELK Stack, Splunk, SIEM

- Good understanding of networking and security concepts (TCP/IP, routing, firewalls)

Будет плюсом

- Understanding of RDBMS - AWS RDS, MySQL/MariaDB

- Basic knowledge of Python or Bash scripting

- Infrastructure as Code tools - Terraform, AWS CloudFormation

- Experience with configuration management tools - Puppet, Ansible

- Experience with on-premise private cloud infrastructures running VMware or KVM

OUR TECH STACK

- Public cloud - AWS and GCP

- Infrastructure-as-Code and configuration management - Terraform, Ansible, Puppet

- CI/CD - GitHub

- Web Servers and Load Balancing - NGINX, Envoy, AWS NLB/ALB, HAProxy

- Containers and orchestration - Docker, Kubernetes, AWS EKS/ECS

- Databases - Amazon RDS (MariaDB/PostgreSQL), TimescaleDB, Amazon Aurora, ClickHouse

- Messaging services - Amazon MSK, RabbitMQ

- Monitoring and logging - Grafana, Telegraf, Prometheus, VictoriaMetrics, ELK Stack, OpenTelemetry

- Private cloud - VMware and KVM
