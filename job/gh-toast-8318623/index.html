Toast creates technology to help restaurants and local businesses succeed in a digital world, helping business owners operate, increase sales, engage customers, and keep employees happy.

We are hiring a Senior Software Engineer to join the Reporting Experience team in Dublin. The Reporting Experience team owns the reports restaurant operators use every day to run their business.

As a Senior Software Engineer, you will build and evolve the services that generate those reports, making sure every number an operator sees is correct, fast and explainable, from a single location to large multi-location groups.

A day in the life (Responsibilities)

  • Design, build and run backend services in Java / Kotlin that define, generate and deliver reports
  • Build new reports and metrics end to end, from the query to the API to the page and the export, working with Product and Design
  • Investigate and fix data discrepancies raised by customers and support, digging through code, logs and data to find the root cause
  • Own correctness: cover report logic with automated tests and add the monitoring and alerts that catch regressions before customers do
  • Improve the performance and reliability of report generation as data volume and customer size grow
  • Evolve the agentic framework to be more complete and accurate
  • Use AI tooling as a genuine part of your workflow, not an afterthought

What you'll need to thrive (Requirements)

  • 5+ years of professional software development, building backend or distributed systems
  • Proficiency in Kotlin, Java or another object-oriented language, with solid instincts around testing and code quality
  • Strong data analytics skills, and comfort reasoning about how data is aggregated and why two numbers don't match
  • Experience operating production services: observability, debugging incidents, and safe rollouts
  • The ability to take an ambiguous problem, break it down and drive it to completion with little oversight
  • Strong communication and problem-solving skills, and curiosity to learn the restaurant domain
  • Experience building data analytics agents or AI skills is a bonus
  • Experience with OpenSearch is a bonus

**This is a hybrid role requiring in-office collaboration two days per week in our Dublin office.**

Our tech stack

TREX's report generation service is written in Kotlin and serves report definitions, data and exports to the web app through APIs. Data sources live in Postgresql, Apache Iceberg, OpenSearch, DynamoDB.
