Senior Frontend Engineer

Обязанности

  • Design, develop, and maintain modern, scalable, and responsive web interfaces using React and TypeScript.
  • Translate product designs and user stories into high-quality, functional UI components.
  • Optimize performance for speed and scalability across browsers and devices.
  • Refactor legacy code to align with current best practices and architectural patterns.
  • Write clean, maintainable, and testable code using modern frontend tooling.
  • Implement effective state management strategies and integrate with REST/GraphQL APIs.
  • Participate in and lead frontend design reviews and architecture discussions.
  • Collaborate closely with product managers, designers, and backend engineers to deliver features end-to-end.
  • Contribute to planning, estimation, and delivery tracking of new features and technical improvements.
  • Identify and resolve performance bottlenecks, UI bugs, and UX inconsistencies.
  • Mentor peers, provide constructive code reviews, and foster a culture of continuous improvement.

Требования

  • 6+ years of professional experience in software development.
  • 4+ years of hands-on experience with React (and ideally TypeScript).
  • Deep knowledge of JavaScript/ES6+, HTML5, CSS3, and Web APIs.
  • Experience with responsive design systems and CSS-in-JS (e.g., Tailwind).
  • Familiarity with REST/GraphQL APIs, WebSockets, and real-time data handling.
  • Comfortable working with Git, CI/CD pipelines, and agile collaboration tools.
  • Exposure to testing frameworks such as Jest or Cypress.

Будет плюсом

  • Experience with microfrontend or monorepo architectures.
  • Strong understanding of design systems and scalable component architectures.
  • Experience integrating third-party identity/auth systems (e.g., SSO, OAuth2).
  • Proficiency with Next.js, SSR/SSG, and hybrid rendering strategies.
  • A deep appreciation for UX polish, animation, and interaction design.
  • Excellent written and verbal communication skills for both technical and non-technical audiences.
