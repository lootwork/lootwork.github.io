Senior Frontend Engineer

ОБЯЗАННОСТИ

  • Проектировать, разрабатывать и поддерживать современные масштабируемые responsive web interfaces на React и TypeScript.
  • Превращать product designs и user stories в качественные функциональные UI components.
  • Оптимизировать скорость и масштабируемость в разных браузерах и устройствах.
  • Рефакторить legacy code в соответствии с современными best practices и architecture patterns.
  • Писать чистый, сопровождаемый и тестируемый код с современным frontend tooling.
  • Реализовывать эффективные state management strategies и интеграции с REST/GraphQL API.
  • Участвовать и лидировать в frontend design reviews и architecture discussions.
  • Тесно работать с PM, designers и backend engineers, доводя features end-to-end.
  • Участвовать в planning, estimation и tracking delivery новых features и технических улучшений.
  • Находить и устранять performance bottlenecks, UI bugs и UX inconsistencies.
  • Менторить коллег, давать конструктивный code review и развивать культуру постоянного улучшения.

ТРЕБОВАНИЯ

  • 6+ лет профессионального software development.
  • 4+ года hands-on React, желательно TypeScript.
  • Глубокие знания JavaScript/ES6+, HTML5, CSS3 и Web APIs.
  • Responsive design systems и CSS-in-JS, например Tailwind.
  • REST/GraphQL APIs, WebSockets и real-time data handling.
  • Git, CI/CD pipelines и agile collaboration tools.
  • Знакомство с Jest или Cypress.

БУДЕТ ПЛЮСОМ

  • Microfrontend или monorepo architectures.
  • Глубокое понимание design systems и масштабируемой component architecture.
  • Интеграция third-party identity/auth systems: SSO, OAuth2.
  • Next.js, SSR/SSG и hybrid rendering strategies.
  • Внимание к UX polish, animations и interaction design.
  • Отличная письменная и устная коммуникация с технической и нетехнической аудиторией.

Обязанности могут со временем меняться. После финального интервью Xsolla может проводить background checks в рамках закона; персональные данные обрабатываются конфиденциально и не продаются внешним сторонам.
