В Rockstar Games мы создаём развлекательные продукты мирового уровня.

Станьте частью команды, работающей над одними из самых масштабных и вдохновляющих творческих проектов во всей индустрии развлечений — в инклюзивной, мотивированной среде, где можно учиться и сотрудничать с одними из самых талантливых специалистов отрасли.

Rockstar ищет талантливого Software Engineer с сильным интересом ко всем низкоуровневым технологиям, благодаря которым работает современная видеоигра, для поддержки creator platforms Cfx.re, включая FiveM и RedM. Как участник команды вы должны обладать критическим и творческим взглядом и уметь предлагать инновационные решения сложных проблем. Если вам нравится понимать, как любимые игры действительно устроены «под капотом», мы будем рады вашей заявке.

Это штатная постоянная позиция с полной занятостью и работой из офиса в уникальной студии разработки Rockstar в центре Лондона.

ЧЕМ МЫ ЗАНИМАЕМСЯ

  • Команда Rockstar Creator Platform предоставляет технологическую платформу, позволяющую игрокам пользоваться контентом сообщества на полностью кастомизированных dedicated servers, где создатели могут разрабатывать собственные game modes и другие modifications на различных scripting languages.
  • Мы создаём технологии, инструменты и решения, улучшающие creator experience и позволяющие сообществу создавать и делиться практически любыми вообразимыми experiences.

ОБЯЗАННОСТИ

  • Поддерживать и улучшать существующие и новые codebases, обеспечивая высокие стандарты качества, стабильности и эффективности совместно с cross-functional teams.
  • Поддерживать software release processes в нескольких branches, координируясь с production и engineering для готовности и высокого качества.
  • Помогать выявлять, приоритизировать и устранять критические проблемы, координируя своевременные fixes при сохранении общей стабильности систем.
  • Вести release planning, deployment и rollback procedures.
  • Поддерживать и улучшать build, test и release automation pipelines для улучшения development workflows и надёжности deployment.
  • Мониторить platform health, performance metrics и operational KPIs после релиза, помогая устранять проблемы и обеспечивать continuous improvement.
  • Работать между Creator Platform и более широкими development teams Rockstar, создавая надёжные решения сложных software challenges.

ТРЕБОВАНИЯ

  • 5+ лет опыта в software development team на C++.
  • Понимание основ computing и связанной терминологии.
  • Способность работать с крупными codebases, охватывающими разные области, и понимать риски предлагаемых изменений.
  • Отличные навыки решения проблем с акцентом на debugging C++ code.
  • Понимание особенностей memory layout, включая padding и cache efficiency.
  • Аналитические навыки для измерения system performance, memory use и др., а также коммуникационные навыки для выработки решений.
  • Опыт source control workflows, включая branch management, code integration, conflict resolution и поддержание стабильных development practices.
  • Уверенное владение GitLab и/или GitHub, включая их CI/CD systems.
  • Способность позитивно сотрудничать с другими подразделениями во всех студиях Rockstar.
