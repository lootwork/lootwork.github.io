With multiple awards to our name, Larian Studios has proven that we’re dedicated to delivering high-quality role-playing games. As we move on to new projects, the studio that brought you Baldur’s Gate 3 & Divinity: Original Sin 2 is looking for a Gameplay Programming Intern to join the team and help us in crafting the high caliber games our fans have come to expect.

REQUIREMENTS

  • Solid knowledge of C++
  • Strong understanding of basic C++ concepts (types, OOP, memory management, etc.)
  • Ability to write robust code without infinite loops or memory leaks
  • Portfolio of personal C++ project(s) (with source code), not older than 2 years
  • Projects must be personal work (university coursework will not be considered)
  • Applications without coding examples will not be considered
  • Open-minded and willing to experiment and iterate on features
  • Good communication skills in English
  • Passion for making and playing great games

RESPONSIBILITIES

  • Collaborate with developers on real gameplay systems
  • Actively participate in game production as part of the technical creative team
  • Design, develop, and support gameplay systems for the RPG (including code architecture)
  • Work on all aspects of gameplay system implementation
  • Cooperate closely with other departments to implement required game components
  • Collaborate with UI designers to implement in-game UI features
  • Write robust, maintainable, and high-quality code

We are looking for highly motivated individuals with ever-evolving skillsets and passion for player experience. If you want to contribute to making amazing RPG experiences, we would love to hear from you.
