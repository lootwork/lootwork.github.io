Larian Studios, обладатель множества наград и создатель Baldur’s Gate 3 и Divinity: Original Sin 2, ищет Gameplay Programming Intern, который присоединится к команде и поможет создавать игры высокого уровня, которого ждут наши фанаты.

ТРЕБОВАНИЯ

- Хорошее знание C++.

- Сильное понимание базовых концепций C++: types, OOP, memory management и т. д.

- Умение писать надёжный код без infinite loops и memory leaks.

- Портфолио личных C++ проектов с source code не старше 2 лет.

- Проекты должны быть личной работой; университетские coursework-проекты не рассматриваются.

- Заявки без примеров кода не рассматриваются.

- Открытость к экспериментам и итерациям над features.

- Хорошая коммуникация на английском.

- Любовь к созданию и игре в отличные игры.

ОБЯЗАННОСТИ

- Сотрудничать с разработчиками над реальными gameplay systems.

- Активно участвовать в game production как часть технической creative-команды.

- Проектировать, разрабатывать и поддерживать gameplay systems RPG, включая code architecture.

- Работать со всеми аспектами реализации gameplay systems.

- Тесно сотрудничать с другими подразделениями при внедрении необходимых игровых компонентов.

- Работать с UI designers над внутриигровыми UI features.

- Писать надёжный, поддерживаемый и качественный код.

Мы ищем высокомотивированных людей с постоянно растущими навыками и страстью к player experience. Если вы хотите помогать создавать выдающиеся RPG, будем рады вашему отклику.
