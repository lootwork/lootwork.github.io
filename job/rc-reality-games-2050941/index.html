Monopoly World выходит на глобальный рынок, и мы ищем талантливого Data Analyst, который поможет превращать данные в применимые инсайты, формирующие будущее игры. Это возможность стать частью яркого и влиятельного проекта, который охватит игроков по всему миру.

Эта роль подчиняется Head of Analytics. Это full-time позиция с работой из офиса в знаковом здании железнодорожного вокзала в Кракове.

Если вам нравится решать сложные задачи, вы любите работать с данными и хотите стать частью команды, расширяющей границы мобильного гейминга, — это возможность для вас.

Присоединяйтесь к нам и помогите создать нечто действительно инновационное, оставив свой след в одной из самых известных игр всех времён.

Давайте создадим что-то невероятное вместе! Посмотрите наш трейлер и узнайте, что вас ждёт! 🚀🎥

Ключевые обязанности

  • Анализировать и моделировать данные, предоставляя практические инсайты для game design и monetization strategies.
  • Разрабатывать и поддерживать data pipelines и работать с большими наборами данных, находя значимые закономерности.
  • Сотрудничать с Game Designers и Engineers для создания data-driven решений.
  • Выполнять web scraping и взаимодействовать с REST API для сбора и получения данных.
  • Работать с BigQuery SQL для запросов и обработки игровых данных в аналитических целях.
  • Проектировать и запускать симуляции для поддержки разработки Free-to-Play мобильных игр.
  • Постоянно отслеживать KPI и предлагать улучшения на основе анализа данных.
