Who is SkyBox Labs?

Recognized as one of BC's Top Employers (2025), SkyBox Labs is a game development studio that works on some of the world’s most iconic games. The studio is currently working on projects in the Minecraft universe, supporting the dev team at Bungie on Destiny 2, supporting development of Fallout 76, in addition to work on unannounced IP. Since our inception in 2011, SkyBox Labs has evolved from a small team of eight individuals to a fully established team of Engineers, Artists, Animators, Designers, Producers, and more. Come join our hybrid team in our Burnaby, BC studio today!

PLEASE NOTE: At this time, we are only able to hire candidates who are legally eligible to work in Canada and reside within Canada.

Interested? Let’s talk about what we’re hiring for

SkyBox Labs is looking for a Senior UI/UX Engineer to join our team on an ambitious AAA co-development project set within a highly anticipated universe.

Working in close collaboration with our partner studio, you'll play a key role in implementing performant, responsive in-game UI and HUD systems using cutting-edge UE5 technology. As part of our specialized engineering group, you’ll collaborate with UI/UX designers, artists, technical designers, and core software engineers to build solid underlying UI architecture for features ranging from dynamic HUDs and map systems to settings menus and accessibility integrations.

Using UE5’s toolset and your own technical chops, you'll tackle real-world runtime, optimization, and architectural challenges. This role is built for proactive problem solvers: you'll thrive here if you enjoy taking high-level, open-ended requirements, asking the right questions, figuring out the technical puzzle, and driving practical solutions forward.

This team works in a hybrid capacity, with three days a week at our studio in Burnaby, BC.

A SNAPSHOT OF YOUR ROLE

  • Implement Performant UI Systems: Architect, build, and optimize responsive runtime UI and in-game HUD features within Unreal Engine 5.
  • Cross-Discipline & Co-Dev Collaboration: Work closely with technical designers, UI designers, artists, and engineering leads—both internally and with partner teams—to translate creative direction and feature requests into robust technical solutions.
  • Bridge Gameplay & UI: Build the underlying frameworks and data flows connecting gameplay logic to user interfaces in a clean, scalable manner.
  • Core Feature Support: Support development across player-facing interfaces, including interactive maps, HUD elements, options menus, and accessibility features.
  • Proactive Problem-Solving & Communication: Navigate high-level design concepts, incomplete specs, and open-ended feature requests with autonomy—taking ownership to investigate technical paths, communicate proactively across disciplines to resolve ambiguity, and deliver solid results.

SOUND LIKE YOU? THIS IS WHAT WE’RE LOOKING FOR

  • 7+ years of software engineering experience in game development, with a primary focus on UI systems and user interfaces.
  • Unreal Engine 5 Experience: Hands-on development experience in UE5 with a strong practical understanding of its UI frameworks.
  • Core UI Tech Stack: Hands-on experience working with key Unreal UI technologies, including Slate, UMG, MVVM / View Models, and CommonUI
  • Core C++ Foundations: Strong fundamental C++ programming, memory management, data structures, and object-oriented design skills.
  • Engine-Level C++ Proficiency: Proven experience applying core C++ concepts within Unreal Engine’s framework, architecture, and macro ecosystem.
  • Self-Motivated & Autonomous Mindset: Comfort operating in an environment where solutions aren't always pre-defined. You enjoy rolling up your sleeves, digging into high-level problems, and finding the answers proactively.
  • Collaborative Communication: Strong teamwork skills and the adaptability to work effectively within a co-development environment across artists, designers, and engineers.

Nice-to-Haves

  • Shipped Unreal Titles: Experience shipping a game built in Unreal Engine with a focus on UI/UX systems.
  • Console & Compliance Experience: Familiarity with building and optimizing UI for console platforms alongside PC support (addressing controller navigation, layout compliance, and platform performance).
  • Input Architecture: Experience working with Unreal’s Enhanced Input system and handling complex multi-device input mappings.
  • UI Profiling & Performance: Experience using profiling tools (e.g., Unreal Insights, CPU/GPU trace tools) to diagnose and fix UI performance overhead.…
