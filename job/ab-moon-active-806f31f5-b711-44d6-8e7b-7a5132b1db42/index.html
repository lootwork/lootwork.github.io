Moon Active — одна из ведущих mobile game companies мира. Наши команды используют современные технологии для создания увлекательных интерактивных игр, которыми наслаждаются миллионы людей. Мы создаём захватывающие развлечения для игроков по всему миру и гордимся качественными casual games, помогающими людям взаимодействовать друг с другом.

Playable Ads — интерактивные мини-игры, которые используются для вовлечения и привлечения новых пользователей к скачиванию и игре в наши проекты.

В роли Game Designer вы будете отвечать за game design и полировку game mechanics и game-flows наших playable ads, а также тестировать их и получать insights на основе performance.

Обязанности

  • Проектировать уровни для наиболее эффективных playable ads ведущих игр, чтобы заинтересовать, вовлечь и мотивировать новых игроков скачать наши проекты.
  • Исследовать и разрабатывать инновационные game mechanics для playable ads.
  • Тесно работать с game developers и давать конструктивный feedback по mechanics и experience playable ads.
  • Анализировать performance data для оптимизации game mechanics и conversions.
  • Сотрудничать с game design team над улучшением content pipeline и процессов.
  • Следить за трендами и best practices mobile game advertising.
  • Поддерживать и сотрудничать с командой с точки зрения level design: Production, QA, Art, Game Design и др.

Требования

  • Опыт product management role в casual gaming или 2+ года опыта level design и game mechanics для casual mobile games.
  • Сильная любовь к играм, особенно casual mobile games.
  • Позитивное творческое мышление и увлечённость level design craft, подтверждённые релевантным портфолио.
  • Хорошее понимание game design methodologies и актуальное знание casual audience, casual game markets и player motivations.
  • Отличные interpersonal skills для чёткой и эффективной передачи feedback и design ideas.
  • Сильная самостоятельная work ethic и способность эффективно работать в agile team environment.
  • Способность интегрировать feedback команды в свою работу, учиться на нём и развиваться в роли.
