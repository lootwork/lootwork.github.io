Что предстоит делать

  • Work in a cross-functional agile team and be responsible for designing, developing, and evolving systems that validate and improve the performance, scalability, and reliability of backend services running on AWS
  • Design and implement performance and reliability strategies for our core backend systems, including defining service-level expectations (latency, throughput, error rates) and validating them under realistic conditions
  • Build frameworks and tooling to simulate real-world production scenarios, including multi-service interactions, high concurrency, and network variability
  • Develop and maintain load, stress, and endurance testing systems, integrated into CI/CD pipelines to detect regressions before production
  • Analyze system behavior using metrics, logs, and distributed tracing, identifying bottlenecks and driving improvements across services
  • Define and drive the adoption of a comprehensive testing strategy across backend services, including unit tests, integration tests (leveraging test containers), and clear guidelines for when and how each layer should be applied
  • Enable a shift-left quality culture by building tooling, patterns, and best practices that allow teams to detect regressions early
  • Collaborate with feature teams to improve system design, resilience, and scalability, acting as a force multiplier across backend engineering
  • Leverage AI tools and agentic workflows in your daily work — from tech planning, code generation and review to exploring novel solutions.

Кого мы ищем

  • Highly experienced as a software engineer working on backend systems, distributed systems (operating in the Public Cloud) , or other relevant areas with a strong passion for testing and performance testing
  • Professional experience building and operating highly available, scalable backend systems, such as MMO game servers, high-traffic services, or real-time applications
  • Experience with Python and its ecosystem, including familiarity with asynchronous programming, concurrency, and performance considerations
  • Solid understanding of distributed systems, including:
  • service-to-service communication, including event driven architectures
  • failure modes and resilience patterns
  • stateful vs stateless architectures
  • Experience designing and implementing highly scalable and low-latency systems, including use of Redis, DynamoDB, or similar technologies
  • Strong understanding of API design (REST/gRPC) and ability to write efficient, low-latency code
  • Experience working in cloud environments (AWS) and familiarity with containerized deployments (Docker)
  • Familiarity with CI/CD pipelines, automated testing, and infrastructure automation
  • Experience using observability tools (Datadog, logs, tracing) to analyze and debug system behavior
  • Hands-on experience working with AI-assisted development tools (e.g. GitHub Copilot, Codex, Claude Code) and an understanding of how agentic workflows can augment engineering productivity.

Дополнительный плюс

  • Experience with load testing frameworks like K6, Locust
  • Understanding of SRE concepts like: SLA, SLO, error budgets
  • Experience with load testing messaging systems such as NATS;
  • Experience with relational databases likeMySQL.
  • Familiarity with Infrastructure-as-Code (preferred Terraform) for managing infrastructure deployment
  • Understanding of network infrastructure and cloud networking concepts, such as VPC, Subnet, Security Groups, and Load Balancing
  • Understanding modern observability stacks like Kibana / Datadog to perform log querying and dashboards
