Описание вакансии

Развивать IT infrastructure через проектирование, внедрение и optimization automation solutions для operating systems и hybrid cloud environments. Эта роль отвечает за создание tools и automations, устраняющих root causes и улучшающих ежедневную работу Systems Engineering team. Общая цель — повысить operational efficiency, освободить время для стратегических проектов и внедрить современные self-service IT solutions по всей организации.

Обязанности

  • Проектировать, тестировать, внедрять и поддерживать advanced scripts — например PowerShell, Python, Bash — и applications, автоматизирующие administrative и operational tasks в IT infrastructure.
  • Анализировать области с высоким automation potential и вести проекты, повышающие velocity команды, включая optimization существующих tools.
  • Разрабатывать, интегрировать и управлять tools для Infrastructure as Code (IaC), proactive monitoring и поддержки CI/CD practices.
  • Работать с Systems Engineering team и делиться знаниями по automation strategies и tools.
  • Создавать и поддерживать technical documentation по внедрённым automation tools и processes.
  • Тесно работать с ITSECOPS и другими internal teams, собирать requirements и успешно внедрять automation solutions.
  • Постоянно улучшать processes и tools, исследуя новые технологии и внедряя инновационные industry best practices в IT automation.

Квалификация

  • Не менее 3 лет опыта IT process automation, programming или advanced systems administration.
  • Продвинутое знание как минимум одного scripting language, например Python или PowerShell.
  • Подтверждённый опыт проектирования, создания и deployment automation tools в production environments.
  • Хорошее понимание software engineering principles, version control systems (Git, Perforce) и практический опыт CI/CD tools и concepts.
  • Опыт administration operating systems (Windows Server, Linux) и cloud platforms, например AWS, GCP.
  • Хорошее понимание Ansible или других configuration-management tools.
  • Опыт Terraform или аналогов.
  • Знание monitoring tools вроде Zabbix или Prometheus и visualization platforms вроде Grafana.
  • Сильно развитое аналитическое мышление и способность самостоятельно диагностировать и решать сложные technical challenges.
  • Отличные communication и collaboration skills и открытость разным working styles и взглядам.
  • Инициативность, проактивность, ориентация на результат и высокие стандарты качества работы.
  • Рабочее владение польским и английским.
