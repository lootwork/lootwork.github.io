Локация: Кембридж, Великобритания. Возможны гибкие варианты работы, включая преимущественно remote. Кандидат должен жить на комфортном расстоянии от офиса, чтобы при необходимости приезжать onsite.

У вас есть опыт detection и incident response, инженерное мышление и интерес к улучшению tools, automation и процессов расследования угроз?

В роли Senior Detection & Response Engineer в Cyber Security team вы будете укреплять capability Jagex по detection и incident response в студийной и игровой среде. Вы возьмёте ownership эскалированных security investigations и будете выходить за рамки обычной обработки alerts: понимать, что произошло, оценивать impact и обеспечивать эффективный response.

Помимо hands-on расследований, вы будете развивать tooling, detection logic, automation, runbooks и процессы, позволяющие эффективнее находить угрозы и реагировать на них. Работая в hybrid environment и вместе с внешней security operations-командой, вы будете помогать фокусировать monitoring и detection strategy на действительно важных сигналах и рисках.

Чем вы будете заниматься

  • Руководить расследованиями эскалированных security events и incidents: формировать гипотезы, собирать evidence и определять root cause и impact.
  • Создавать и оптимизировать detection rules, queries и monitoring logic для cloud, endpoint, network и application environments.
  • Разрабатывать tooling и automation для улучшения security telemetry, alert enrichment, investigation workflows и response times.
  • Проводить threat hunting на основе adversary behaviours, TTP и frameworks вроде MITRE ATT&CK и использовать результаты для security controls и detections.
  • Создавать и постоянно улучшать incident runbooks, playbooks и detection processes на основе реальных расследований.
  • Работать с внешним SOC и внутренними Engineering-командами над улучшением monitoring coverage, расследованием escalations и постоянным развитием detection & response capability.
  • Позиция предполагает участие в on-call rotation.

Что мы ищем

  • Практический опыт расследования security incidents, включая формирование investigation hypotheses, сбор artefacts и анализ endpoint, network и application data.
  • Сильное рабочее знание SIEM и security monitoring tools, включая способность писать и развивать queries для сложных расследований.
  • Понимание tactics, techniques and procedures злоумышленников, offensive security concepts и принципов MITRE ATT&CK.
  • Практическое знание cloud environments и security controls и способность применять detection и incident response practices в hybrid infrastructure.
  • Опыт разработки detection logic, runbooks, automation или security tooling; знание scripting, например PowerShell или Python, будет преимуществом.
  • Знание internals операционных систем и forensic investigation в Windows, macOS или Linux.
