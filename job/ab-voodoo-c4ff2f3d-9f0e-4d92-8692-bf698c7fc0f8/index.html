关于 VOODOO

Voodoo 是一家总部位于巴黎的移动游戏与应用公司，成立于 2013 年，是全球超休闲品类的头部发行商。旗下有 Paper.io http://Paper.io、Mob Control、Hole.io http://Hole.io、Helix Jump、Aquapark.io http://Aquapark.io 等全球爆款游戏，以及 BeReal、Wizz 等热门社交应用。公司拥有 1000+ 名员工，累计下载量超过 80 亿次，活跃用户超过 2 亿。

我们正在中国组建创意团队，与巴黎的试玩策略、营销买量团队直接协作。这个岗位是中国团队的首位试玩开发，负责 Mob Control 等核心产品的 2D/3D 试玩广告。

岗位职责

1. 根据创意 brief，独立开发 2D/3D 试玩广告（H5），从玩法原型做到最终交付，能独立攻克复杂 3D 玩法。

2. 与巴黎试玩策略团队协作，按反馈快速迭代。

3. 适配主流广告平台规范，优化包体和性能。

4. 沉淀可复用的模板和工具，用 AI 提升开发效率。

任职要求

1. 有多年游戏客户端、H5 小游戏或试玩广告开发经验，有在广告平台上线投放过的试玩作品，以作品和实际能力为准。

2. 精通 JavaScript / TypeScript，熟悉 HTML5、Canvas、WebGL。

3. 有 3D 试玩或 3D H5 游戏开发经验，熟练使用 Cocos Creator 或 Three.js 等 H5 引擎。

4. 熟悉主流广告平台的试玩规范，有包体压缩、资源加载、内存和渲染优化经验。

5. 有 AI 辅助开发的实操经验（Cursor、Claude Code 等）。

6. 有游戏感，理解玩法的乐趣点和用户心理；沟通主动，能独立推进项目。

7. 具备良好的英语读写能力，能处理日常沟通（会议、文档、留言）；口语流利者优先。

加分项

- 熟悉 Shader、粒子特效或 3D 性能优化

- 做过消耗领先的爆款试玩，或有休闲、益智、中度游戏项目经验

- 做过关卡编辑器、批量迭代工具或自动化打包流程

- 能自己处理简单的美术、动画或特效

投递要求

请附可玩 Demo 链接或演示视频，并说明你负责的部分；附上投放数据更佳。

我们提供

- 参与全球头部休闲游戏的试玩制作，直接看到海外投放数据

- 作为中国团队早期核心成员，参与团队从 0 到 1 的搭建
