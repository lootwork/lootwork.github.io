Job Description

  • Responsible for the development and optimization of iOS/macOS applications.
  • Build high-performance, stable applications using Swift and SwiftUI (or AppKit).
  • Collaborate with product and design teams to deliver excellent user experiences.
  • Continuously optimize code architecture to improve application performance and maintainability.

Требования

  • Bachelor's degree or above from a full-time university program; Computer Science major preferred.
  • 3+ years of experience in iOS/Mac application development, with a solid understanding of iOS/macOS platform characteristics.
  • Proficient in Swift programming language, with strong knowledge of the SwiftUI or AppKit framework.
  • Strong command of iOS/Mac platform technologies including memory management, thread communication, and network communication.
  • Demonstrated ability in maintaining clean code style and designing sound application architecture.
  • Proficient in AI coding tools (e.g., Codex, Claude Code, etc.) with the ability to effectively boost development efficiency.
  • Candidates with experience in independently developing or leading projects are preferred.
