XE (Experience Engineering) Dept. проектирует и эксплуатирует продукты от внутренних analytics dashboards до global external/web/event services. Новая роль — с нуля построить unified mobile app на KID (KRAFTON ID), связывающее game ecosystem KRAFTON с пользователями. Старт — Native + Hybrid WebView для быстрого запуска, затем постепенный переход к pure Native. Разработчик будет единолично вести mobile-app domain при наличии отдельных PM/backend roles.

Миссия

  • Архитектура и development нового iOS/Android app.
  • KRAFTON ID authentication, user profiles, game records и preference data integrations.
  • Объединение множества KRAFTON service modules в одном app.
  • Архитектура Hybrid(WebView) integrations и roadmap перехода к pure Native.
  • Client-side data management и UI/UX для personalized content.
  • Backend API integration и app state-management architecture.
  • App Store/Google Play releases и CI/CD.

Требования

  • 7+ лет mobile-app development.
  • React Native или Flutter cross-platform design/development/shipping.
  • Опыт построения приложения с нуля до store release.
  • Hybrid/WebView и Native↔WebView bridge communication.
  • REST APIs и state-management patterns.
  • OAuth/authentication integration.
  • App Store/Google Play release/review process.
  • Сильная коммуникация с PM и backend engineers.
  • Возможность зарубежных поездок.

Будет преимуществом

Kotlin/Jetpack Compose, Swift/SwiftUI, large B2C/global apps, gaming/community apps, Super App/Mini App integration, personalization/recommendations, push/deep/dynamic links, Fastlane/Bitrise, Crashlytics/Firebase Analytics, Kotlin Multiplatform, AI/LLM tools.
