О position

We're looking for a QA Analyst to join our Quality team and help ensure the quality of Fanatee's mobile game portfolio. You'll work closely with developers, product, and design to catch issues before they reach our players, and help build a more efficient testing process as our games evolve.

Что предстоит делать

  • Execute manual and exploratory testing across our game portfolio, covering functional, regression and edge-case scenarios.
  • Identify, document and report bugs clearly, with reproduction steps, severity and impact, so the dev team can act fast.
  • Build and maintain test plans and checklists for critical game flows.
  • Support test automation efforts, contributing to scripts and coverage under guidance from senior QA.
  • Use AI-assisted QA tools (test case generation, log summarization, bug triage support) to speed up repetitive work, always validating results critically.
  • Track testing tasks and bugs in our project management tools (Jira/Azure DevOps), keeping status updated.
  • Collaborate directly with developers to clarify, prioritize and follow up on reported issues.
  • Test across different devices, OS versions and stores (iOS/Android) to catch platform-specific issues.

What you’ll need

  • Bachelor's degree in Computer Science, Information Systems, Engineering, or related fields (or equivalent practical experience) .
  • Understanding of software testing fundamentals (test cases, regression, exploratory testing).
  • Strong attention to detail, able to spot small, non-obvious inconsistencies in gameplay, UI or text.
  • Good organizational skills to manage multiple test cycles at once.
  • Programming knowledge (C#) with hands-on experience writing and maintaining automated tests. Not senior-level, but able to build test scripts independently, not just follow a script someone else wrote.

Будет плюсом

  • Experience with Unity or mobile game development.
  • Familiarity with AI-powered testing tools (test case generation, automated regression, visual QA).
  • Experience with test automation frameworks
  • Previous QA experience in mobile games or apps.
  • Comfortable reading English (docs, tools, error logs).
  • Proactive. Flags risks and suggests process improvements without being asked.
  • Comfortable with repetitive tasks without losing rigor or focus.
  • Collaborative, with strong communication skills to work closely with developers under tight release cycles.
  • Curious and adaptable, comfortable with fast-changing priorities typical of game development.
  • Genuine interest in mobile games.
  • Certification iSTQB
