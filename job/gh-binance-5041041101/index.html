О роли

We are looking for an experienced Infrastructure Security Engineer with strong expertise in securing Linux systems, cloud infrastructure, and containerized environments.

The ideal candidate should have deep hands-on experience in Linux system security, vulnerability management, cloud security architecture, and infrastructure security engineering. This includes system hardening and patch management, kernel and core package vulnerability assessment, system behavior monitoring, security logging and telemetry, application execution control (allowlisting), and container security.

You will be responsible for designing and building scalable security solutions to strengthen Binance's infrastructure security posture. In addition, you will work on emerging security challenges associated with AI applications and AI agents, leveraging automation and AI LLM-based technologies to improve security detection, analysis, and response capabilities.

Что предстоит делать

  • Design, implement, and continuously improve security controls and solutions to protect Binance's infrastructure across cloud and on-premises environments.
  • Develop and maintain security infrastructure and platforms, including Bastion Hosts, CVE Detection and Management Systems, Infrastructure Security Monitoring, and Alerting Systems.
  • Build automated vulnerability detection, assessment, prioritization, and remediation workflows covering operating systems, kernels, core packages, containers, and cloud infrastructure.
  • Leverage system telemetry, audit logs, network traffic, and security analytics to identify suspicious activities, potential compromises, and infrastructure-level threats.
  • Conduct infrastructure-level penetration testing, security assessments, and attack simulations to identify security weaknesses and drive remediation.
  • Implement security controls for cloud infrastructure and containerized environments, including IAM, network segmentation, secrets management, workload isolation, and runtime protection.
  • Develop security solutions to protect internal AI applications, AI agents, and supporting infrastructure against threats such as prompt injection, tool misuse, privilege escalation, and sensitive data exfiltration.

Кого мы ищем

  • Deep expertise in GNU/Linux systems, including system hardening, patch management, process and behavior monitoring.
  • Practical software development experience in Python, Go, or JavaScript.
  • Strong hands-on experience with AWS or other major cloud platforms, including cloud security architecture and related security service such as IAM, AWS GuardDuty, AWS Config, CloudTrail.
  • Hands-on experience with Docker and Kubernetes security, including container isolation, runtime protection, image security, and Kubernetes RBAC.
  • Solid understanding of vulnerability management, privilege escalation, access control, endpoint security, system auditing, and infrastructure attack and defense techniques.
  • Familiarity with security technologies and practices such as secrets management, workload identity, network segmentation, and runtime threat detection.
  • Relevant hands-on experience in using LLMs and coding agents in your projects, and have applied them to at least one security task (e.g., code review, recon, or analyzing a vulnerability).

Будет плюсом

  • Experience with endpoint detection and response (EDR), application allowlisting, file integrity monitoring, and host-based intrusion detection.
  • Experience with Linux security technologies such as eBPF, Linux Audit Framework, SELinux, AppArmor, seccomp, and kernel security mechanisms.
  • Good understanding of LLM-based applications and AI agent architectures, including prompt engineering, prompt injection, tool-calling security, and AI application security. Practical experience in securing LLM applications or AI agents.
