О Monopoly World

Monopoly World is a location-based mobile game that turns the real world into a dynamic Monopoly board. Players walk, buy, trade, and build in real-world cities using real-time geolocation data and AI-driven personalization.

Come build something incredible with us! Check out our trailer and see what’s in store! 🚀🎥

As we prepare for full monetization launches across Europe and beyond, we're seeking a Senior QA Specialist who can help us ensure a seamless, high-quality gameplay experience across thousands of device variations, real-world environments, and server connections.

This is a critical role where you’ll directly influence the player experience, game stability, and market readiness at a global scale.

О роли

As a Senior QA Specialist on the Monopoly World team, you will own end-to-end quality control across mobile platforms (Android/iOS). You’ll work closely with developers, designers, product managers, and data engineers to proactively identify, track, and resolve gameplay, UI/UX, geolocation, performance, and network issues before players ever encounter them.

You’ll lead testing strategies, implement best practices, mentor junior testers (where applicable), and ensure we ship features, updates, and live operations events with maximum reliability.

It's a full-time, work-from-office position in the historical railway station building in Kraków.

Основные обязанности

  • Test Planning & Execution: Create and manage detailed, scalable test plans for new features, releases, live ops events, and patches.
  • Gameplay Testing: Test core mechanics (movement, property buying, trading, leaderboard, in-game events) across different real-world locations and network conditions.
  • Mobile Device Compatibility: Validate builds across a wide range of mobile devices (flagship, mid-tier, low-end) on Android and iOS.
  • API Testing: Carry out functional and end-to-end tests of the REST API used by the game client in external tools, such as Postman or cUrl.
  • Unity-Specific Testing: Identify, reproduce, and document bugs related to Unity game engine components, asset loading (Addressables), UI/UX flows, and backend services.
  • Automation Collaboration: Work alongside engineers to identify areas suitable for test automation (e.g., smoke tests, login flows, UI validation).
  • Regression and Release Testing: Ensure new code doesn't break existing functionality across different game modules.
  • Network and Geolocation Testing: Simulate different network conditions (3G, 4G, WiFi loss) and verify real-world geolocation behavior (GPS drift, spoofing detection).
  • Bug Reporting & Tracking: Write clear, reproducible bug reports and help prioritize issues based on impact and severity.
  • Cross-Team Communication: Work with designers, engineers, and PMs to deliver builds on time and ensure top-quality player experiences.
