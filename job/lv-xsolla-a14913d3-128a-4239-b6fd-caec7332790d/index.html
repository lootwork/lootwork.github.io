О ВАС

Мы ищем Principal Engineer, который возьмёт архитектурную ответственность за agent-readable платформу Shop Builder. Это самая senior individual contributor роль в DevX and AI team, и решения, которые вы примете — какие surfaces открыть, какие форматы поддержать и какие стандарты установить — определят платформу на годы.

Вы не manager, но ваше влияние распространяется на всю организацию. Вы определяете, как разработчики и AI agents взаимодействуют с базовыми возможностями Shop Builder: UI as Data, custom blocks, themes, data binding, catalog, payments. Вы — технический авторитет по тому, что и каким образом платформа предоставляет наружу, и лично работаете с наиболее сложными частями системы.

О КОМПАНИИ И ПРОЕКТЕ

Xsolla — глобальная payments и commerce платформа для игровой индустрии, которой пользуются тысячи publishers для монетизации, дистрибуции и эксплуатации игр по всему миру. Shop Builder — storefront-платформа Xsolla: от простых catalogs/webshops до полностью custom headless storefronts на backend Xsolla.

DevX and AI team отвечает за public APIs, документацию и AI-функции, предоставляющие разработчикам и AI agents полный набор возможностей для кастомизации и расширения Shop Builder. Это новая команда из семи человек, созданная для закрытия реального пробела: раньше ни одна выделенная команда не отвечала за developer surface end-to-end.

ОБЯЗАННОСТИ

  • Полностью отвечать за technical architecture agent-readable Shop Builder: какие API открывать, в каком формате и через какие surfaces — REST, SDK, MCP, CLI.
  • Определять interface contracts для LLM и разработчиков — React component APIs, custom block schemas, theme tokens, data binding formats — и поддерживать их с уровнем строгости public API.
  • Спроектировать и возглавить создание MCP server, позволяющего AI agents вроде Claude Code и Cursor строить, deploy и эксплуатировать Shop Builder storefronts end-to-end без участия editor.
  • Спроектировать CLI и local development environment: scaffolding проектов, локальные итерации, preview изменений и push в production.
  • Определить deploy, versioning и rollback модель для developer-published контента — custom blocks, themes, layouts.
  • Спроектировать sandbox и preview environments, чтобы agents и developers могли экспериментировать, не затрагивая live partner sites.
  • Задать стандарт документации для LLM и людей как равноправных пользователей; поддерживать единые canonical sources и публиковать их во все surfaces: CLI help, dev docs, MCP tool descriptions, AI context.
  • Руководить архитектурой eval harness: как измерять корректность LLM-generated block, theme или layout до релиза.
  • Сотрудничать с Principal/Staff Engineers в payments, auth, live ops и catalog, объединяя inbound capabilities в цельные developer-facing surfaces.
  • Быть technical bar-raiser команды: задавать code standards, review критических implementation decisions и менторить Tech Lead и engineers.
  • Участвовать в найме и формировать техническую культуру команды с первого дня.

КВАЛИФИКАЦИЯ И НАВЫКИ

  • 10+ лет профессионального engineering-опыта и подтверждённый опыт Staff/Principal engineer, формировавшего platforms, APIs или developer tooling для внешних разработчиков.
  • Глубокая экспертиза public APIs и SDK: versioning strategy, backwards compatibility и developer ergonomics; сформированное понимание того, что делает API удобным или болезненным.
  • Expert-level JavaScript/TypeScript и React — основные interface languages для LLM и разработчиков платформы.
  • Hands-on опыт CLI tooling и local developer workflows: scaffolding, hot reload, file-based config, deploy commands.
  • Хорошее понимание MCP или аналогичных agentic tool-use interfaces и практический опыт инструментов, которые AI agents могут надёжно вызывать.
  • Опыт глобально масштабируемых cloud-систем AWS/GCP, глубокое знание containerization, CI/CD и infrastructure-as-code.
  • Умение писать и проектировать LLM-friendly documentation и API surfaces с пониманием важности token efficiency, predictability и schema clarity наряду с читаемостью для людей.
  • Исключительно сильная technical communication: понятные RFC и ADR, продуктивные architecture reviews, способность объяснять second-order consequences engineering- и business-руководству.
  • Комфортная работа в greenfield-контексте, где структуру нужно создавать, а не наследовать.…
