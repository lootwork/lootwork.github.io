Moon Active — одна из самых быстрорастущих mobile game companies мира, развлекающая миллионы активных пользователей. Штаб-квартира находится в центре Тель-Авива.

Мы ищем талантливого DevOps Engineer. В этой роли вы будете проектировать и эксплуатировать масштабируемые и устойчивые cloud environments, используя продвинутую автоматизацию и AI-based tools для повышения здоровья систем, сокращения ручного вмешательства и оптимизации infrastructure costs.

Обязанности

  • Полностью отвечать за lifecycle платформы Coin Master. Обеспечивать high availability, performance и cost-efficiency в multi-region AWS environment.
  • Проектировать и поддерживать надёжную высокопроизводительную infrastructure через IaC. Фокус — self-healing environments, где AI agents постоянно мониторят состояние и устраняют проблемы в real time.
  • Встраивать security в infrastructure layer. Использовать AI-assisted tooling для проактивного поиска и исправления vulnerabilities в Kubernetes clusters и AWS stack.
  • Создавать tools и services, которые помогают engineering team быстрее выпускать код. Вы будете архитектором платформы, следя за её интуитивностью, scalability и полной automation.

Требования

  • 3+ года DevOps experience. Подтверждённый опыт управления production-ready Kubernetes clusters, AWS infrastructure и high-traffic distributed systems.
  • Опыт интеграции AI tools в ежедневные workflows, включая практическое использование AI agents (Cursor, Claude Code или аналогов) для infrastructure automation, planning и debugging.
  • Большой опыт управления несколькими AWS accounts в разных регионах и уверенное владение Lambda, CloudFront, SQS, VPC, IAM и другими services.
  • Сильное понимание cloud cost optimization в масштабе через architectural design и automated resource management.
  • Глубокое владение современными CI/CD platforms: GitHub Actions, Jenkins, ArgoCD.

Преимущества

  • Опыт LLM orchestration (LangChain, LangGraph) или создания внутренних tools/agents, взаимодействующих с cloud APIs для automation operational tasks.
  • Практический опыт Kafka (MSK/Apache Kafka) и high-performance caching layers вроде Redis/ElastiCache.
  • Опыт управления Cloudflare и сложными edge-computing configurations.
