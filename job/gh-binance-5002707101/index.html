Binance is a leading global blockchain ecosystem behind the world’s largest cryptocurrency exchange by trading volume and registered users. We are trusted by 300+ million people in 100+ countries for our industry-leading security, user fund transparency, trading engine speed, deep liquidity, and an unmatched portfolio of digital-asset products. Binance offerings range from trading and finance to education, research, payments, institutional services, and more. Our mission is to increase the freedom of money and financial access for people around the world.

Binance platform provides a large range of different cryptocurrency services to retail users, high net vault individuals, institutions, and enterprise customers. As a platform frontend developer, you must be active in designing and building efficient web applications. You should be self-motivated, and be able to proactively push from the start to finish of each feature.

Обязанности

  • Core Development: Responsible for feature development and architecture optimization of the MPC Wallet Android client, ensuring code quality and maintainability.
  • Security Implementation: Participate in client-side implementation of security-related modules including key management, MPC signing flows, and device binding.
  • Cross-Platform Collaboration: Align interfaces (API/Proto) with iOS, backend, and Web teams to ensure multi-platform consistency and compatibility.
  • Performance Optimization: Continuously optimize app startup speed, memory usage, network requests, and UI rendering performance.
  • Quality Assurance: Write unit and integration tests, participate in code reviews, and drive engineering standards and CI/CD pipeline development.
  • Technical Research: Track new technologies in the Android ecosystem, evaluate and introduce suitable tools and frameworks for the team.

Требования

  • 5+ years of native Android development experience, with a track record of shipping commercial products end-to-end.
  • Proficient in Kotlin (primary language), familiar with Java.
  • Solid command of Android SDK and Jetpack components (Lifecycle, ViewModel, Navigation, Room, WorkManager, etc.).
  • Familiar with Jetpack Compose or traditional View system; capable of independently building complex UI.
  • Familiar with common architecture patterns: MVVM / MVI / Clean Architecture.
  • Familiar with networking frameworks (OkHttp, Retrofit), serialization (Protobuf / JSON), and dependency injection (Hilt / Koin).
  • Familiar with Android security mechanisms: KeyStore, encrypted storage, certificate pinning, code obfuscation / hardening.
  • Good code review habits; familiar with Git workflows (feature branching, PR review).
  • Adept at using AI-assisted tools (e.g., GitHub Copilot, Cursor, ChatGPT) to boost development efficiency; demonstrates an AI-augmented development mindset.
  • Strong communication skills; able to collaborate effectively with multi-platform teams.

Nice to Have(Preferred)

  • Blockchain / Web3 Experience: Understanding of major blockchains (BTC, ETH, Solana); experience with wallet apps or DApps.
  • Cryptography Fundamentals: Understanding of symmetric/asymmetric encryption, digital signatures, key derivation (BIP-32/39/44), MPC/TSS concepts.
  • JavaScript / Cross-Platform Experience: React Native, WebView bridging, JS Bridge development, or familiarity with TypeScript.
  • Gomobile / Go Integration Experience: Experience integrating Go libraries via gomobile (e.g., Go-based MPC core library); understanding of cross-language binding and debugging.
  • Security-Sensitive Product Experience: Experience with financial-grade / custody-grade products; understanding of compliance, audit, and risk control requirements.
  • Android Reverse Engineering & Security Protection: Knowledge of Android cracking, reverse analysis, Hook, Root/Jailbreak detection, anti-debugging, memory protection, and data leak prevention; ability to enhance sensitive data and memory security on rooted or high-risk runtime environments.
  • CI/CD Pipeline Experience: GitHub Actions, Fastlane, automated testing.
  • AI-Assisted Development Practice: Experience integrating LLM / AI Agents into daily development workflows (code generation, code review, automated testing, documentation), or understanding of prompt engineering.
