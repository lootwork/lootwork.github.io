О ВАС

Xsolla ищет Senior Frontend Software Developer в команду, создающую платформу, на которой работают все user-facing experiences. Роль даёт возможность сотрудничать с локальными и международными командами над user-centric software для глобальной аудитории Xsolla и вносить вклад в high-performance frontend решения, которыми пользуются разработчики игр по всему миру. Нужны сильный frontend и e-commerce опыт, способность работать над сложными техническими инициативами и обеспечивать предсказуемый, надёжный delivery.

О КОМПАНИИ

Xsolla — глобальная commerce компания для игровой индустрии. Подробнее: xsolla.com.

ОБЯЗАННОСТИ

  • Вместе с product managers, designers и backend engineers превращать сложные requirements в интуитивный user experience.
  • Проектировать, создавать и развивать масштабируемые high-performance frontend web applications.
  • Участвовать в code review, делиться best practices и поддерживать высокие engineering standards.
  • Вместе с DevOps улучшать CI/CD pipelines, deployment reliability и observability через metrics и monitoring tools.
  • Полностью отвечать за features: requirement refinement, implementation, testing, delivery; оптимизировать loading time, rendering speed и bundle efficiency.
  • Обеспечивать cross-browser и multi-device compatibility, accessibility a11y и usability.
  • Участвовать в modernization, refactoring и continuous performance improvements для scalability и maintainability платформы.
  • Развивать и обеспечивать engineering best practices в coding, documentation, testing и review.
  • Поддерживать сильное automated test coverage и надёжные CI/CD workflows, уменьшающие manual effort и повышающие predictability delivery.
  • Отвечать за operational excellence: incident response, root-cause analysis и долгосрочные reliability improvements.
  • Продвигать scalability, performance, security и observability в architecture/tooling платформы.
  • Выявлять technical risks, оценивать complexity и объяснять trade-offs руководству и стейкхолдерам.

КВАЛИФИКАЦИЯ И НАВЫКИ

  • Не менее 2+ лет в senior frontend title.
  • 7+ лет frontend software development с глубокой экспертизой современных frontend frameworks at scale.
  • Опыт frontend development для e-commerce, gaming или monetization platforms.
  • Большой опыт TypeScript, React, Redux или современных state management libraries.
  • Module federation, component architecture, performance optimization, accessibility, RSC и SSR patterns.
  • Современные CSS frameworks и UX/UI design systems/principles.
  • Понимание microservices architecture и RESTful/RPC-style API integrations.
  • Node.js и MongoDB для server-side functionality.
  • Automated testing Vitest/Jest и E2E Playwright/Cypress.
  • Bundling/compilation: webpack, rollup, vite, esbuild.
  • CI/CD workflows GitLab CI или аналогичные, private registries и secure artifact handling.
  • Способность влиять на technical decisions и вести изменения; leadership experience будет плюсом.
  • Отличные interpersonal и communication skills для cross-functional collaboration.
  • Приверженность качественному коду и постоянному улучшению проектов.
  • Сильное понимание design patterns, testing methodologies и agile development.
  • Bachelor's или Master's degree в Computer Science, Engineering или смежной области.
  • Сильный письменный и устный английский.
