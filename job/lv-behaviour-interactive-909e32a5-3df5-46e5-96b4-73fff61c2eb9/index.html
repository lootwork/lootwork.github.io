Behaviour is looking for a talented Backend programmer (Node.js) with operational skills to work within our Corporate Technologies group that develops and supports the tools game productions teams need in order to deliver outstanding experience to millions of players worldwide. As a member of the Platform team, you will create and maintain tools and services that support player experience, and which rely on advanced CI/CD pipelines and infrastructures, as well as on evolving platforms and technologies that empower developers, reducing the time-to-production of solid features and products.

IN THIS ROLE YOU WILL

  • Design, build, and maintain advanced tools, services, and operational systems that enhance the developer experience.
  • Define technical specifications and requirements before developing new features and services.
  • Diagnose and resolve issues to improve application stability, code quality, and CI/CD pipeline robustness.
  • Collaborate closely with other engineers to deliver scalable, gaming server-compliant services.
  • Develop, execute, and analyze functional and load testing to ensure performance and reliability.
  • Optimize code and system performance while accounting for the live, online nature of game environments.

WHAT WE'RE LOOKING FOR

  • 5 years experience developing backend applications with JavaScript, TypeScript, and Node.js.
  • Good understanding of REST APIs, WebSockets, and modern software architecture principles.
  • Familiarity with CI/CD practices and tools such as GitLab Pipelines, Jenkins, or GitHub Actions.
  • Experience deploying and supporting applications on cloud platforms such as AWS, Azure, or GCP, with exposure to Infrastructure as Code tools like Terraform, Pulumi, or Helm.
  • Knowledge of relational and NoSQL databases, including data modeling and performance considerations.
  • Nice to have: experience with Linux environments, React and/or Angular, server performance optimization, and secure client-server development.
