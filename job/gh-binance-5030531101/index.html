О роли

  • Binance is looking for a hands-on AI Security Engineer to build, ship, and operate security controls for AI-powered applications and autonomous agents — and to apply AI to make security engineering and operations measurably faster and more effective.
  • This is an individual-contributor role. You will own problems end to end at the implementation level: design, code, deploy, monitor, fix. Depth of engineering execution matters more here than org-level strategy or headcount management.
  • You will work closely with Security Engineering, AI Engineering, Infrastructure, and Platform teams to deliver AI-native security capabilities and defend AI systems in production.

Что предстоит делать

AI Agent and Application Security

  • Design and implement security controls for LLM applications, single- and multi-agent systems, and AI-powered services.
  • Secure agent identities and memory, control tool execution and permissions, manage credentials securely, and restrict access to sensitive systems and data.
  • Implement practical defenses against prompt injection, data exfiltration, unauthorized tool execution, malicious dependencies, and AI supply-chain attacks.
  • Build isolation, least-privilege access, human approval gates, and independent verification for high-risk AI actions.

Security Engineering for AI Infrastructure

  • Conduct threat modeling and security reviews across AI infrastructure, model integrations, APIs, and production AI systems.
  • Develop reusable security frameworks, guardrails, automated policy enforcement, and runtime monitoring.
  • Integrate AI security testing and controls into CI/CD pipelines and developer workflows.
  • Strengthen security across model serving, inference APIs, vector databases, data pipelines, and cloud-native AI infrastructure.

AI-Powered Security Tooling

  • Develop AI-powered security tools and automation for threat detection, threat hunting, incident response, vulnerability management, application security, and security assessments.
  • Integrate LLMs, agent frameworks, and AI-driven reasoning into existing security platforms, data pipelines, and operational workflows.
  • Measure and report what the automation actually delivers: detection coverage, detection quality, response time, and manual effort removed.

Adversarial Testing and Resilience

  • Develop and run AI red-teaming, automated adversarial evaluations, and attack simulations for AI applications and agents.
  • Test AI-driven security workflows for resistance to manipulation, false conclusions, and unsafe autonomous actions.
  • Build fallback mechanisms, execution boundaries, auditability, and recovery procedures.
  • Investigate AI-related security incidents, identify root causes, and ship preventive engineering fixes.

Collaboration and Craft

  • Partner with security and engineering teams to identify high-impact automation opportunities and deliver them.
  • Write design docs and engineering standards; review peers' designs and code; share findings and tooling.
  • Raise the team's baseline through reusable components rather than one-off scripts.

Кого мы ищем

  • 5+ years of experience in security engineering, software engineering, infrastructure security, or related technical disciplines, with strong hands-on engineering capability.
  • High agency and strong ownership, with a track record of proactively identifying and solving important problems.
  • Demonstrated experience building and deploying AI/LLM-powered applications, agents, or automation systems in real-world environments.
  • Solid security engineering fundamentals: application security, cloud security, IAM, endpoint security, detection engineering, and secure software development.
  • Strong proficiency in Python, Go, Java, Rust, or similar, with the ability to independently develop and deploy production-quality systems.
  • Practical understanding of modern LLM architectures, agent orchestration, tool calling, RAG, model APIs, and AI development frameworks.
  • Working knowledge of AI-specific threats: prompt injection, data leakage, insecure tool usage, agent privilege escalation, and AI supply-chain attacks.
