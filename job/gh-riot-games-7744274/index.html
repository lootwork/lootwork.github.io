Инженеры Riot обладают глубокой экспертизой в отдельных технических областях, но также ценят возможность работать в более широком спектре направлений. В роли Software Engineer мы работаем как с новыми, так и с существующими технологиями, создавая инновационные решения для высоконагруженных задач и принося ценность игрокам.

В роли Staff Software Engineer в Riot Data Foundations, команде Data Experiences and Automation, вы сможете влиять на то, как Riot собирает и использует данные для улучшения опыта игроков и Rioters. Вместе с product-партнёром и technical lead вы будете расширять возможности потребления данных и reporting и создавать решения, улучшающие development lifecycle data engineers и insights analysts по всей организации. Вы поможете Riot ускорять развитие и итерации Machine Learning и GenAI pipelines. Используя опыт глобально распределённых систем, вы будете вместе с командой software engineers создавать эффективные решения. Позиция подчиняется Engineering Manager команды.

Обязанности

  • Создавать и улучшать системы, позволяющие участникам команды эффективнее работать с инструментами data-экосистемы.
  • Посещать stand-ups и командные rituals и работать с другими software engineers над достижением целей команды.
  • Участвовать в code reviews с другими участниками команды.
  • Быть частью on-call rotation для поддержки live-продуктов.
  • Давать содержательные code reviews коллегам.
  • Сотрудничать с нетехническими customers для достижения deliverables.

Обязательные требования

  • Степень бакалавра в Computer Science или сопоставимой области.
  • Понимание основных концепций data engineering и data pipelines.
  • 7+ лет опыта с Python и SQL.
  • 5+ лет опыта data warehousing.
  • Опыт работы в Agile и DevOps среде.

Желательные квалификации

  • Опыт ML Operations и GenAI pipelines/infrastructure.
  • Опыт open-source ETL frameworks, таких как Airflow, Luigi или аналогичных.

Успех в этой роли определяется профессиональной экспертизой, духом сотрудничества и решениями, которые ставят на первое место ваших коллег из Riot — именно они являются пользователями вашей работы. Быть преданным фанатом игр для этой позиции необязательно.
