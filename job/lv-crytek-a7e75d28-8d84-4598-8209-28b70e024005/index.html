At Crytek we're building a scalable UI platform powered by a Design System implemented in Coherent Gameface (HTML, CSS, JavaScript).

Instead of building UI screen-by-screen, we are creating reusable components and architecture that power Hunt: Showdown and future Crytek titles.

We’re looking for a Senior Web Design Engineer to help build this system - translating Figma components into production-ready UI and shaping how UI is developed across Crytek.

This is an opportunity to build the UI foundation for multiple games, not just individual screens.

We welcome candidates from a variety of backgrounds and experiences who are excited about building thoughtful, scalable UI.

This position is based in Frankfurt, Germany.

An online portfolio with updated work samples is necessary. Your

portfolio should demonstrate the following

  • The scope of your contribution on each project
  • Visual polish and attention to detail
  • A strong sense of UX, both in your work and how your portfolio itself is organized
  • Clean, well-structured code
  • Thoughtful use of modular UI components

Что предстоит делать

  • Build reusable UI components using HTML, CSS, and JavaScript
  • Implement scalable UI architecture using Coherent Gameface
  • Translate Figma design system components into production-ready UI
  • Assemble UI screens from reusable components
  • Improve the design to development pipeline, including tooling and workflows
  • Collaborate with UX, UI art, and engineering to deliver a modern UI pipeline
  • Help define and scale the UI platform used across future Crytek projects

Что вы приносите

  • Experience in web or UI engineering (rough guideline: ~5+ years, but we value equivalent practical experience)
  • Strong skills in HTML5, CSS, and JavaScript
  • Experience with games, Figma, or AI-assisted workflows
  • Experience with Web Components and a major frontend framework (React, Vue, Svelte etc.)
  • Experience building component-based UI systems
  • Good understanding of UI architecture and performance
  • Passionate about games and player experiences, with an appreciation for how great UI and UX contribute to gameplay across all genres.
  • Experience collaborating closely with design teams
  • Willingness to relocate to Frankfurt am Main, Germany.
