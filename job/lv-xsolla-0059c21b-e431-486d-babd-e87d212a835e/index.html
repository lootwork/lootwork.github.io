О ВАС

Мы ищем Senior Software Engineer (Full-Stack) — архитектурно сильного, ориентированного на качество и командного специалиста. Вам предстоит лидировать full-stack architecture decisions, строить scalable distributed systems и развивать shared platform strategies между backend, frontend и cloud ecosystems.

Необходимы глубокие Go и React JavaScript/TypeScript, cloud-native architecture patterns и event-driven system design, а также опыт commercial applications от concept до launch. Для успеха важно проектировать scalable service architectures, надёжные integration/E2E testing strategies, оптимизировать performance across full stack и менторить других developers.

Если вам интересно строить resilient systems в масштабе и бесшовный platform experience на event-driven workflows, cloud infrastructure и modern web interfaces для gaming, virtual currency и digital commerce, будем рады познакомиться.

О КОМПАНИИ

Xsolla — глобальная commerce компания для игровой индустрии. Подробнее: xsolla.com.

КВАЛИФИКАЦИЯ И НАВЫКИ

  • 5+ лет software engineering с сильным full-stack фокусом Go + React JavaScript/TypeScript.
  • Глубокое понимание backend architecture: microservices, event-driven architecture, domain-driven design.
  • Hands-on RESTful API и/или gRPC services на Go с фокусом performance, reliability, maintainability.
  • Сильный React: hooks, context, Redux, Zustand или аналоги.
  • Cloud AWS/GCP/Azure, Docker/Kubernetes и IaC Terraform/Pulumi или аналоги.
  • Message brokers/event streaming Kafka, RabbitMQ, NATS и др.
  • Relational/non-relational DB: PostgreSQL, MySQL, Redis, MongoDB, DynamoDB.
  • CI/CD и automated testing: unit, integration, E2E.
  • Observability Prometheus, Grafana, Datadog или аналоги.
  • Distributed systems: eventual consistency, idempotency, fault tolerance, retry strategies.
  • Опыт mentoring junior/mid engineers и участия в architecture decisions.
  • Отличная communication/collaboration с product, design и DevOps.
  • Проактивный ownership mindset и стремление к clean, documented, testable code.

БУДЕТ ПЛЮСОМ

  • Serverless AWS Lambda/Cloud Functions.
  • GraphQL.
  • WebSocket/real-time protocols.
  • Gaming, virtual currency, digital commerce или fintech.
  • Open-source contributions.
