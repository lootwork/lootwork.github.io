ЦЕЛИ

Мы ищем опытного Unity Game Developer для создания reusable SDK modules и shared runtime systems, которые можно использовать во множестве продуктов. Роль отлично подходит специалисту с сильным game development опытом, хорошей базой computer science и высокими требованиями к clean code, software architecture и долгосрочной maintainability.

Нужно уметь проектировать systems, которые не только корректны и производительны, но и легко интегрируются, расширяются и поддерживаются другими командами со временем.

ЧТО ПРЕДСТОИТ ДЕЛАТЬ

  • Проектировать и реализовывать reusable Unity/C# modules, libraries и runtime systems
  • Создавать clean APIs и modular architectures для разных use cases и команд
  • Писать maintainable high-performance code и повышать качество через refactoring, review и engineering standards
  • Сотрудничать со stakeholders и development teams, создавая практичные и scalable technical solutions
  • Участвовать в architecture decisions, улучшающих extensibility, stability и developer experience

КВАЛИФИКАЦИИ

  • 5+ лет hands-on опыта создания games или software, включая сильный production-опыт Unity/C#
  • Подтверждённая способность проектировать modular architectures и shared runtime systems с практическим применением SOLID principles и чётким separation of concerns
  • Сильная engineering discipline в naming, refactoring, debugging и поддержке legacy code без нарушения stability или замедления команд
  • Сильный performance mindset для real-time systems и практический опыт profiling и optimization CPU, memory, GC allocations, frame time, AOT/JIT constraints и gameplay bottlenecks в Unity/mobile environments
  • Опыт проектирования clean APIs и developer-friendly integration flows с вниманием к developer experience, defensive programming, extensibility и long-term maintainability

БУДЕТ ПЛЮСОМ

  • Опыт H5/web game development на Phaser, Cocos или Three.js
  • Опыт создания SDK, shared libraries или internal platforms для нескольких команд
  • Опыт testing, automation и CI-friendly development practices
  • Ясная коммуникация и сильное межкомандное сотрудничество

Об Amanotes

Мы — Amanotes, динамичная music game company, которая использует передовые технологии, чтобы менять то, как люди взаимодействуют с музыкой.

С 2014 года мы лидируем на глобальном рынке simple music games: более 3,5 млрд загрузок в 190+ странах, включая хиты Magic Tiles 3, Tiles Hop, Dancing Road и Duet Cats.
