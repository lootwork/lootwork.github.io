Инженеры Riot обладают глубокими знаниями в конкретных технических областях, но также ценят возможность работать в более широком спектре направлений. В роли Engineering Manager вы будете проводить инженерную команду через все этапы жизненного цикла разработки и эксплуатации ПО. Вы также будете people-менеджером, наставником и коучем для инженеров, отвечая за управление результативностью, возможности роста и ответственность за результат.

Команда Core Game Loop отвечает за сервисы, которые обеспечивают игровой опыт во время матча и передают данные downstream-сервисам после его завершения. Сюда входят подготовка игровых сессий, доставка игровых данных, а также сервисы лидербордов и истории матчей. Концентрируя экспертизу в игровых платформах, мы можем предоставлять надёжные и масштабируемые функции для всех текущих и будущих игр Riot. В роли Manager, Software Engineering в Core Game Loop вы будете сотрудничать с командами всех игр Riot, центральными технологическими командами и командами Tencent, чтобы принимать сильные решения, поддерживать высокий стандарт качества и эффективно работать в интересах игроков. Вы будете находить возможности централизовать функциональность и проектировать решения, обеспечивающие глобальную масштабируемость и надёжность. Позиция подчиняется Senior Engineering Manager организации Game Foundations в составе Publishing Platform.

Обязанности

  • Управлять командой из 5+ software engineers: коучить их, управлять производительностью, находить возможности для роста и обеспечивать положительные результаты.
  • Сотрудничать с Product Leads, Delivery Leads и Technical Leads внутри команды и Game Foundations, согласуя план работы команды.
  • Поддерживать техническое видение и roadmap, распределяя инженеров и компетенции для достижения целей и результатов.
  • Отвечать за процесс интервью и онбординга новых сотрудников инженерной команды.
  • Нести ответственность за техническое состояние продуктов, которыми владеет команда.
  • Сохранять практическую вовлечённость в технологии команды, контролировать технический дизайн и поставку результатов совместно с техническим руководством.
  • Регулярно взаимодействовать с кодовой базой, участвуя в code review и некритичных задачах.
  • Выстраивать здоровые отношения с другими инженерными командами Riot по всему миру для развития межкомандного сотрудничества.
  • Владеть и эксплуатировать live-сервисы: соблюдать ожидания по надёжности, реагировать на срочные проблемы и поддерживать инженеров во время on-call troubleshooting.

Обязательные квалификации

  • Степень бакалавра или магистра в Computer Science или смежной области либо эквивалентный профессиональный опыт.
  • 5+ лет опыта Software Engineer, предпочтительно в технических product-командах, создающих инструменты для сервисов и API.
  • 2+ года непосредственного руководства инженерной командой в роли Engineering Manager или Technical Lead.
  • Опыт управления инженерами и активного участия в их профессиональном росте и развитии.
  • Опыт найма кандидатов и расширения инженерной команды.
  • Опыт работы с распределёнными системами, микросервисами и высокомасштабным ПО.
  • Опыт эксплуатации и поддержки live-сервисов, включая срочные инциденты и on-call troubleshooting.

Желательные квалификации

  • Опыт создания сервисов на Java, Kotlin или Go.
  • Опыт разработки с использованием облачной инфраструктуры (AWS, GCP), контейнеров и оркестрации (Docker, Kubernetes), управляемых через Infrastructure as Code (Terraform, Ansible).
  • Опыт с CI/CD-пайплайнами, например GitHub Actions или Jenkins.
  • Опыт с реляционными базами данных, например MySQL, и key-value хранилищами, например Redis.
  • Опыт с платформами очередей или потоковой обработки данных, например Kafka.

Успех в этой роли определяется профессиональной экспертизой, духом сотрудничества и решениями, которые ставят на первое место ваших коллег из Riot — именно они являются пользователями вашей работы. Быть преданным фанатом игр для этой позиции необязательно.
