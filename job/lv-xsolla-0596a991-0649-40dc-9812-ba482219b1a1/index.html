О ВАС

Мы ищем Tech Lead Frontend Platform Team, который обеспечит техническое лидерство core-платформы Xsolla, лежащей в основе всех user-facing experiences. Роль сочетает глубокую engineering expertise и people leadership для команды примерно из восьми developers. Tech Lead формирует architecture платформы, улучшает developer workflows и обеспечивает качественные масштабируемые решения для storefronts, widgets и других monetization-focused experiences во всей экосистеме Xsolla.

Нужны сильный frontend/platform опыт, способность вести сложные technical initiatives и обеспечивать предсказуемый надёжный delivery.

О КОМПАНИИ

Xsolla — глобальная commerce компания для игровой индустрии. Подробнее: xsolla.com.

ОБЯЗАННОСТИ

  • Обеспечивать technical leadership frontend platform: architecture, coding standards и long-term technical direction.
  • Coach, mentor и manage команду ~8 developers, поддерживать growth и сильную engineering culture.
  • Тесно работать с другими Tech Leads той же платформы для architecture alignment, единых standards и решений.
  • Контролировать planning/execution platform features и improvements, обеспечивая smooth delivery и quality.
  • Вести modernization, refactoring и performance enhancements для scalability, maintainability и product alignment.
  • Устанавливать и обеспечивать engineering best practices в coding, documentation, testing, review.
  • Работать с PM, designers, backend engineers и platform teams над цельным partner-facing experience.
  • Обеспечивать сильное automated test coverage и reliable CI/CD, снижая manual effort и повышая predictability.
  • Использовать automation и AI-assisted tooling для ускорения development и повышения consistency/developer velocity.
  • Отвечать за operational excellence: incident response, root-cause analysis, long-term reliability.
  • Продвигать scalability, performance, security и observability.
  • Выявлять technical risks, оценивать complexity и объяснять trade-offs leadership/stakeholders.
  • Согласовывать shared services, APIs, rendering pipelines и platform interfaces с другими engineering teams.

КВАЛИФИКАЦИЯ И НАВЫКИ

  • 8+ лет software development, сильный modern frontend at scale; минимум 3 года similar Tech Lead.
  • Глубокий hands-on React: component architecture, SSR, RSC, complex UI data flows.
  • Node.js и MongoDB server-side.
  • Modern styling/theming: vanilla-extract, styled-components, design tokens.
  • Strong TypeScript: strict typing, shared contracts, schema validation Zod или аналоги.
  • Module Federation.
  • Bundling/compilation: webpack, rollup, vite, esbuild.
  • Testing Vitest/Jest и E2E Playwright/Cypress.
  • Backend integrations REST, GraphQL, RPC-style API.
  • CI/CD GitLab CI или аналоги, private registries, secure artifacts.
  • Подтверждённое leadership engineers, ownership architecture decisions и delivery complex platform projects.

БУДЕТ ПЛЮСОМ

  • Platforms/tooling для нескольких frontend teams: design systems, template engines, configuration frameworks; React Native/mobile.
  • Client/server rendering performance optimization.
  • Accessibility, internationalization и semantic UI best practices.
  • SDK, CLI или developer-facing automation.
  • Event-driven UI, real-time interfaces, edge rendering.
  • Developer platforms, observability или performance monitoring systems.
  • UI-as-data и AI-assisted/no-code tooling.
