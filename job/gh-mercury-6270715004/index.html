О роли

Mercury's Detection and Response team writes detections, triages alerts, responds to incidents, hunts for threats, and protects the Mercury brand. As a Senior Detection and Response Engineer you'll own that work from start to finish on a small, fast-moving team. You'll lead incidents, run detection projects from scoping to rollout, and set the quality bar for the engineers working with you. At this level you take an open-ended problem, break it into workstreams, write the tickets, and see it through. You're the person the team trusts to run an incident and write the summary leadership reads. You'll ship security outcomes, not checkbox compliance. You'll lead the response when a supply chain compromise or account takeover hits, decide what the team builds in your detection domain, and help the engineers around you grow. The platform you protect is one businesses depend on to run their finances every day.

Что предстоит делать

  • Incident Response: Lead incidents as incident lead: scope the impact, coordinate containment with Engineering, IT, and Legal, run the war room, and write the executive summary and post-incident review. Handle supply chain compromises, account takeovers, insider threats, and phishing.
  • Detection Engineering and SIEM Operations: Own detection work for a domain such as identity, cloud, endpoint, or SaaS. Decide what to build, write detections as code in Python, set severity, routing, and suppression, and track false-positive rates. Onboard new log sources and fix data quality problems.
  • Threat Hunting and Intelligence: Write hunting hypotheses from threat reports and active campaigns, run them against endpoint telemetry and the security data lake, and turn the results into detection coverage.
  • Brand Protection and Fraud Detection: Run takedown workflows for impersonation and phishing domains, and work with Fraud and Risk teams to put external fraud feeds to use.
  • Endpoint Security and DLP: Tune EDR and data loss prevention policies, and work with IT on endpoint compliance.
  • Automation and Tooling: Build enrichment pipelines and integrations between security platforms that remove manual triage work.
  • Team: Break projects into tickets that other engineers execute, review detection pull requests, mentor teammates, and interview candidates.

Must Have

  • 5+ years in detection and response, SOC, incident response, security operations, or adjacent security experience
  • Has led incidents from detection through post-incident review, including containment decisions and communication to leadership
  • Hands-on detection writing in a SIEM (ideally Python) with detections-as-code workflows (Git, pull requests, CI/CD)
  • Deep fundamentals in networking, operating systems (macOS, Linux, Windows), and identity (SSO, MFA, OAuth, session tokens), and the ability to explain attacker behavior at each layer
  • Cloud security experience in AWS and/or GCP: audit logs, IAM, and common attack paths
  • EDR platform experience and SQL proficiency for log analysis and threat hunting
  • Has owned a project from scoping to delivery: broke it into workstreams, sequenced the risky parts first, and kept stakeholders informed
  • Clear written communication for incident summaries, runbooks, and cross-functional updates

Будет плюсом

  • Financial services or fintech background (fraud detection, account takeover, financial crime)
  • Threat intelligence platforms and standards (STIX/TAXII, MITRE ATT&CK)
  • Identity-based attack detection (credential stuffing, impossible travel, privilege escalation)
  • Brand protection, anti-phishing takedowns, or DLP and insider threat experience
  • Python or Bash automation across security tools
  • Experience mentoring engineers or reviewing their detection work
  • Participation in industry information-sharing communities
  • Has built LLM-assisted security operations automations, tools, and capabilities with deterministic, reviewable outputs, and understands prompting, context windows, tool use, and failure modes such as hallucination and prompt injection
