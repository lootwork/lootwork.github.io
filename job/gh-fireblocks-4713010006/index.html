О роли

As Director of Security Engineering, you will lead the modernization of Fireblocks’ security infrastructure — across both our in-house-built tooling and the SaaS platforms we rely on. You will own the architecture behind security operations, our security data lake, SaaS security, and cloud security, and build the infrastructure that makes Fireblocks’ security tooling faster, more efficient, and ready for an agentic operating model.

This is a hands-on leadership role: you will set the technical direction, build out a team and processes, and personally drive projects from architecture through implementation and measurable impact.

Что предстоит делать

Security Infrastructure Strategy & Modernization

  • Own the multi-year modernization roadmap for Fireblocks’ security infrastructure, spanning in-house tooling and SaaS.
  • Analyze the needs across security domains, ensure we have the appropriate architecture for a centralized security data lake, and propose and drive optimized designs for agentic flows.

Security Data & Detection Engineering

  • Build and evolve Fireblocks’ security data lake and the logging, detection, and analytics pipelines built on top of it.
  • Optimize security data infrastructure to support faster detection, detailed investigation and automated response.

Cross-Functional Leadership

  • Coordinate and align with Security, R&D, and DevOps stakeholders to drive infrastructure projects end-to-end.
  • Lead projects from concept to delivery, and define the metrics that demonstrate their impact.

Требования

  • 7+ years of progressive cybersecurity experience, including leadership roles in SecOps, Application Security, or DevSecOps.
  • At least 3–4 years in a formal leadership or management capacity.
  • Security Engineering background — hands-on experience implementing and optimizing security systems is a must.
  • Proven experience building security systems and workflows that handle large-scale data (e.g., security data lakes, SIEM), including hands-on work with security auditing, logging, and cloud infrastructure.
  • Hands-on experience implementing AI processes, workflows, and tools to optimize security operations and workflows, and familiarity with AI security tooling.
  • Strong track record coordinating across Security, R&D, and DevOps stakeholders.
  • A builder mentality: the desire and ability to create infrastructure from scratch, lead projects end-to-end, and measure their impact.

Будет плюсом

  • Bachelor’s degree in Computer Science, Computer Engineering, Software Engineering, or a related field.
  • Professional certifications (e.g., CISSP, CISM, CCSP).
