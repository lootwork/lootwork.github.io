О роли

We're looking for a WordPress Developer to take technical ownership of SEON's global website and help us build a faster, more scalable and reliable web platform. You'll be responsible for everything from developing custom Gutenberg blocks and maintaining our WordPress architecture to managing deployments, security, performance and integrations. Working closely with our Website Manager, Marketing, Design and SEO teams, you'll turn business requirements into robust, reusable solutions that enable us to launch campaigns, experiment and scale without unnecessary developer dependencies. This is a hands-on engineering role with significant ownership and autonomy. We're looking for someone who doesn't just deliver tickets, but proactively identifies opportunities to improve the platform, challenges technical decisions when necessary and takes pride in building a website that performs as well behind the scenes as it does for our visitors.

Location: US East Coast or Austin, TX

Что предстоит делать

- Build and maintain custom Gutenberg blocks, patterns and page templates, extending the block editor so content can scale without developer involvement

- Own the custom SEON theme and plugin codebase: maintenance, refactoring, documentation and paying down technical debt

- Own the build pipeline and releases: Git workflow, staging, deployments to WP Engine, and rollback when something goes wrong

- Own site security: hardening, vulnerability monitoring, plugin and theme updates, and incident response

- Own site performance: Core Web Vitals, edge and object caching, and page speed

- Plan and deliver platform upgrades (WordPress core, PHP, MySQL) with full compatibility testing across the multisite network

- Make sure every change works across all three locales (EN, ES, PT-BR), including multilingual and hreflang behaviour

- Maintain the site's integrations, including forms and CRM, analytics and tag management, and cookie consent

- Implement technical SEO and accessibility with the SEO team: schema, crawlability and indexation, and WCAG 2.2 AA compliance

- Set and uphold engineering standards: code review, coding conventions, monitoring, backups and recovery testing

- Scope and estimate requests from marketing and design, and give technical direction to agencies or freelancers when they're used

- Run cross-browser and cross-device testing before every release, using tools such as BrowserStack, and include visual regression checks on key templates

WHAT YOU'll BRING

- Strong WordPress engineering experience, with extensive hands-on experience developing and maintaining custom, production-grade WordPress websites, ideally with 5+ years in a professional development environment and experience owning complex or multisite implementations

- Excellent PHP and WordPress knowledge, including advanced PHP skills, a strong understanding of WordPress internals, hooks, APIs, custom themes, plugins, database structures, custom post types and WP-CLI

- Ability to confidently troubleshoot and extend WordPress without relying on third-party plugins for everything

- Modern front-end and Gutenberg expertise, including strong JavaScript (ES6+), React, HTML5 and CSS/SCSS skills, with proven experience building custom Gutenberg blocks, reusable components and responsive, accessible templates

- Development workflow and testing experience, including Git, code review, staging environments, automated builds, CI/CD pipelines and structured deployment practices

- Understanding of unit, integration and end-to-end testing and how to release changes safely

- Performance, security and infrastructure knowledge, including Core Web Vitals, caching, CDNs, web security, vulnerability management, monitoring and the fundamentals of hosting and maintaining a business-critical website

- Experience working with WordPress multisite, multilingual websites or similarly complex architectures, with an understanding of technical SEO, accessibility, compatibility testing and safe platform upgrades

- A proactive, solutions-focused approach with the ability to independently investigate problems, prioritise technical improvements, translate business requirements into maintainable solutions and collaborate effectively with Marketing, Design and other stakeholders

AMAZING IF YOU ALSO HAVE

- Experience managing production websites on WP Engine, including staging, environment management, caching, Global Edge Security and deployment workflows

- Experience with HubSpot, GA4, Google Tag Manager, Consent Mode v2, cookie consent platforms and complex form integrations, particularly where accurate lead attribution matters

- Experience implementing A/B tests, personalisation, conversion-focused templates or experimentation platforms such as VWO or GrowthBook

- Familiarity with MultilingualPress or equivalent multilingual solutions, particularly within WordPress multisite environments

- Previous experience maintaining a high-performing B2B SaaS or enterprise marketing website where technical reliability, SEO, analytics accuracy and lead generation are critical

- Familiarity with DNS, CDNs, WAFs, Cloudflare, server logs, security scanning, API troubleshooting and third-party script governance
