В Rockstar Games мы создаём развлекательные продукты мирового уровня.

Станьте частью команды, работающей над одними из самых масштабных и вдохновляющих творческих проектов во всей индустрии развлечений — в инклюзивной, мотивированной среде, где можно учиться и сотрудничать с одними из самых талантливых специалистов отрасли.

Rockstar Games ищет опытного Senior Software Engineer (C++) в команду разработки. Наша Core Security team ищет engineer с фокусом на security, который поможет развивать различные инициативы software security. Успешный кандидат будет помогать сохранять игры и сервисы приятными для игроков, защищая их от читеров, хакеров, эксплойтеров и других нарушителей.

Это штатная постоянная позиция с полной занятостью и работой из офиса в современной студии разработки Rockstar в Эдинбурге, Шотландия.

ЧЕМ МЫ ЗАНИМАЕМСЯ

  • Core Security team отвечает за защиту наших игроков, сотрудников и бизнеса.
  • Мы разрабатываем anti-cheat для сохранения честности online experience.
  • Мы создаём anti-piracy меры для защиты интеллектуальной собственности.
  • Мы создаём и применяем anti-tamper technologies для защиты чувствительных областей кода.
  • Мы поддерживаем все проекты Rockstar, включая Grand Theft Auto V и Red Dead Redemption.
  • Мы тесно работаем со множеством cross-functional teams, повышая безопасность наших игр.

ОБЯЗАННОСТИ

  • Создавать и внедрять инновационные решения для лучшей защиты продуктов от известных уязвимостей.
  • Исследовать и внедрять различные anti-tamper и anti-cheat technologies.
  • Отлаживать exceptions и устранять проблемы, связанные с obfuscation transformations и anti-tamper mechanisms.
  • Профилировать производительность защищённого и незащищённого кода для соответствия ожидаемым performance requirements.
  • Следовать software SDLC для интеграции с операциями game teams.
  • Тестировать cross-platform software solutions для обеспечения качества.

ТРЕБОВАНИЯ

  • 7+ лет опыта работы в software/security development team на C++.
  • Опыт security и/или game development.
  • Отличные problem-solving skills с акцентом на debugging C++ code.
  • Аналитические навыки для измерения system performance и memory use, а также communication skills для выработки решений.
  • Способность самостоятельно вести задачи от идеи до исполнения.
