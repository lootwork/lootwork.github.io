Visual Concepts China в Шанхае ищет Senior Full-Stack Server Engineer для неанонсированного проекта. Visual Concepts, дочерняя компания Take-Two Interactive Software, Inc. (TTWO), широко считается одной из ведущих игровых студий мира и особенно известна спортивными играми, включая баскетбольную франшизу NBA 2K — №1 по рейтингам и продажам.

Кто нам нужен

Мы ищем backend specialist, который будет отвечать за проектирование, разработку и поддержку надёжных, масштабируемых и безопасных server-side applications и API. Роль требует уверенного практического опыта настройки server API и глубокого понимания решений для хранения данных.

Кто отлично подойдёт

  • Опыт: 8–10 лет профессиональной разработки ПО, включая не менее 5 лет high-scale backend server engineering.
  • Server API: подтверждённая экспертиза в проектировании, создании, документировании и использовании сложных API (REST/GraphQL), включая API gateways и service-to-service communication.
  • Владение основными backend-языками, например Python, Java, C++.
  • Databases: сильное понимание relational databases (PostgreSQL, MySQL, MS SQL Server), включая query optimization, indexing и schema design; хорошее понимание in-memory и NoSQL решений для масштабирования между кластерами машин.
  • Cloud computing: практический опыт развёртывания и управления приложениями минимум на одной крупной cloud platform — AWS, Azure или GCP.
  • Экспертное знание testing methodologies и требований — unit, integration, BVT, stress и performance testing; способность построить testable framework для automation и white-box testing.
  • Степень бакалавра или выше по Computer Science, Computer Engineering или напрямую связанной специальности либо эквивалент.
  • Любовь к видеоиграм, не только к нашим.

Будет плюсом

  • Опыт развёртывания крупномасштабных microservices и distributed systems.
  • Хорошее понимание networking, data storage и security.
  • Опыт Infrastructure as Code (IaC), например Terraform, AWS CloudFormation, Google Cloud Deployment Manager или Azure Resource Manager.
  • Понимание heavily regulated или high-traffic environments, например FinTech, e-commerce или telecommunications.
  • Опыт руководства техническими проектами и наставничества junior engineers.

*Точный уровень позиции и компенсация будут определяться с учётом релевантного опыта и экспертизы кандидата.
