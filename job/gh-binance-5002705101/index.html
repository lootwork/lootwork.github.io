If you're passionate about building cutting-edge solutions and making a real impact, we invite you to apply and be part of our dynamic and forward-thinking team!

This role is 100% Remote, Work from Home based.

Обязанности

1. Build and optimize high-performance Android applications for risk control and identity verification products;

2. Integrate and optimize on-device AI models — deploy lightweight face recognition / liveness detection models running locally on Android;

3. Develop Android client-side libraries and frameworks to speed up development and improve code quality;

4. Collaborate with cross-functional teams to build hybrid frameworks and on-device inference pipelines;

5. Implement user action recognition flows: camera capture → on-device preprocessing → backend API calls;

6. Handle video processing on Android — real-time frame processing, camera stream management;

Требования

1. 3+ years of experience building Android applications from scratch, high proficiency with Kotlin/Java;

2. Bachelor's or Master's degree in Computer Science, Engineering, or a related field

Proven experience with on-device / local AI model deployment on Android — integrating lightweight ML models (face recognition, liveness detection, action recognition) with optimized inference;

3. Experience with video processing on Android — camera capture, real-time frame processing, video stream handling;

4. Familiarity with face recognition / computer vision product development — face detection, liveness, anti-spoofing workflows;

5. Proven experience in Android development, including architecture design, Jetpack, OkHttp, and related frameworks;

6. Familiarity with cross-platform technologies such as JavaScript/TypeScript, React; knowledge of C++ and JNI is a plus;
