"AI First 크래프톤을 완성하는 데이터의 심장,"

크래프톤 AX(AI Transformation)는 전사에 AI를 도입하여, 데이터와 인프라를 기반으로 임직원들의 워크(Work)와 워크플로우(Workflow) 자동화를 가속화하고 그 압도적인 효율화 성과를 전사로 확산하는 핵심 조직입니다.

Data Foundation 팀은 파편화된 전사 데이터를 통합하고, AI(LLM, AI Agent 등)가 즉각적으로 이해하고 활용할 수 있는 최적의 데이터 구조(Ontology)와 아키텍처를 설계·구축합니다.

크래프톤의 각 조직이 실제로 사용하는 데이터와 업무 맥락을 깊이 이해하고, 이를 AI가 이해할 수 있는 데이터 관리·활용 체계로 직접 기획하고 설계해 낼 분을 모십니다.

우리 팀과 함께할 미션을 소개합니다.

담당 도메인의 데이터 관리·활용 체계를 직접 기획·설계하고, 설계 산출물(Ontology 설계서, 데이터 모델, 거버넌스 기준 문서 등)을 주도적으로 작성·관리합니다.

  • 도메인별 데이터 구조 분석 및 Ontology 설계: 도메인의 원천 데이터와 업무 프로세스를 분석하고, AI(LLM, AI Agent)가 활용할 수 있는 Ontology(개체·관계·속성 정의) 구조를 주도적으로 설계하며 Ontology 설계서를 작성·관리
  • 비즈니스 용어·지표 정의 및 데이터 거버넌스 기준 수립: 도메인별 핵심 용어(Glossary), 지표 정의, 데이터 오너십·접근 권한 기준을 현업과 협의해 수립하고 거버넌스 기준 문서로 정립
  • 데이터 품질·정합성 분석 및 개선: 원천 데이터의 정합성, 완결성, 중복 여부를 분석하고, 개선 방안을 직접 도출해 Ontology 설계 및 데이터 구축에 반영
  • 현업 부서와의 요구사항 분석 및 데이터 모델링: 담당 조직의 실무자를 인터뷰하고 업무 데이터를 분석하여, 실제 질의·분석 시나리오에 맞는 데이터 모델(테이블 구조, 관계, 계층)을 설계·구축하고 지속적으로 개선

이런 경험을 가진 분과 함께 성장하고 싶습니다! (필수요건)

  • 데이터 분석, BI, 또는 데이터 모델링 관련 분야 7년 이상의 경력을 보유하신 분 (데이터 엔지니어링뿐 아니라 데이터 분석가 경력도 포함)
  • SQL을 능숙하게 다루며, 원천 데이터를 스스로 탐색·분석해 구조를 파악할 수 있는 분
  • 특정 업무 도메인의 데이터와 프로세스를 깊이 이해하고, 현업과 커뮤니케이션하며 요구사항을 구조화해 데이터 모델·지표 체계로 설계해 온 경험이 있는 분
  • 데이터 모델링(테이블 설계, 정규화, 관계 정의 등)을 직접 기획·수행해 본 경험이 있으신 분
  • 새로운 개념(Ontology, Semantic Layer 등)을 빠르게 학습하고 실무에 적용하려는 의지가 강하신 분
  • 해외 출장에 결격 사유가 없는 분

이런 경험들이 있다면 저희가 찾는 그 분입니다! (우대요건)

  • Ontology, Knowledge Graph, Semantic Layer 등 개념을 실제 프로젝트에 적용해 본 경험이 있으신 분
  • Databricks 데이터 카탈로그/온톨로지/거버넌스 플랫폼을 사용해 본 경험이 있으신 분
  • 재무, HR, 마케팅 등 특정 도메인에서 데이터 분석가/기획자로 근무하며 해당 도메인 데이터 구조를 잘 이해하고 계신 분
  • 데이터 거버넌스, 메타데이터 관리, 용어 표준화(Glossary) 작업을 수행해 본 경험이 있으신 분
  • LLM, RAG, AI Agent가 데이터를 어떻게 활용하는지에 대한 이해와 관심이 높으신 분
