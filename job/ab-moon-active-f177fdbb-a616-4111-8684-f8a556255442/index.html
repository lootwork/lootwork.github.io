Moon Active — одна из самых быстрорастущих mobile game companies мира, развлекающая миллионы активных пользователей.

Мы ищем звёздного Monetization Artist для нашего первоклассного, лидирующего в индустрии продукта.

В роли Monetization Artist вы будете отвечать за user experience, visual design concepts и game UI в цифровых продуктах и платформах. Став частью нашей dream team, вы получите дружелюбных и творческих коллег и сильный фокус на вашем профессиональном развитии.

Требуемый часовой пояс: CET ±3 часа.

Требования

  • Создавать playful, intuitive и цельный look & feel и общий user experience мобильной игры.
  • Концептуализировать, презентовать и реализовывать свои идеи от A до Z.
  • Совместно работать с другими designers и кросс-функционально с UX, engineering и product management над design и implementation новых game features.
  • Создавать и полностью отвечать за implementation увлекательных внутриигровых events и другого game content.
  • Проектировать и выдавать UI для внутриигровых offers, promotional screens и purchase flows: offer popups, sale banners, seasonal promotions.
  • Полностью вести visual pipeline от brief до implementation, включая asset handoff.
  • Поддерживать и развивать UI component library и style guides для единообразия features.
  • Быстро создавать варианты для A/B tests — несколько visual treatments — и адаптировать их на основе performance data.
  • Тесно работать с monetization team над design decisions, ориентированными на conversion.
  • Участвовать в design reviews и давать коллегам конструктивный feedback.

Обязанности

  • Минимум 3 года опыта game UI и понимание game UI principles.
  • Практический опыт monetization UI: offer screens, shop flows, promotional screens — серьёзное преимущество.
  • Знакомство с mobile game design patterns: LiveOps events, popups, progression screens.
  • Способность работать в динамичной среде с быстрым принятием решений и жёсткими сроками.
  • Уверенное владение Photoshop, Figma и AI creative tools.
  • Сильные навыки дизайна, рисунка, цвета, композиции и conceptual ideation.
  • Комфортная работа с data-informed iteration: способность создавать варианты и корректировать их по результатам A/B.
  • Понимание asset production constraints: texture atlases, file sizes, animation-ready layers.
  • Свободный английский.
