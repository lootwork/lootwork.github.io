О ВАС

Мы ищем Site Reliability Engineer — прагматичного специалиста с product mindset, который одинаково уверенно пишет код и эксплуатирует production-системы, — в SRE-команду Infrastructure department. Идеальный кандидат хочет полностью отвечать за application-level infrastructure и reliability высоконагруженного commerce domain: от deploy pipelines и Kubernetes manifests до SLO, capacity planning и production readiness.

Необходимы сильные Kubernetes, observability и software engineering skills, опыт эксплуатации production services в cloud environment GCP/GKE или аналогичном и тесной работы с product development teams. Для успеха важно одновременно понимать, как developers выпускают features и что нужно инфраструктуре для надёжной работы, и приносить reliability perspective в design decisions ещё на раннем этапе.

Если вам нравится превращать сложные distributed systems в предсказуемо надёжные и строить commerce/monetization backbone, благодаря которому разработчики игр по всему миру получают оплату, будем рады познакомиться.

О КОМПАНИИ

Xsolla — глобальная commerce компания для игровой индустрии. Подробнее: xsolla.com.

ОБЯЗАННОСТИ

  • Полностью отвечать за application-level infrastructure: Helm charts, Terraform configs, Kubernetes deployments, runtime configuration, service-level networking и integrations.
  • Отвечать за observability domain: SLO/SLI, monitors, alerts и dashboards критических сервисов на Datadog и OpenTelemetry tooling.
  • Помогать создавать и развивать CI/CD pipelines GitLab CI/GitHub Actions, включая deploy и rollback automation.
  • Проводить capacity planning и performance tuning до ожидаемых нагрузок — launches, sales events, regional rollouts — включая load testing и performance regression investigation.
  • Проводить Production Readiness Reviews новых сервисов и крупных изменений, определять и обеспечивать критерии production-ready.
  • Поддерживать incident response domain: глубокое расследование сложных incidents, post-mortems, follow-up reliability improvements и runbooks.
  • Создавать domain-specific automation для снижения operational toil: runbook automation, deploy helpers, recurring scripts.
  • Вместе с product engineering leads вести forward-looking reliability roadmap.
  • Участвовать в product planning, refinements и architecture reviews, внося reliability perspective до дорогих design changes.
  • Совместно с широкой SRE team формировать company-wide standards SLO/SLI, capacity и operations и улучшать shared SRE subsystems.
  • Участвовать в SRE duty rotation и поддерживать developers компании.

КВАЛИФИКАЦИЯ И НАВЫКИ

  • 3+ года SRE, DevOps или platform engineering: on-call/incident response, ownership SLO/monitoring, deploy pipelines и infrastructure для production services.
  • Software development background: вы создавали и выпускали backend services, умеете читать application code при расследовании и писать production-quality automation хотя бы на Go, PHP или другом языке.
  • Hands-on Kubernetes: Helm, manifests, deploy strategies, debugging application performance/networking в GKE или другом managed Kubernetes.
  • Solid observability: monitors, dashboards, SLO/SLI в Datadog либо Prometheus/Grafana, знакомство с OpenTelemetry.
  • Infrastructure as Code Terraform/Terragrunt.
  • GCP: IAM, networking, managed services.
  • CI/CD GitLab CI и/или GitHub Actions.
  • Python, Go или Bash для automation/tooling.
  • Практический incident response, post-mortems и reliability improvements.
  • Сильные collaboration/communication skills для ежедневной работы с product teams.
  • Опыт payments, fintech, e-commerce или gaming и high-traffic transactional systems.

БУДЕТ ПЛЮСОМ

  • Kubernetes certifications.
  • Google Cloud Platform certifications.
  • HashiCorp certifications.
