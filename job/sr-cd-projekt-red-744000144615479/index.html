О компании

Наша миссия — создавать революционные сюжетные RPG, которые попадают прямо в сердца игроков. Хотите лучше узнать культуру компании? Загляните в наши социальные сети, YouTube-канал и блог Beyond the Game, где мы делимся закулисными материалами и историями напрямую от участников команды!

Описание вакансии

Как Core Engineer вы примените опыт с core code Unreal Engine, чтобы находить лучшие способы использовать движок для создания правдоподобных крупных open-world игр и при необходимости расширять возможности технологии. Вы войдёте в Team, отвечающую за Streaming solutions, editor tools, physics engine support и engine-level optimizations. Благодаря значительному опыту Unreal Engine вы будете работать со всем проектом и направлять его, создавая надёжную технологическую основу для новой саги The Witcher и будущих игр.

Ежедневные обязанности

  • Разрабатывать и поддерживать core technology systems на базе Unreal Engine.
  • Предлагать и реализовывать решения технических требований performance и scale крупной open-world игры.
  • Сотрудничать с Epic, обмениваться идеями и находить способы развивать technology дальше.
  • Создавать technology для игры, которая дарит игрокам запоминающийся опыт.
  • Работать между всеми дисциплинами, следя, чтобы результат отвечал потребностям всех stakeholders.
  • Создавать tools и data pipelines для огромного мира с минимальным влиянием на performance.
  • Демонстрировать strong ownership mindset: проактивно поддерживать ясную коммуникацию и строить тесные долгосрочные отношения с power users наших systems.

Квалификация

  • Значительный опыт Unreal Engine, особенно в одной или нескольких областях:
  • Streaming — например World Partition System, HLOD, cooking pipeline, FastGeo.
  • Memory system — allocations, GC.
  • Physics — ChaosPhysics.
  • World-building tools — SceneOutliner, LevelInstances.
  • Большой опыт C++.
  • Релевантный game-development опыт, включая AAA-проект.
  • Опыт разработки для PC и consoles.
  • Опыт multithreaded programming.
  • Сильные system architecture skills.
  • Способность debug и optimize код.
  • Collaborative mindset, ясная коммуникация и способность строить доверительные отношения между командами.
