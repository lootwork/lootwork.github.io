О ВАС

Мы ищем Senior Software Engineer (React Native) — архитектурно сильного, ориентированного на качество и командного специалиста — в Mobile Engineering team. Идеальный кандидат хочет влиять на mobile architecture, создавать масштабируемые cross-platform приложения и развивать стратегии общего кода между web и mobile ecosystems.

Необходимы сильная экспертиза React Native и JavaScript/TypeScript, глубокое понимание mobile architecture patterns и state management, а также опыт создания и выпуска коммерческих mobile apps от идеи до launch. Для успеха важно проектировать scalable architecture, внедрять устойчивые testing strategies, включая E2E, оптимизировать performance и менторить разработчиков в cross-functional окружении.

Если вам интересно создавать качественный mobile experience в масштабе и бесшовную app ecosystem для gaming, virtual currency и digital commerce, будем рады познакомиться.

О КОМПАНИИ

Xsolla — глобальная commerce компания для игровой индустрии. Подробнее: xsolla.com.

ОБЯЗАННОСТИ

  • Разрабатывать и поддерживать React Native приложения для iOS и Android.
  • Внедрять best practices mobile development: code review, testing strategies, CI/CD.
  • Вовремя выпускать качественные features по всему development lifecycle.
  • Создавать масштабируемые и сопровождаемые features в существующей architecture.
  • Вместе с product/design реализовывать technical solutions под business goals.
  • Интегрировать mini-apps и virtual currency systems с Xsolla App ecosystem.
  • Работать с developers, QA engineers и project managers.
  • Участвовать в технических обсуждениях и согласовании development с business objectives.
  • Эффективно коммуницировать между распределёнными командами.

АРХИТЕКТУРА И ДИЗАЙН

  • Проектировать scalable architecture React Native apps с фокусом на maintainability, performance и developer experience.
  • Лидировать решения по shared code между React web и React Native mobile.
  • Устанавливать coding standards, design patterns и best practices mobile-команды.
  • Создавать technical specs и architecture documentation для сложных features/systems.
  • Строить и поддерживать monorepo infrastructure на Nx, Turborepo или аналогах.
  • Настраивать build pipelines, dependency management и workspace configurations.
  • Внедрять caching и incremental builds для оптимизации CI/CD.
  • Управлять versioning, publishing и dependency relationships пакетов.
  • Проектировать comprehensive shared component library для React и React Native.
  • Создавать platform-agnostic business logic, utilities и services для web/mobile.
  • Создавать tooling и documentation для удобного переиспользования shared code.
  • Реализовывать adaptive components с platform-specific implementation при едином API.
  • Устанавливать patterns для shared types, hooks, contexts и state management.

КВАЛИФИКАЦИЯ И НАВЫКИ

  • 5+ лет mobile development с сильным фокусом на React Native.
  • Bachelor's degree в Computer Science, Engineering или смежной области либо эквивалентный опыт.
  • Подтверждённый опыт commercial mobile applications от concept до launch.
  • React Native и JavaScript/TypeScript; знание native modules Swift/Kotlin — плюс.
  • Сильное понимание mobile architecture patterns и state management.
  • Third-party integrations и APIs.
  • Сильное problem solving и ориентация на результат.
  • Эффективная письменная и устная коммуникация.
  • Gaming ecosystems и virtual currency platforms — плюс.
