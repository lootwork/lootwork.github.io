Project Overview

Responsible for testing and risk investigation of AI Agent, OpenClaw ("小龙虾") intelligent agent, and HIDS (Host-based Intrusion Detection System) host security systems, covering both mainnet and testnet environments. The role focuses on security validation against two primary risk categories — external hacker attacks and internal personnel violations — identifying issues such as privilege escalation, anomalous behavior, and data leakage. The intern will follow up on issue remediation, optimize testing processes, and help ensure the secure and stable operation of systems and business services.

Основные обязанности

  • Perform functional testing and regression testing on AI Agent, OpenClaw intelligent agent, and HIDS host security systems; document and track security issues through to resolution.
  • Conduct vulnerability scanning and risk investigation; simulate hacker attack and internal violation scenarios to verify the effectiveness of security controls.
  • Design and write test cases tailored to AI agent and host security scenarios, improving security test coverage and quality.
  • Participate in security requirement reviews; identify potential risks and provide optimization recommendations; compile test reports to support business iterations.

Требования

  • Major in Computer Science, Cybersecurity, or a related field, with a solid foundation in network security and host security theory.
  • Familiar with web security, HIDS host protection, and common security risks associated with AI agents; proficient in fundamental security testing methodologies.
  • Able to independently perform security testing, vulnerability verification, and report writing, with the ability to simulate risk scenarios.
  • Strong cross-team communication and collaboration skills; detail-oriented, responsible, and a fast learner capable of efficiently driving security issue remediation.
  • Minimum 3-month internship commitment, 5 days per week on-site.
  • Fluent in Mandarin is required; proficiency in English is a plus.
