Client Security Expert

Job Description

  • Identify client-side security risks, propose solutions, and drive their implementation.
  • Lead offensive and defensive exercises on mobile clients, and drive remediation of business-related risk issues.
  • Analyze attack techniques used by black/gray-market actors, reconstruct attack mechanisms and details, and produce countermeasure plans.
  • Design and build systematic client-side defense solutions to improve defensive effectiveness and mitigation efficiency.

Требования

  • Bachelor's degree or above in Computer Science or a related field.
  • Familiar with low-level Android and iOS system architecture, security mechanisms, and reverse engineering.
  • Familiar with typical cheating/fraud techniques used by black/gray-market actors.
  • Proficient in leveraging AI Agents for security workflows, including reverse engineering, vulnerability discovery, attack reconstruction, and log/data analysis, with hands-on experience integrating AI tools into daily security operations.
  • Candidates with the following experience will be preferred:
  • Client security experience in Web3/blockchain scenarios.
  • Familiarity with browser-side security.

Client Security Architect

Job Description

  • Own the overall architecture design for client-side security, ensuring high availability, high performance, and scalability of the system.
  • Design and optimize the backend data pipeline for security data collection, processing, and analysis, supporting various business scenarios.
  • Incorporate AI Agent capabilities to design intelligent security strategy operations and automated countermeasure architecture, improving strategy iteration speed and incident response speed.

Требования

  • Bachelor's degree or above in Computer Science or a related field; 3+ years of experience in backend development or architecture design.
  • Strong backend architecture skills, with expertise in high-concurrency, high-availability distributed system design.
  • Familiarity with the client security domain (e.g., device fingerprinting, environment detection, behavioral risk control), with the ability to understand endpoint-collected data and design corresponding backend processing solutions.
  • Familiar with AI Agent technical principles and application paradigms, with practical experience integrating AI capabilities into security architecture design.
  • Candidates with the following experience will be preferred:
  • Risk control system architecture (e.g., rule engines).
  • Security backend experience in Web3/blockchain scenarios.
  • Architecture experience in security data platforms or threat intelligence systems.
