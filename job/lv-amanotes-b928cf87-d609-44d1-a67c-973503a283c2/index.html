О роли

Amanotes Tech Team is looking for a detail-oriented and eager-to-learn Intern QA Engineer who is interested in building reliable software products. You will work with the team to test internal platforms supporting creative production, User Acquisition and system operations, including. Our internal products are:

  • A platform that supports creative lifecycle management and automation for banner, video ads and playable HTML5 assets.
  • A platform that supports creative management, validation, upload, synchronization and lifecycle tracking across campaigns, ad groups and ad-network channels.

This internship will help you build practical QA fundamentals while gradually gaining hands-on experience in API testing, E2E testing and test automation with Playwright/TypeScript.

Что предстоит делать

  • Able to read and understand user stories, Definition of Done (DoD) and Acceptance Criteria (AC).
  • Design test scenarios and test cases covering happy paths, edge cases, negative cases and error handling.
  • Execute assigned test cases under the guidance and mentorship of QA Engineers.
  • Log, categorize and track defects in Jira with clear reproduction steps, expected result, actual result, severity/priority and supporting evidence.
  • Retest fixes and collaborate with Developers and Product Owners during bug triage, clarification and release verification.
  • Learn and help maintain automated tests using Playwright/TypeScript; gradually work with API automation, test data, fixtures, page objects and GitLab CI/CD execution.

Требования

  • Final-year student or recent graduate in Computer Science, Software Engineering, Information Technology or a related field.
  • Available to work full-time for 3–6 months.
  • Basic understanding of SDLC, software testing, test cases, bug lifecycle and defect reporting.
  • Logical thinking, strong attention to detail and the ability to analyze problems.
  • Basic understanding of web applications, HTTP/API, JSON and data validation.
  • Able to read technical documentation in English and communicate in a team environment.
  • Proactive, willing to learn, open to feedback and accountable for assigned work.

Будет плюсом

  • Exposure to or interest in Playwright, TypeScript, Postman, SQL, Git, GitLab or Jira.
  • Personal projects, coursework or hands-on experience in manual testing, API testing or test automation.
  • Interest in media/creative-related testing, including images, videos and playable HTML5 assets.

WHAT YOU WILL LEARN

  • Hands-on QA experience on products used in real workflows by Creative, UA and internal operations teams.
  • Practical exposure to functional, API, integration, E2E, regression and output validation testing.
  • How to translate product requirements into measurable test scenarios, test cases and acceptance checks.
  • How defect triage, QC testing, release verification and QA release recommendations work in practice.
  • Step-by-step experience with Playwright/TypeScript automation and integrating tests into CI/CD.
