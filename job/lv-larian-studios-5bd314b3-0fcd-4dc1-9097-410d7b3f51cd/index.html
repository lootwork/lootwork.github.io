Larian Studios, обладатель множества наград и создатель Baldur’s Gate 3 и Divinity: Original Sin 2, ищет Junior Web Dev QA Analyst.

ОБЯЗАННОСТИ

  • Тесно сотрудничать с Digital Team, обеспечивая понятную коммуникацию, согласованность и своевременный follow-up назначенных задач.
  • Выполнять testing instructions Digital Team и проактивно помогать с investigations, validation и regression testing.
  • Разрабатывать, поддерживать и улучшать web automation scripts для automated testing.
  • Поддерживать end-to-end automation scripts и стабильность automation framework.
  • Развивать понимание Digital QA workflows и их применения в Digital и Gameplay QA.
  • При необходимости поддерживать Gameplay QA feature testing в зависимости от приоритетов проекта и доступной нагрузки.
  • Выполнять testing instructions и validation regressions от Gameplay QA Team.

ТРЕБОВАНИЯ

  • Хорошее знание HTML и CSS, базовый JavaScript или TypeScript.
  • Способность готовить test cases и test scenarios.
  • Базовое понимание web applications, HTTP и API.
  • Умение пользоваться browser developer tools.
  • Знакомство с cross-browser, cross-platform и cross-device testing.
  • Знакомство с Git concepts: branches, commits, pull, push и merge requests.
  • Сильные навыки коммуникации и эффективного сотрудничества с QA и Digital teams.
  • Проактивность и сильное желание учиться и развивать новые навыки.
  • Способность работать самостоятельно и вести назначенные задачи с минимальным контролем.
  • Сильный интерес к поиску bugs, расследованию issues и созданию качественного user experience через QA practices.

БУДЕТ ПЛЮСОМ

  • Общий опыт Playwright test automation framework.
  • Общее понимание REST APIs и их роли в testing workflows.
  • Знакомство с reporting/task-tracking tools вроде Jira.
  • Общее знание GitLab CI/CD workflows.
  • Знание WCAG Guidelines.
  • Базовое понимание SQL и relational databases, умение писать простые queries для получения данных и пользоваться database administration tools вроде MySQL Workbench или аналогов.

ЧТО МЫ ПРЕДЛАГАЕМ

  • Международную команду из более чем 550 сотрудников в 7 студиях по всему миру, каждая из которых имеет свои особенности и сохраняет атмосферу небольшой студии.
  • Открытую и collaborative-среду, где идеи приветствуются и поощряются.
  • Руководящую команду из очень опытных game developers, ведущих специалистов своих направлений.
  • Возможность разделять хобби и увлечения с единомышленниками.
  • Инклюзивную среду с множеством активностей, организуемых студиями или сотрудниками.
  • Стремление сделать лучшую возможную игру для фанатов, включая внимательное отношение к community feedback.
