О Company

Gemini is a global crypto and Web3 platform founded by Cameron and Tyler Winklevoss in 2014, offering a wide range of simple, reliable, and secure crypto products and services to individuals and institutions in over 70 countries. Our mission is to unlock the next era of financial, creative, and personal freedom by providing trusted access to the decentralized future. We envision a world where crypto reshapes the global financial system, internet, and money to create greater choice, independence, and opportunity for all — bridging traditional finance with the emerging cryptoeconomy in a way that is more open, fair, and secure. As a publicly traded company, Gemini is poised to accelerate this vision with greater scale, reach, and impact.

The Department: Trading Systems

The Role: Senior Software Engineer (Full Stack, React)

We are looking for a Senior Full-Stack Engineer to build and own products across web, mobile, and backend systems. Your primary focus will be developing complex web applications using React and TypeScript. You will also contribute to React Native mobile applications and backend services built with Scala and Go on AWS.

Обязанности

  • Design and deliver scalable web applications using React and TypeScript.
  • Own features from technical design through release, monitoring, and improvement.
  • Define frontend architecture and build reusable components.
  • Contribute to React Native applications for iOS and Android.
  • Develop and integrate backend services using Scala or Go.
  • Make pragmatic technical decisions and communicate trade-offs.
  • Improve performance, accessibility, reliability, testing, and security.
  • Collaborate with product managers, designers, and engineers.
  • Review code, mentor engineers, and improve engineering standards.
  • Use AI development tools effectively while remaining accountable for code quality.

Minimum Qualifications

  • Strong experience with React, TypeScript, JavaScript, HTML, and CSS.
  • Experience building large-scale, production-grade web applications.
  • Strong knowledge of frontend architecture, performance, testing, and accessibility.
  • Solid software engineering and system-design fundamentals.
  • Experience integrating web applications with APIs and distributed systems.
  • Ability and willingness to contribute to React Native and backend development.
  • Proven ownership of complex projects from design to production.
  • Strong communication, technical leadership, and mentoring skills.

Будет плюсом

  • React Native or native mobile development.
  • Backend development with Scala, Go, Java, or Kotlin.
  • AWS, Docker, Kubernetes, Terraform, and CI/CD.
  • REST APIs, event-driven architecture, Kafka, and distributed systems.
  • AI coding agents and AI-assisted development workflows.
  • Financial services, trading, payments, or regulated systems.
