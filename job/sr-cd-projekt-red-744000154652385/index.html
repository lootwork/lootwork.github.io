Job Description

We are looking for a Software Engineer to join the Online Services Team who will help build and evolve web applications and services used across the company. You will work with modern web technologies, independently owning features from implementation through delivery, while collaborating with engineers, cross-functional teams, and external partners. The role offers the opportunity to contribute not only to product development, but also to code quality, performance, technical improvements, and the long-term maintainability of our shared web solutions.

Daily Responsibilities

  • Implementing and maintaining high-quality web applications, services, and supporting systems,
  • Independently delivering features and technical tasks using established architectures, patterns, and engineering practices,
  • Taking ownership of assigned features and technical tasks from implementation through testing and delivery,
  • Collaborating with engineers and cross-functional teams across the company, as well as external partners and vendors when required,
  • Participating in code reviews, technical discussions, troubleshooting, and knowledge sharing within the team,
  • Identifying and implementing improvements to code quality, maintainability, performance, and existing development workflows,
  • Understanding business and user requirements and translating them into appropriate technical implementations,
  • Applying established technologies, frameworks, and engineering practices while developing knowledge of the team's systems and architecture,
  • Contributing to reducing technical debt and improving existing components, services, and shared solutions.

Требования

  • 3 years of professional experience on a similar position in web development.

And practical knowledge of

  • Front-end programming language: JavaScript/TypeScript,
  • Front-end application frameworks: React/Next.js,
  • HTML5, CSS3/SCSS, and browser fundamentals,
  • Common design patterns and application architecture principles,
  • HTTP, REST APIs, and OpenAPI,
  • Automated testing using Jest, Cypress, or similar,
  • Git, Docker, and CI/CD workflows,
  • Dependency and build tooling such as npm/yarn,
  • Authentication and authorization technologies such as OAuth 2.0, OpenID Connect and JWT,
  • Web application security and privacy principles,
  • SEO, accessibility and web performance fundamentals.

Будет плюсом

Familiarity with

  • Back-end programming language: PHP or Go,
  • Back-end application frameworks such as Symfony or similar,
  • SQL and relational databases such as MySQL/PostgreSQL,
  • Cloud and container orchestration concepts,
  • Search, messaging, and data technologies such as Elasticsearch/OpenSearch, RabbitMQ, and NoSQL databases.
