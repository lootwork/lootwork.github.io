Обзор вакансии

Wargaming ищет Render Developer в команду Game Engine Development. Работа включает разработку кроссплатформенного игрового движка, написанного на C++.

Чем вы будете заниматься?

  • Реализовывать новые и улучшать существующие графические функции
  • Выполнять рефакторинг, оптимизацию кода и исправлять графические баги
  • Писать код в соответствии с code style
  • Создавать техническую документацию

Что мы ищем?

  • 2+ года опыта коммерческой разработки на C++
  • Опыт работы с любым graphics API (DirectX, Vulkan, OpenGL)
  • Опыт написания шейдеров (GSL, HLSL)
  • Базовые знания линейной алгебры (векторы, матрицы, кватернионы)
  • Опыт создания собственных 3D demo-приложений или собственного движка
  • Знание и опыт работы с инструментами отладки и профилирования (Nsight, RenderDoc, PIX и т. д.)
  • Понимание graphics pipeline и архитектуры GPU
  • Практическое знание DirectX 11/12/Vulkan

Какие дополнительные навыки помогут выделиться?

  • Английский на уровне Intermediate
