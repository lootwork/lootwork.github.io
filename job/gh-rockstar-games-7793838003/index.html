В Rockstar Games мы создаём развлекательные продукты мирового уровня.

Станьте частью команды, работающей над одними из самых масштабных и вдохновляющих творческих проектов во всей индустрии развлечений — в инклюзивной, мотивированной среде, где можно учиться и сотрудничать с одними из самых талантливых специалистов отрасли.

Rockstar ищет квалифицированного Data Design Analyst, увлечённого видеоиграми и data design.

Это штатная постоянная позиция с полной занятостью и работой из офиса в уникальной студии разработки Rockstar в центре Лондона.

ЧЕМ МЫ ЗАНИМАЕМСЯ

  • Команда Rockstar Games Analytics предоставляет insights и практические результаты широкому кругу стейкхолдеров по всей организации, поддерживая принятие решений.
  • Мы сотрудничаем с несколькими подразделениями компании и используем analytics для измерения и улучшения успеха и состояния наших игр.
  • Как распределённая команда мы совместно создаём инновационные data pipelines, data products, data models, отчёты, анализы и machine learning applications.
  • Функция Data Design внутри Analytics тесно сотрудничает с game development, analytics engineering и data science, проектируя telemetry, которая надёжна, интерпретируема и оптимизирована для downstream data models и pipeline consumption.

ОБЯЗАННОСТИ

  • Сотрудничать с game development, analytics engineering и data science, чтобы понимать игровые системы, product questions и downstream data needs.
  • Проектировать понятные, согласованные и масштабируемые telemetry specifications, точно отражающие player behavior и игровые системы и поддерживающие эффективное потребление data model pipelines.
  • Совместно с Game Data Development превращать аналитические требования в raw telemetry event designs, schemas, naming conventions, validation rules и documentation, которые могут реализовать development teams.
  • Проверять предлагаемые telemetry designs на полноту, качество, согласованность и пригодность для downstream modelling, reporting, experimentation и machine learning.
  • Сотрудничать с analytics engineers, чтобы структура telemetry снижала сложность transformations и повышала надёжность curated data products.
  • Поддерживать telemetry QA команды Data Integrity & Operations, определяя expected behaviors, edge cases, acceptance criteria и validation checks для новой или обновлённой game instrumentation.
  • Поддерживать документацию и design standards, повышающие discoverability, governance и consistency игровой telemetry.
  • Участвовать в развитии best practices для event taxonomy, schema design, metadata capture и lifecycle management telemetry definitions.

ТРЕБОВАНИЯ

  • 5+ лет опыта в analytics, data design, data analysis, product analytics, game analytics или смежной data-focused роли.
  • Степень бакалавра или эквивалентный опыт в количественной, технической, аналитической или design-oriented области.
  • Сильное понимание event-based data, data schemas, data quality principles и того, как raw telemetry используется в downstream analytics и data modelling.
  • Умение превращать неоднозначные вопросы стейкхолдеров в структурированные data requirements и практичные telemetry designs.
  • Знакомство с SQL и большими datasets для исследования, валидации и интерпретации behavioural data.
  • Отличная письменная коммуникация и способность создавать ясные specifications, documentation и guidance для технической и нетехнической аудитории.
  • Высокое внимание к деталям и способность учитывать edge cases, data lineage, implementation constraints и downstream usage patterns.
