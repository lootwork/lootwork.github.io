Senior Technical QA Tester (f/m/d)

Мы ищем Senior Technical QA Tester в берлинскую команду Idle Bank Tycoon. Вы будете отвечать за качество игры end-to-end: от feature testing и test automation до performance profiling и process improvement, работая внутри кросс-функциональной команды вместе с Product, Game Design и Engineering.

Если вам одновременно нравится техническая глубина engineering и ремесло, позволяющее убедиться, что продукт действительно работает для реальных игроков, эта роль может вам подойти.

ОБЯЗАННОСТИ

- Полностью отвечать за features и test coverage: от определения QA flows и edge cases по product requirements до release sign-off и post-release monitoring.

- Проектировать, писать и ревьюить test plans и test maps; проверять материалы других QA и определять QA strategy для сложных features.

- При необходимости выполнять technical QA analysis, включая runtime profiling, memory analysis, CPU/GPU usage и проверку build size на iOS и Android.

- Отслеживать и расследовать regressions: падения frame rate, рост load times, изменения размера APK/IPA между builds.

- Проактивно координировать team playtests и постоянно отслеживать release performance, заранее поднимая red flags.

- Продвигать постоянные улучшения QA process и tooling, вместе с QA manager управляя нагрузкой и приоритетами внутренних и внешних testers.

- Запускать и поддерживать automated test suites на нашей внутренней Test Automation Platform и переводить manual test cases в automated tests.

ОБЯЗАТЕЛЬНЫЕ НАВЫКИ

- Сильная практическая экспертиза manual QA/testing на всём test lifecycle, желательно mobile или gaming.

- Хорошее понимание performance metrics мобильных игр: profiling, memory, build sizes и frame pacing на iOS/Android.

- Опыт test management tools (Xray, TestRail, Zephyr или аналогов) и Agile/Scrum workflows в Jira.

- Опыт координации QA workload между внутренними и внешними testers.

- Знакомство с AI-assisted tooling для testing, triage или workflow automation.

- Базовый Python — достаточно для запуска automated test suites и преобразования manual tests в automation на внутренней платформе.

- Сильная письменная и устная коммуникация на английском между кросс-функциональными командами.

- Проактивность, ownership и уверенность в принятии решений в неоднозначных ситуациях.

ЖЕЛАТЕЛЬНЫЕ НАВЫКИ

- Большой QA-опыт в mobile gaming, особенно F2P/LiveOps.

- Опыт CI/CD tools вроде Jenkins или GitLab.

- Знакомство с Unity.

- Практический опыт mobile profiling tools: Xcode Instruments, Android Profiler или аналогов.

- Знакомство с Firebase, SDK и third-party plugins.

- Базовый SQL и понимание data pipelines.
