Riot ищет execution-focused UI Visual Designer, способного быстро выпускать high-quality interface visuals для R&D-проекта. В рамках заданного UX и art style роль отвечает за visual design/finish игрового UI и тесно работает с UX, motion и client teams. Основной акцент — visual craft, скорость исполнения и production feasibility.

Обязанности

  • Создавать game UI на базе established UX и style direction.
  • Самостоятельно вести wireframe → visual design → high-fidelity UI.
  • Развивать visual system и детали в рамках правил, сохраняя consistency.
  • Создавать UI elements: icons, buttons, panels, decorations.
  • Подготавливать production-ready UI assets, slicing, annotations и component specs.
  • Работать с UX/motion/development до корректной engine implementation.
  • Балансировать visual quality и mobile performance/resource limits.
  • Соблюдать typography, hierarchy и component standards, стабильно держать quality/delivery cadence.
  • Быстро реагировать на feedback и правильно расставлять priorities.

Требования

  • 3+ года game UI visual design; shipped/outsourcing experience предпочтительны.
  • Сильные typography, color, composition и visual hierarchy.
  • Способность адаптироваться к разным styles, особенно stylized.
  • Уверенное владение design tools.
  • Полный UI visual pipeline от wireframes до resource delivery.
  • Basic UX: information hierarchy, readability, interaction fundamentals.
  • Понимание game UI implementation и production feasibility.
  • Надёжный execution/time management и коммуникация.

Будет преимуществом

Stylized UI, mobile projects/adaptation/performance, UI motion fundamentals, icon/component-library design, Unreal UI или Unity UI pipeline, outsourcing/remote collaboration.

Portfolio

2–4 UI cases: screens, buttons/panels/icons, style variations/themes. Важно показать visual quality, consistency и адаптацию к combat/system/monetization screens; полезны motion demos и engine implementation comparisons.

Тип занятости: employment contract с FESCO Adecco.
