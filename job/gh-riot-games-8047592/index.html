我们正在寻找能够高效产出高质量界面视觉，并稳定支持项目研发节奏的执行型设计师。

作为一名UI视觉设计师（Contract），你将加入拳头，参与项目研发阶段的界面视觉设计工作。

你将基于既定产品体验与美术风格，负责游戏内UI界面的视觉设计与细化，与UX、动效及客户端团队紧密协作，确保界面具备良好的视觉表现与可实现性。该岗位更侧重视觉表现能力、执行效率与协作能力，适合具备成熟产出经验的设计师。

岗位职责

UI视觉设计执行

  • 根据既定UX方案与风格方向，完成游戏内UI界面设计
  • 独立完成从线框稿 → 视觉设计 → 高保真界面的完整流程
  • 在明确规范下进行视觉延展与细节设计，保证界面一致性与完成度

风格还原与视觉统一

  • 准确理解项目美术风格，进行高质量视觉还原与设计延展
  • 设计UI元素（图标、按钮、面板、装饰等）
  • 保持界面风格统一，提升整体视觉品质

设计落地与实现支持

  • 输出规范化UI资源（切图、标注、组件说明等），支持客户端实现
  • 与UX、动效及开发团队协作，确保设计效果正确落地
  • 根据实现反馈调整设计，兼顾视觉效果与性能限制（移动端）

规范执行与质量控制

  • 遵循项目UI设计规范（排版、层级、组件规则等）
  • 控制视觉复杂度与资源成本（贴图尺寸、元素数量等）
  • 保持稳定的设计质量与交付节奏

协作与反馈响应

  • 快速理解需求并执行设计任务，按时完成交付
  • 参与设计评审，根据反馈高效迭代方案
  • 在多任务环境中合理安排优先级

任职要求

  • 3年以上游戏UI视觉设计经验，有完整项目或外包经验优先
  • 扎实的视觉设计基础（排版、色彩、构图、层级）
  • 具备良好的UI设计能力，能够快速适应不同风格（尤其风格化方向）
  • 熟练使用设计工具
  • 能独立完成完整UI视觉流程（线框 → 高保真 → 资源输出）
  • 理解基础UX逻辑（信息层级、可读性、交互基础）
  • 了解游戏UI实现流程，具备“设计可落地”意识
  • 良好的执行力与时间管理能力，能够稳定交付
  • 良好的沟通能力，能够高效响应反馈

加分项

  • 熟悉风格化UI设计
  • 有移动端项目经验，了解适配与性能限制
  • 具备UI动效基础理解（如交互反馈、基础动画节奏）
  • 有图标设计或完整UI组件库经验
  • 熟悉UE引擎 UI流程或Unity UI流程
  • 有外包项目或远程协作经验

作品集与材料

  • 提供2–4个UI设计案例（以完成度与执行质量为主）。包含： 界面设计（UI Screens）/ 组件设计（Buttons / Panels / Icons 等） / 风格延展（Variation / Theme）
  • 强调视觉质量与风格一致性（非常重要）
  • 展示对不同类型界面的适应能力（战斗 / 系统 / 商业化等）。如有，请附带： 动效演示（如有）与引擎实现效果对比（如有）
  • 商业项目或外包经验（如有）

用工性质：与专业人事服务公司FESCO Adecco签订劳动合同.
