Описание вакансии

CD PROJEKT RED ищет опытного Expert Animation Programmer в R&D-команду в Ванкувере, British Columbia. Роль сосредоточена на разработке и внедрении передовых next-generation character animation systems, использующих animation generation models. У вас должна быть глубокая экспертиза в animation technology, character rigging и tool development; вы будете играть важную роль в определении будущего character animation в наших проектах. Опыт generative models и machine learning будет плюсом, но не обязателен.

Ключевые обязанности

  • Проектировать, внедрять и поддерживать advanced animation systems и tools, дополняющие generative models для реалистичного character motion.
  • Работать с machine-learning researchers, engineers, animators и game designers, определяя и достигая высокого качества animation features и улучшая workflows.
  • Оптимизировать и debug animation code и systems по usability, performance, memory и stability на нескольких target platforms.
  • Прототипировать новые animation techniques, включая procedural generation и physics-based systems.
  • Наставлять junior programmers и участвовать в code reviews, поддерживая высокие стандарты code quality и documentation.
  • Вместе с lead engineers планировать project milestones и своевременно выдавать качественный результат.

Квалификация

  • 7+ лет game programming с фокусом на character animation systems.
  • Отличное владение C++ и опыт performance optimization.
  • Глубокое понимание real-time 3D animation principles, kinematics (IK/FK) и rigging systems.
  • Сильные математические знания, особенно linear algebra и vector math.
  • Опыт с крупными game engines, например Unreal Engine, Unity или proprietary engines; Unreal Engine предпочтителен.

Будет плюсом

(Обратите внимание: эти навыки не обязательны для отклика на позицию.)

  • Опыт Motion Matching, procedural animation techniques и physics simulation.
  • Знакомство с animation pipelines и DCC tools — Maya, Blender.
  • Опыт выпуска AAA-игры.
  • Знание parallel programming и GPU optimization techniques, например CUDA, compute shaders.
