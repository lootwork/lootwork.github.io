О вакансии

We are looking for Fullstack Engineer to help QVAC application teams develop, review, test, and deliver reliable software with less friction. Your focus will be our desktop and mobile applications and their shared runtime, AI harness, and skills packages. You will build and maintain developer tools, integrate AI agents into engineering workflows, and improve code quality and delivery automation.

This is a hands-on engineering role with room to shape the tooling roadmap. You will work with engineers to identify useful improvements and own them from implementation through adoption and ongoing support. Success means shorter feedback loops, dependable automation, and tools that developers trust and use.

Обязанности

  • Evaluate, integrate, and maintain developer tools and AI agents, including the repository guidance and integrations they need to work effectively.
  • Build and operate agents in CI and scheduled workflows that investigate failures, propose fixes, and give engineers evidence they can act on.
  • Improve automated pull request reviews, evaluating finding accuracy and reducing noise for reviewers.
  • Develop code quality scripts and checks for complexity, function and file size, dependency cycles, and performance regressions. Work with package owners on practical thresholds and targeted refactoring.
  • Improve development environments, testing, and build and release workflows so engineers and agents can verify changes reliably.
  • Prioritize improvements with engineering teams, support adoption through documentation and onboarding, and measure effectiveness, reliability, and operating costs.

Example projects include agents that investigate CI failures, diagnose compatibility and performance regressions, and flag changes that affect package interfaces or architecture. You will choose and refine these workflows with the engineers who use them.
