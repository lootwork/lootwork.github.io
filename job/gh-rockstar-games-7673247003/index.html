В Rockstar Games мы создаём развлекательные продукты мирового уровня.

Станьте частью команды, работающей над одними из самых масштабных и вдохновляющих творческих проектов во всей индустрии развлечений — в инклюзивной, мотивированной среде, где можно учиться и сотрудничать с одними из самых талантливых специалистов отрасли.

Rockstar ищет увлечённого Associate Lead Microsoft Database Engineer, который обеспечит техническое лидерство, будет развивать лучшие практики работы с базами данных и повышать операционное качество глобальной среды SQL Server.

Это штатная позиция с полной занятостью и работой из офиса в штаб-квартире Rockstar в центре Манхэттена, Нью-Йорк.

ЧЕМ МЫ ЗАНИМАЕМСЯ

  • Команда Online Services Database Operations в Rockstar Games — группа разработки, увлечённая развитием и поддержкой технологической платформы, на которой работают онлайн-проекты Rockstar и которая позволяет нам создавать выдающийся игровой опыт.
  • Команда Rockstar Database предоставляет разработческую и операционную поддержку критически важных платформ и сервисов.

ОБЯЗАННОСТИ

  • Руководить и наставлять команду SQL Server Database Engineers, развивая сотрудничество и обмен знаниями.
  • Контролировать состояние, производительность и доступность enterprise-сред SQL Server большого масштаба.
  • Проектировать, внедрять и поддерживать HA/DR-решения с Always On, кластеризацией и best practices для нескольких дата-центров.
  • Развивать автоматизацию регулярных операционных задач для повышения эффективности команды и сокращения ручной работы.
  • Анализировать и оптимизировать запросы, индексы и конфигурации серверов для максимальной пропускной способности и минимальной задержки.
  • Сотрудничать с разработчиками при review database-кода, схем и deployment pipelines.
  • Проверять состояние серверов, error logs и производительность системы, проактивно устраняя потенциальные проблемы.
  • Отвечать за подробную документацию стандартов, процессов и runbooks.
  • Совместно с руководством планировать roadmap, приоритизировать инициативы и согласовывать database operations с потребностями бизнеса.
  • Участвовать в круглосуточной on-call-ротации, предоставляя руководство и поддержку при критических инцидентах.

ТРЕБОВАНИЯ

  • 10+ лет опыта администрирования и разработки Microsoft SQL Server.
  • Подтверждённый опыт руководства или наставничества Database Engineers в enterprise-средах.
  • Экспертное понимание внутреннего устройства SQL Server, performance tuning и troubleshooting.
  • Опыт проектирования HA/DR и решений для нескольких дата-центров.
  • Опыт поддержки крупномасштабных, высококонкурентных и критически важных систем.
  • Уверенное владение автоматизацией database deployments и интеграцией с source control.
  • Продвинутые знания T-SQL и оптимизации запросов.
  • Сильное знание стратегий индексирования, locking, blocking и управления concurrency.
  • Практический опыт performance tuning на уровне хранилища, серверов и ОС.
  • Умение анализировать сложные проблемы производительности и доводить расследование до устранения первопричины.
  • Навыки создания automation scripts и tools.
  • Знакомство с другими БД: MySQL, MongoDB, Redis.
  • Отличные навыки документации, коммуникации и межкомандного сотрудничества.
  • Стратегическое мышление с фокусом на масштабируемости, надёжности и непрерывном улучшении.
  • Высокая мотивация, самостоятельность и способность принимать решения на основе данных.
  • Опыт с PowerBI, SSRS, SSIS или ETL workflows.

БУДЕТ ПЛЮСОМ

Обратите внимание: перечисленные ниже навыки желательны, но не обязательны для подачи заявки.

  • Увлечённость играми Rockstar Games.
  • Знакомство с .NET/C# или разработкой приложений.
  • Опыт с SQL Sentry, SolarWinds DPA или другими инструментами мониторинга.
  • Опыт руководства инициативами нагрузочного тестирования баз данных.
  • Знание Splunk, Datadog или аналогичных observability-платформ.
  • Опыт CI/CD-сред и практик database-as-code.
