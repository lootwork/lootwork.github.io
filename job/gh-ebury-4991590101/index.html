Platform Engineer

Madrid Office - Hybrid: 4 days in the office, 1 day working from home

Senior Platform Engineer (Go / Python / TypeScript)

О роли

The Platform team builds the infrastructure, backend systems and tooling that every engineering team at Ebury builds and ships on.

Because software delivered at this level powers systems across the organization, what you build will be used by engineers in Ebury across all our products..

You'll write production code, own infrastructure, and design the abstractions other engineers use every day.

What you'll work on

  • Building and running the platform on AWS
  • Maintaining and extending our Terraform and tooling module library across AWS and GCP
  • Improving the deploy path: ArgoCD, GitHub Actions developers use to deploy, restart and inspect their services
  • Writing services, controllers and tooling in Go and Python, and TypeScript where developer-facing tools need it
  • Improving observability (Datadog), reliability, security and cost
  • Debugging production issues that span application code, Kubernetes, networking and cloud services
  • Evolve the Platform to an AI Assisted SDLC Platform internally and externally for our product engineers using frontier labs and OSS models.
  • Reviewing code, contributing to architecture decisions, and helping set platform standards

What you'll need

  • 7+ years of software, backend, platform or infrastructure engineering experience
  • Strong production experience with Go, Python or JavaScript/TypeScript, and willingness to work across languages
  • Strong hands-on experience running production workloads on AWS and/or GCP
  • Terraform or similar Infrastructure as Code
  • Containers and Kubernetes in production, at scale.
  • Strong understanding of distributed systems, APIs, networking, concurrency, data consistency and failure modes
  • A track record of building platforms, libraries or core systems that other engineers build on
  • Ability to diagnose complex production issues across applications, infrastructure and cloud services
  • Strong code-review and system-design skills
  • Excellent written and verbal communication in English

Будет плюсом

  • Experience building LLM platforms for AI assisted SDLC
  • Multi-account or multi-region AWS setups, workload identity, policy enforcement
  • Kubernetes cluster lifecycle management, ArgoCD or other GitOps tooling
  • Kafka or other event-driven systems; PostgreSQL, Redis
  • Datadog or OpenTelemetry or other distributed tracing systems experience.
  • Building CLIs, SDKs or internal developer platforms
  • High-volume transactional systems, or fintech/payments experience
  • Open-source contributions
