Основные обязанности

  • Cloud Security Architecture and Hardening

Design, implement, and continuously strengthen security architectures across public cloud environments, including AWS, Tencent Cloud, Huawei Cloud, and Alibaba Cloud. Areas of focus include container isolation, Identity and Access Management (IAM), VPC network segmentation, and security policies.

  • Security Operations and Incident Response

Build and continuously improve cloud security monitoring and operations capabilities, including Security Information and Event Management (SIEM) and Cloud Security Posture Management (CSPM). Detect, investigate, and respond to security incidents, conduct root cause analysis and post-incident reviews, and drive remediation through to closure.

  • Infrastructure Security and Vulnerability Management

Assess and harden cloud compute instances, containers, cloud services, and supporting infrastructure. Develop and enhance host and cloud vulnerability scanning capabilities, and track remediation to completion.

  • Identity and Access Management

Design and maintain cloud IAM and Cloud Access Management (CAM) permission frameworks. Establish lifecycle management policies for credentials, including access keys and secret keys (AK/SK), API keys, and access tokens. Enforce least-privilege access and conduct periodic access reviews.

  • Compliance and Risk Management

Conduct regular security baseline assessments and risk assessments across cloud environments. Produce security compliance reports against industry standards such as CIS Benchmarks, and support internal and external security audits, compliance reviews, and remediation activities.

  • Security Standards and Technical Enablement

Develop and maintain cloud security policies, technical standards, and best-practice documentation. Provide security guidance, technical support, and training to engineering and operations teams to strengthen the organization’s overall cloud security capabilities.

Требования

  • A solid foundation in Linux systems administration, with a strong understanding of networking protocols such as TCP/IP, DNS, and TLS, as well as common network security principles.
  • Familiarity with major public cloud platforms, including AWS, Tencent Cloud, and Alibaba Cloud, with hands-on experience in cloud resource management, security configuration, or operations.
  • An understanding of cloud-native technologies and their security models, with familiarity with Docker, Kubernetes, microservices, serverless architectures, and associated security practices.
  • Familiarity with public cloud IAM/CAM frameworks, with practical experience in permission model design, account governance, key management, or least-privilege implementation.
  • An understanding of common cloud security threats and attack paths, including lateral movement, privilege escalation, server-side request forgery (SSRF), and abuse of the Instance Metadata Service (IMDS).
  • Experience in vulnerability scanning, risk assessment, or security tool integration. Hands-on experience deploying, integrating, and operating Tenable, Orca, or comparable solutions is preferred.
  • Experience managing north–south and east–west traffic, reducing exposed network boundaries, or designing and implementing zero-trust network architectures is preferred.
  • Strong security risk awareness, analytical and problem-solving skills, and effective communication and collaboration abilities, with a demonstrated ability to drive cross-functional security initiatives and remediation efforts to completion.
