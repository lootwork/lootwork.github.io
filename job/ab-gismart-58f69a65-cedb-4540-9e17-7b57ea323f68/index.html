О project

FitMe is a fitness app created for people who want to stay active without long, repetitive workouts. It offers short, easy-to-follow routines that can be done at home with no equipment. FitMe is perfect for busy people who want to maintain their health, boost energy levels, and feel good every day — without going to the gym or spending hours on exercise.

Требования

- Test features against requirements: analyze acceptance criteria, design test scenarios using test design techniques

- Report and prioritize defects: repro steps, screenshots, logs

- Maintain test documentation: checklists, regression notes

- Prepare Release Candidates, validate build stability

- Monitor post-release stability via Crashlytics and analytics events

- Verify localization and content delivery (Strapi, Crowdin)

- Validate JSON configs: flags, values, conditions affecting production

- Set up and validate A/B tests and feature flags for target user segments

- Own quality: assess risks, defend quality decisions, cover edge cases

- Develop and maintain mobile UI autotests

- Debug flaky tests, analyze reports, keep the suite stable

- Use AI tools to speed up writing and review of test scenarios and automation code

- 3+ years in QA, mobile or cross-platform products

- Requirements analysis, test design, risk assessment

- Mobile UI test automation with at least one framework (Espresso, XCUITest, Maestro, Appium)

- Autotest debugging: distinguishing flaky tests from real defects, analyzing reports

- Practical use of AI tools for test scenarios and automation code, with critical review of output

- Understanding of iOS and Android: architecture basics, UI/UX patterns, background behavior, permissions

- iOS Sandbox and Google Wallet: limitations, security policies, testing payment and authorization flows

- Experiance with Crash and analytics tools: Firebase Crashlytics, Firebase Analytics, or similar

- A/B tests and feature flags: GrowthBook, Firebase Remote Config, or similar

- Tools: Charles Proxy, Xcode, Android Studio, Jenkins or other CI/CD
