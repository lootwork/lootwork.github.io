🤖 THE AGENTIC PLATFORM AREA

In 2027, we expect to run more AI agents than we have employees.

Agents already do real work at Alan. They answer members' health questions, resolve support requests, read medical documents, detect fraud, automate operational tasks, and write a large share of our code.

But every team building an agent ends up solving the same hard problems again: how to call models safely with health data, how to give an agent tools and the right permissions, how to know whether a prompt change made it better or worse, how to debug what it did. The result: several agent frameworks and evaluation stacks, each with its own security and compliance story.

The Agentic Platform area was created to fix that. Our mission: make it cheap, fast and safe for every Alaner or crew to build, run and improve agentic products and workflows.

We own the environment agents run in (infrastructure, runtime, evaluation, observability, skills lifecycle), with security, privacy and compliance by design, and the generalist products on top: Hopper and the Agent Studio. Product teams and all Alaners own their agents, skills, and their outcomes. We give them the paved road.

Two crews, one team

- Hopper is every Alaner's AI companion. Five months after it started, 80% of Alaners use it, 3k sessions are created each day, and about 30% of our pull requests are opened from it (watch how we built it https://www.youtube.com/watch?v=hAu7Ngfd0ys).

- AI Product Platform builds the shared blocks every AI product at Alan runs on. For instance, our ops teams now build agents autonomously on our Ops AI Platform (read how https://medium.com/alan/how-we-bootstrapped-an-ai-agents-platform-for-operations-at-alan-fefd87ed6314, watch the talk https://www.youtube.com/watch?v=_pg1ij8k5Rw).

🧩 PROBLEMS YOU'LL ONLY FIND HERE

Run agents at scale

- 🧠 One runtime for every AI product. A shared agent framework, from a single model call to multi-agent workflows with live streaming, and one gateway to every model: routing, failover across providers, quotas and cost per use case built in.

- ⏳ Agent sessions that last for hours. Durable sessions, started from the web, Slack, Linear or GitHub, that survive pod restarts and deploys, and pick up exactly where they left off.

- 📦 Sandboxes at scale. An isolated environment for every agent session and every evaluation, on an infrastructure compliant with sensitive data, with negligible boot overhead.

Make agents trustworthy and proactive

- 🔌 One tool gateway to the whole company. An MCP gateway that connects agents to internal tools and data, external services, computer use, managing identity and credentials.

- 🔐 Agents safely acting on critical data. We give each agent no more than the access it needs. Every tool call goes through identity, permissions, confirmations and audit. No sensitive data leaks.

- 🧪 Evals you can replay in time. Re-run an agent or skill against production as it was at a past point in time, on real data, safely isolated. Anyone can ship knowing their change is an improvement rather than a regression.

- 🔁 Agents and skills that proactively fix themselves. Every run is traced, and every human correction, failed tool call or escalation becomes a prioritized fix that Hopper can apply.

Put agents in everyone's hands

- 📚 Skills as a product. A registry where Alaners and teams publish, share and version their skills, so that nothing needs to be repeated twice.

- ✨ AI that non-engineers can own. Alaners who ship code through Hopper, Operators or Sales who build their own agents or skills in our Studio and operate them from their day-to-day tools.…
