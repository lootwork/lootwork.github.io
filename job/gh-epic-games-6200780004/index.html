What We Do

Что предстоит делать

We're looking for a Principal Al Engineer who builds products that integrate Al into Unreal Engine. You'll design and ship the full stack of systems that let LLMs act inside the engine (from end to end, not just a single layer), bringing depth in game engine architecture, cloud services, and how LLMs actually work.

In this role, you will

  • Design and build LLM-driven agents and tools that operate directly inside Unreal Engine, including engine-side C++/Python tooling and editor scripting
  • Architect and extend the cloud-hosted agent harness, services, and database that mediate between LLMs and the engine
  • Work across the full stack (engine tooling, cloud backend, and the web UI used to drive and monitor agents) to ship end-to-end features
  • Evaluate and integrate emerging LLM capabilities (tool use, multi-agent orchestration, context management) into Epic's engine and pipeline tooling
  • Define technical direction for the reliability, safety, and evaluation of LLM-driven engine automation
  • Partner closely with engine, tools, and backend engineers, and mentor others on both game engine internals and LLM system design

Кого мы ищем

  • Strong software engineering background with hands-on experience in a game engine (Unreal Engine strongly preferred), including engine architecture and tooling/editor scripting
  • Practical experience building or shipping products powered by LLMs (agents, tool-calling, RAG, prompt/context engineering), or a strong conceptual understanding of how LLMs work
  • Experience with cloud-native services and infrastructure: web APIs, databases, and service architecture and deployment
  • Excellent programming skills across C++ (engine-side) and Python and/or a web backend language
  • Ability to work full-stack and reason about tradeoffs across engine code, backend services, and a web front end
  • Excellent written and verbal communication skills
  • BS/MS in Computer Science or a related field
