О команде

As Airwallex’s engineering organization matures, the Infrastructure team builds and scales our globally distributed financial platform. We focus on high availability, security, and cloud scalability while empowering developer productivity across global regions.

Что предстоит делать

- Cloud Network Architecture: Design, build, and optimize highly available, multi-account, and multi-region AWS and GCP cloud network architectures (Layer 3 routing, Transit Gateway, Shared VPC, Cloud Router, Direct Connect).

- Infrastructure as Code (IaC): Automate and manage global cloud network infrastructure using Terraform through Git-driven CI/CD pipelines.

- Hybrid & Cross-Cloud Connectivity: Manage BGP routing, IPsec VPNs, and dynamic cloud routing between public clouds (AWS/GCP), regional POPs, and external banking partners under strict financial regulatory requirements.

- Operational Excellence & Observability: Serve as an escalation point for complex cloud networking issues, improve network visibility, and participate in a global on-call rotation.

- Cross-functional Collaboration: Work closely with Security, DevOps, and Platform teams to build secure Landing Zones and automated network controls.

Требования

1. Cloud & DevOps Experience

- Solid AWS Design Experience: hands-on experience designing and operating AWS network environments at scale (VPC, TGW, Route Tables, Direct Connect, AWS Network Firewall).

- Infrastructure as Code: Proficiency in Terraform (or equivalent IaC tools) for provisioning and automating cloud network components.

- GCP / Multi-Cloud Exposure: Practical experience with GCP networking concepts (Shared VPC, Cloud Router) or multi-cloud environments.

- DevOps Alignment: Familiarity with Linux distributions, scripting (Python or Bash), and CI/CD pipelines.

2. Networking Fundamentals

- Networking Fundamentals: Strong knowledge of core routing and switching, subnetting, TCP/IP, and BGP dynamic routing principles.

- Certification / Experience: Holds or has equivalent hands-on experience equal to Associate-level networking certifications (e.g., CCNA, JNCIA-Junos, HCIA, Aruba ACA, Network+, or AWS Certified Advanced Networking - Specialty / GCP PCNE).

Будет плюсом

- Experience in Fintech, local banking, or high-concurrency/high-availability financial networks with strict information security requirements.

- Familiarity with GCP-preferred architectures

- Advanced certifications (CCNP/JNCIP or AWS Certified Advanced Networking - Specialty).

- AI-assisted workflows and modern operational tools integration.
