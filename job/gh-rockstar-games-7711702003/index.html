В Rockstar Games мы создаём развлекательные продукты мирового уровня.

Станьте частью команды, работающей над одними из самых масштабных и вдохновляющих творческих проектов во всей индустрии развлечений — в инклюзивной, мотивированной среде, где можно учиться и сотрудничать с одними из самых талантливых специалистов отрасли.

Rockstar ищет увлечённого Software Engineer, который воспринимает разработку ПО как ремесло и любит решать сложные задачи в большом масштабе.

ЧЕМ МЫ ЗАНИМАЕМСЯ

  • Команда Rockstar Games Online Services создаёт connected experiences для разных игровых франшиз.
  • Мы создаём online services для игр, включая matchmaking, cloud saves, leaderboards, player inventory, player stats, bounties и многое другое.
  • Мы улучшаем существующие функции и проектируем новые решения для развития Online Services.

ОБЯЗАННОСТИ

  • Разрабатывать высоконагруженные и масштабируемые server-side features с использованием Windows Server, SQL Server, IIS, .NET и C#.
  • Разрабатывать web services для game console clients, browser clients и external server clients.
  • Создавать высоконадёжные distributed server systems.
  • Оптимизировать web performance.
  • Сотрудничать с другими технологическими командами Rockstar во всех студиях мира.

ТРЕБОВАНИЯ

  • 4+ года опыта разработки scalable distributed systems.
  • Экспертное владение C# и/или C++.
  • Сильная база Computer Science, включая отличное понимание OO design patterns и concepts.
  • Опыт API design и development.
  • Знание scalability, performance и security practices web services.
  • Опыт database development на MSSQL.
  • Опыт source control, предпочтительно Perforce.
