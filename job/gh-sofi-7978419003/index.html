Social Finance, LLC seeks Senior Software Engineer in San Francisco, CA:

Job Duties: Lead the development and testing of system components/services, code and design reviews. Participate in shaping the technical architecture of the product. Help translate product requirements into user stories and technical solutions. Delivery highly available and scalable services in a production environment. Mentor other engineers, support the technical culture, and help grow the team. Generate ideas for new initiatives and technologies. Communicate with project leads, production managers and other software developers. Part-time telecommuting is an option. Hybrid work from Social Finance offices in San Francisco, CA.

Requirements: Seven (7) years of experience in the job offered or in a related occupation.

Special Skill Requirements

  • 48 months of experience in: programming experience utilizing a modern technology stack using ReAct, graphQL, springboot, Airflow, Zookeeper, Terraform, Kafka and Flink.
  • 48 months of experience in: Java, Kotlin, Python and JavaScript in-memory data structures, SQL and NoSQL database design.
  • Service-Oriented Architecture (SOA) or microservice based application environment using Docker, Kubernetes and AWS Fargate.
  • AI terminologies, including Large Language Models (LLM) usage in agent development using AWS Bedrocks and Spring AI.
  • modern CI-CD and collaborative coding environments, including using Git for version control, code reviews, and terraform, AWS CDK for continuous development
  • sophisticated testing systems for distributed systems at scale using JUnit.
  • Operational excellence practices and using monitoring tools, including DataDog or AWS Cloudwatch.
  • driving digital transformation initiatives through large-scale service migrations and tech stack modernization using feature gating mechanisms like Optimizely.

Any suitable combination of education, training and/or experience is acceptable. Part-time telecommuting is an option. Hybrid work from Social Finance offices in San Francisco, CA.

Salary: $221,187.00 - $243,305.00 per year.
