Мы ищем Software Engineers, готовых расти вместе с вызовами игр, занимающих верхние позиции чартов.

В тесном сотрудничестве с Game Development Team вы будете проектировать и поддерживать масштабную backend architecture мобильных игр для миллионов игроков. Создавая best-in-class ощущения для пользователей, вы будете решать тысячи инженерных задач.

О РОЛИ

  • Создавать и поддерживать масштабируемые low-latency backend services для game и platform functionality.
  • Анализировать и повышать эффективность, масштабируемость и стабильность системы.
  • Обеспечивать и улучшать game performance, reliability и security.
  • Участвовать во всех аспектах game development.
  • Тесно работать со Studio Team — product managers, game developers и artists — создавая лучший опыт для пользователей.

ВЫ ОТЛИЧНО НАМ ПОДОЙДЁТЕ, ЕСЛИ

  • Степень бакалавра по Computer Science и 2+ года опыта Software Engineer.
  • Глубокое понимание backend systems на Java Spring Boot, Java и связанных технологий.
  • Знакомство с Java, Spring, Redis и AWS Cloud Systems; сильные engineering skills и фундаментальные знания программирования.
  • Знание software architecture design, OOP и design patterns.
  • Страсть к мобильным играм, готовность играть в них и особое внимание к деталям и качеству кода.

ДОПОЛНИТЕЛЬНЫЙ ПЛЮС, ЕСЛИ

  • Вы играли в Tasty Match: Cook and Puzzle и знакомы с игрой. Если нет — сейчас отличный момент начать!
  • Вам интересна игровая индустрия и вы хотите узнавать о ней больше.
  • Вам нравится работать в быстро меняющейся, динамичной среде.

ПРЕИМУЩЕСТВА

  • Работа в сильной команде, возможность учиться у лучших и создавать игры, которые любят игроки.
  • Конкурентная компенсация.
  • Медицинская страховка с неограниченным покрытием.
  • Красивый и удобно расположенный офис в самом центре Стамбула.
  • Возможность посещать международные конференции и оставаться в центре событий индустрии.
  • При необходимости — помощь с релокацией, чтобы переезд прошёл максимально просто.
