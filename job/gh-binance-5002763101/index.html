Обязанности

  • Collaborate closely with design, backend, and product teams to thoroughly understand business requirements and translate them into effective, high-quality frontend solutions.
  • Develop fast, user-friendly web applications compatible with both desktop and mobile browsers by writing clean, efficient client-side code.
  • Design and build reusable libraries and frameworks that support complex web applications, accelerate development workflows, and enhance overall code quality.
  • Optimize web applications to ensure maximum performance, scalability, and responsiveness.

Требования

  • Strong proficiency in React.js with hands-on experience building complex, high-performance web applications.
  • Solid foundation in JavaScript, including thorough knowledge of ES6+ features and best practices.
  • Skilled in TypeScript, capable of leveraging static typing to improve code quality and maintainability.
  • Deep understanding of component-based architecture, state management, and React Hooks.
  • Familiarity with frontend performance optimization techniques, including code splitting, lazy loading, and caching strategies.
  • Proficient with frontend build tools and workflows such as Webpack, Babel, ESLint, and Prettier.
  • Strong code quality awareness, emphasizing readability, modularity, and reusability.

  • Familiarity with ethers.js / web3.js
  • Have experience of building Web3 App
