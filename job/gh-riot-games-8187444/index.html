岗位定位

我们希望找到一位对游戏、玩家体验和声音设计充满热情的游戏音频设计师。

你将与游戏设计、美术、叙事、动画、工程等团队紧密合作。

这不仅是一个“制作声音资产”的岗位。你需要理解为什么需要这个声音、玩家什么时候听到它，以及它如何服务于玩法和体验。

主要职责

  • 负责游戏中音效的设计、制作与实现。
  • 根据玩法目标和玩家体验，建立清晰、有辨识度且具有情绪表现力的声音语言。
  • 参与游戏音乐设计。
  • 使用 Wwise / FMOD / Unreal / Unity 或内部引擎完成音频资产的游戏内实现。
  • 设计音乐与音效的state、Transition、Layer、Trigger及其他交互逻辑。
  • 与 Game Design、Art、Narrative、Animation、Engineering 等团队合作，将抽象体验目标转化为可执行的音频方案。
  • 在保证艺术品质的同时，关注玩法信息传达、声音层级、可读性以及游戏性能。
  • 主动根据玩家反馈、测试结果和团队反馈持续迭代。
  • 与外部作曲家、录音师、音频供应商等合作，并能够提供明确、有效的创作反馈。

任职要求

  • 具备成熟的游戏音效设计与制作能力，能够独立完成从概念到游戏内落地的完整流程。
  • 熟练使用主流 DAW 及声音设计工具，如 Pro Tools、Reaper、Nuendo、Ableton、iZotope 等。
  • 熟悉 Wwise / FMOD 等音频中间件，并具备实际游戏项目实施经验。
  • 理解游戏引擎中的音频工作方式，具备 Unreal、Unity 或其他商业/自研引擎经验。
  • 对Gameplay Feedback、声音层级、空间音频和交互式音频系统有深入理解。
  • 能够理解产品和设计目标，而不是仅从单一声音资产的品质出发进行设计。
  • 具备良好的跨职能沟通能力，能够清晰表达设计意图，并处理来自不同专业方向的反馈和分歧。

我们尤其看重

  • 能够从玩家体验而不是单纯从音频专业角度判断方案。
  • 能够解释自己的设计决策，而不仅仅依赖个人审美。
  • 面对设计、工程或制作限制时，能够找到体验、品质和成本之间的合理平衡。
  • 能够主动发现体验问题，并推动相关团队一起解决。
  • 对反馈开放，同时拥有明确的专业判断和设计立场。

加分项

  • 参与过完整上线的 PC / Console / Mobile 游戏项目。
  • 熟悉交互式音乐设计及实时音乐系统。
  • 具有作曲、编曲或乐器演奏能力。
  • 具有 Voice Over 制作、录音及后期经验。
  • 具备基础 Blueprint / Lua / Python 或其他脚本能力。
  • 有大型全球化团队或跨地区协作经验。

作品集要求

作品集建议包含：

  • 游戏内实际音效设计案例
  • Gameplay Feedback 音频案例
  • 环境及空间声音设计
  • 交互式音乐或音乐系统案例
  • Wwise / FMOD / 游戏引擎内实现案例

我们尤其希望看到的不只是最终 Demo，而是：

设计目标 → 音频思路 → 游戏内实现 → 最终玩家体验

并请明确说明每个案例中你本人负责的具体部分。
