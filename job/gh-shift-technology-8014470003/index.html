The Software Engineering Team 💻

The Software Engineering team designs, builds, and maintains the applications and services that Shift’s teams rely on every day. We are Software Engineers working across the full stack, from user interfaces to back-end services. Here are just a few of the areas we work on:

  • Front-end applications and user interfaces, mainly in React;
  • Back-end services and APIs, mainly in C#;
  • Internal tools that make the daily work of our Data Scientists simpler and faster;
  • Software architecture, code quality, and reliable delivery to production;
  • Close collaboration with Product, UX, and Data Science teams to turn real needs into working software

Working closely with Product managers, UX designers, and Data Scientists, we take end-to-end ownership of what we build: from understanding the need and designing the solution to developing, deploying, and improving it over time.

Your key responsibilities🧑‍💻

You’ll lead the development of an internal project, from the first idea to a working product: a tool that helps our Data Scientists create and manage the JSON configuration files of Shift’s product features. Today these files are written by hand and are hard to read and maintain. You’ll build an interface where users select the values they need, and the tool generates the files for them. The scope is open, so you will shape it with your users. You’ll be responsible for:

  • Meeting our internal clients, the Data Scientists, to understand how they work today and define what the tool should do
  • Working with Product and UX teams to turn these needs into clear requirements and a simple user experience, without ready-made mock-ups
  • Designing and building the front end of the tool in React, so that users can select values and see clear, guided options for each feature
  • Developing the back-end services that validate the choices and generate the JSON configuration files
  • Sharing your progress with developers and stakeholders, and collecting feedback to improve the tool
  • Deploying the tool and maintaining it, so that it keeps saving time for the Data Science teams

Along the way, you’ll discover how Engineering, Product, UX, and Data Science work together, and what the role of a developer is across all these technical jobs. This is a project you will own: you’ll learn to manage it, communicate about it, and deliver it.

  • Your profile and requirements✅:

  • You have solid skills in React and/or C#, and you understand Object-Oriented Programming (OOP). Experience with another language, such as Java, is welcome if you are ready to learn ours.
  • You have a strong engineering mindset, with an interest in code quality, software design, and building both front-end and back-end features.
