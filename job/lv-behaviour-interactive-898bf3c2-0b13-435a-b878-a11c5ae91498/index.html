Behaviour is looking for a Senior Backend Programmer to join our internal R&D team and help build the tools and services that production teams rely on every single day. In this role, you'll design systems that reduce time-to-production, empower developers across the studio, and run reliably at scale. The kind of behind-the-scenes work that quietly makes everything else possible.

If you enjoy solving backend problems, care deeply about clean architecture and want your code to have a studio-wide impact, we'd love to hear from you.

В этой роли вы будете

  • Design, build, and maintain advanced backend services and operational systems;
  • Define technical specifications and requirements before developing new features and services;
  • Diagnose and resolve issues to improve application stability, code quality, and CI/CD pipeline robustness;
  • Collaborate closely with other developers to deliver scalable, production-grade services;
  • Develop, execute, and analyze functional to ensure performance and reliability.

Кого мы ищем

  • Minimum of 5 years of backend development experience in Python;
  • Strong, hands-on expertise in the AWS ecosystem, including services like Lambda, ECS, API Gateway, RDS, DynamoDB, S3, and CloudWatch;
  • Solid grasp of REST APIs, WebSockets, and modern software architecture principles;
  • Experience with Linux environments, server performance optimization, and secure client-server development;
  • Experience with CI/CD practices and tools such as GitLab Pipelines, Jenkins, or GitHub Actions;
  • Experience with Infrastructure as Code tools like Terraform, Pulumi, or CDK;
  • Knowledge of relational and NoSQL databases, including data modeling and performance considerations.

DANS CE RÔLE, TU DEVRAS

  • Concevoir, bâtir et maintenir des services backend avancés ainsi que des systèmes opérationnels;
  • Définir les spécifications techniques et les exigences avant de développer de nouvelles fonctionnalités et services;
  • Diagnostiquer et résoudre des problèmes afin d'améliorer la stabilité des applications, la qualité du code et la robustesse des pipelines CI/CD;
  • Collaborer étroitement avec d'autres développeurs afin de livrer des services évolutifs, de qualité production;
  • Développer, exécuter et analyser des tests fonctionnels afin d'assurer la performance et la fiabilité.

CE QUE NOUS RECHERCHONS

  • Minimum de 5 ans d'expérience en développement backend en Python;
  • Expertise solide et pratique de l'écosystème AWS, incluant des services comme Lambda, ECS, API Gateway, RDS, DynamoDB, S3 et CloudWatch;
  • Solide compréhension des API REST, des WebSockets et des principes modernes d'architecture logicielle;
  • Expérience avec les environnements Linux, l'optimisation de la performance des serveurs et le développement sécurisé client-serveur;
  • Expérience avec les pratiques et outils CI/CD tels que GitLab Pipelines, Jenkins ou GitHub Actions;
  • Expérience avec des outils d'infrastructure as code tels que Terraform, Pulumi ou CDK;
  • Connaissance des bases de données relationnelles et NoSQL, incluant la modélisation des données et les considérations de performance.
