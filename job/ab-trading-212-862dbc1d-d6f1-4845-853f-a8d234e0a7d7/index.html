Что предстоит делать

- Design and deploy dynamically scalable, self-healing infrastructure and applications in public and private cloud environments.

- Striving to constantly improve and automate the infrastructure design in order to achieve better resilience and scalability.

- Use IaaS automation tools like Terraform, AWS CloudFormation and Ansible.

- Migrate environments from on-premise infrastructure to AWS/GCP environments.

- Evaluate application and infrastructure KPIs and proactively mitigate bottlenecks and possible issues.

- Design zero-downtime infrastructures.

- Continuous performance improvement and troubleshooting of critical components.

- Learn from your colleagues and share your knowledge with them. We have to grow as the company grows and mutual honest feedback is one of our most reliable weapons.

WHAT YOU NEED TO HAVE

- Expertise in public cloud - AWS/GCP.

- Deep understanding of the DevOps principles and their implementation in different workflows. Previous experience with CI/CD services - GitHub/GitLab or Jenkins.

- Experience with containers and container orchestration systems - Docker, Kubernetes, EKS/ECS, Nomad.

- Good understanding of Infrastructure as Code - Terraform, AWS Cloudformation.

- Implementation and maintenance of configuration management tools - Puppet, Ansible.

- Expertise in RDBMS - AWS RDS, MySQL/MariaDB/PostgreSQL, TimescaleDB.

- Understanding of Messaging Services - Amazon MSK, Amazon MQ, Kafka, RabbitMQ.

- Strong knowledge of Python and Bash scripting.

Будет плюсом

- Experience with on-premise private cloud infrastructures running VMware or KVM.

- Good understanding of networking and security concepts (TCP/IP, routing, firewalls, DDoS mitigation and prevention).

- Previous experience in an operations role, R&D experience.

- Experience with PCI-DSS and ISO 27001 compliance.

OUR TECH STACK

- Public cloud - AWS and GCP

- Infrastructure-as-Code and configuration management - Terraform, Ansible, Puppet

- CI/CD - GitHub

- Web Servers and Load Balancing - NGINX, Envoy, AWS NLB/ALB, HAProxy

- Containers and orchestration - Docker, Kubernetes, AWS EKS/ECS

- Databases - Amazon RDS (MariaDB/PostgreSQL), TimescaleDB, Amazon Aurora, ClickHouse

- Messaging services - Amazon MSK, RabbitMQ

- Monitoring and logging - Grafana, Telegraf, Prometheus, VictoriaMetrics, ELK Stack, OpenTelemetry

- Private cloud - VMware and KVM
