Кто вы

31st Union is seeking a Senior AI Tools Engineer to join our core Tools team. You will be the studio's expert on AI tooling. You'll design, build, and maintain the internal agent tools and workflows that speed up how our studio makes games. You'll evaluate models, define processes, and build the harnesses our teams use every day.

Обязанности

  • Build AI agent tools and infrastructure that speed up our game development pipeline.
  • Integrate LLM workflows into Unreal Engine and our studio toolchains.
  • Review, maintain, and upgrade harnesses, skills, and MCP servers.
  • Measure and tune context usage, prompting strategies, and token cost.
  • Collaborate with Engineering, Art, and Design to solve creative workflow challenges.
  • Train teams as they adopt agent tools, and document best practices.

Required Qualifications

  • 5+ years of tools or engine programming experience.
  • Shipped at least one AAA console or PC title.
  • Bachelor's degree in Computer Science, or equivalent experience.
  • Strong C++ skills and production experience with Unreal Engine.
  • Proficiency in Python for API integration and automation.
  • Hands-on experience building with LLM APIs or agent tooling. Personal projects count.
  • Experience working with artists and designers to iterate on tools and workflows.

Preferred Experience

  • Production experience building agent harnesses, skills, or MCP servers.
  • Agent orchestration: tool use and multi-agent workflows.
  • Weighing LLM options on cost, quality, and speed.
  • Integrating tools with version control and CI on large game projects.
  • Performance analysis of tools and pipelines.
