Кого мы ищем

Мы ищем Senior Engineer, увлечённого server-side development, в команду NBA 2K. Вы возьмёте ownership в широком техническом спектре — distributed systems, large-scale computing и эффективные databases — для создания высокопроизводительных backend services. Ваша работа напрямую повлияет на online experience одной из самых популярных спортивных игровых франшиз мира. Позиция подчиняется Lead Director of Programming.

Что вы будете делать

  • Работать над backend architecture и services, поддерживающими online features NBA 2K.
  • Проектировать и оптимизировать distributed systems для scalability, reliability и fault tolerance.
  • Создавать и поддерживать large-scale computing solutions для миллионов одновременных игроков.
  • Разрабатывать эффективные database structures и queries для высокообъёмных real-time transactions.
  • Создавать high-performance backend services с фокусом на low latency и stability.
  • Работать с engineering и design teams над бесшовным online gameplay experience.

Кто отлично подойдёт

  • 5+ лет professional software development с сильным фокусом на backend/server-side systems.
  • Сильный C++ и хорошее понимание OOP.
  • Владение одним или несколькими scripting languages — Python, PHP, Perl или Ruby; Python предпочтителен.
  • Понимание distributed и scalable systems.
  • Подтверждённый опыт multithreaded programming и обеспечения эффективности/стабильности крупномасштабных real-time environments.
  • Способность исследовать, оценивать и интегрировать emerging technologies и trends для развития команды, platform performance и product innovation.
  • BS в Computer Science или эквивалентный опыт large-scale software development.
  • Большим плюсом будет опыт secure transaction systems, включая virtual currency и account-based features.
  • Навыки database optimization, включая connection management и query performance tuning.
  • Знакомство с online gaming architectures и service design для live connected player experiences.
  • Знание SQL databases: MySQL, Microsoft SQL Server или аналогов.
  • Опыт console game development будет серьёзным преимуществом.
  • Любовь к видеоиграм, не только нашим.
