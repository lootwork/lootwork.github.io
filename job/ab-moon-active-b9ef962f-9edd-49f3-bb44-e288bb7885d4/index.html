Moon Active — одна из самых быстрорастущих mobile game companies мира, развлекающая миллионы активных пользователей. Штаб-квартира расположена в центре Тель-Авива.

Мы ищем талантливого IT Infrastructure & Cloud Engineer, который будет отвечать за корпоративную IT и Cloud infrastructure.

Вы будете предлагать, внедрять и разворачивать новые решения, одновременно поддерживать существующую infrastructure и следить, чтобы все системы находились в оптимальном состоянии и предоставляли нашим клиентам лучший сервис.

Обязанности

  • Отвечать за запросы из бизнеса, связанные с глобальной корпоративной on-premise и cloud infrastructure: servers, storage appliances, active network equipment, firewalls, cloud services, cloud automations, CI/CD и другие инициативы.
  • Проектировать и контролировать интеграцию core services и platforms: AWS, Google Cloud и Workspace, Okta, Cloud Backups, Zero Trust Network Access (ZTNA), Secure Web Gateway, cloud-based EDR и другие современные технологии.
  • Возглавлять стратегию, внедрение и governance GenAI tools и platforms по всей компании с фокусом на process improvement, создание внутренних AI agents и организационную AI transformation.
  • Руководить architectural design и deployment масштабируемой, надёжной и безопасной corporate infrastructure с акцентом на Infrastructure as Code (IaC) для управления on-premise и cloud environments.
  • Определять network policies и procedures, включая design, planning новых communication systems и monitoring, чтобы обеспечивать качественный сервис глобальным офисам.
  • Сотрудничать с security team при внедрении technology и security policies, защищая systems и data от потенциальных угроз.

Требования

  • Минимум 2 года практического опыта System Administrator, IT Infrastructure Engineer, Junior DevOps, Platforms Engineer или аналогичной роли.
  • Опыт cloud services (AWS/GCP), включая compute, storage, databases, networking, security и monitoring.
  • Практический опыт внедрения GenAI, включая создание и governance AI agents/bots для enterprise use cases.
  • Опыт design и deployment масштабируемых infrastructure solutions с Infrastructure as Code tools вроде Terraform, CloudFormation или Ansible.
  • Экспертиза интеграции и automation business workflows.
  • Практический опыт networking, wireless, routing, switching, enterprise firewalls и VPN.
  • Практический опыт администрирования Linux servers: CentOS, Ubuntu или Red Hat.
  • Опыт scripting languages: Bash, Python, PowerShell.
  • Высокая customer orientation и исключительные communication skills для эффективной работы с сотрудниками в динамичной среде.
  • Свободный иврит и английский.

Преимущества

  • Знакомство с Kubernetes.
