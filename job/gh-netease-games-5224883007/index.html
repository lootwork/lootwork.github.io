Position Overview：

Responsible for localization quality assurance of the product in overseas target markets, ensuring localized text is accurate, contextually natural, culturally adapted and free of dissonance. The last line of defense for "copy-as-product" quality in overseas publishing.

Responsibilities：

  • Conduct language and functional testing of localized versions of in-game text, UI, events and narratives
  • Review translations from a native target-market perspective; correct stiff translations, cultural inappropriateness and tone deviations
  • Log and track localization bugs (text truncation / variable misplacement / encoding issues / contextual errors)
  • Verify text consistency and compliance across language / region versions (e.g., rating language)
  • Coordinate with localization and worldview/narrative teams; provide feedback on how narratives land in target languages

Требования

  • Currently enrolled or fresh graduate; majors in Language / Translation / Media / Game / Digital Media preferred, any major acceptable
  • Native-level proficiency in target-market languages (English, and/or French / German / Spanish / Portuguese and other European / American languages)
  • Sensitive to target-market culture, slang and gaming terminology
  • Meticulous and patient with strong quality awareness; able to log issues systematically
  • Casual / merge game player experience preferred

Будет плюсом

  • Experience in localization / translation / QA / game testing
  • Second or third language proficiency to cover multilingual testing
  • Familiarity with localization tools or bug tracking systems (e.g., Jira)
