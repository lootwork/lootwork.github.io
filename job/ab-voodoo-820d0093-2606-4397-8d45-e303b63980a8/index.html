关于 VOODOO

Voodoo 成立于2013年，总部位于法国巴黎，是一家以“用娱乐点亮世界”为使命的全球领先娱乐科技公司。我们通过打造标志性的手机游戏和应用，持续影响全球数亿用户的日常娱乐体验。目前公司在全球范围内拥有约1000名员工，年收入近8亿美元。公司旗下拥有Paper.io http://公司旗下拥有Paper.io、Mob Control、Hole.io http://Hole.io、Marble Sort、Castle Buster等经典爆款游戏，以及BeReal、Wizz等热门社交应用。累计下载量已突破80亿次，每月活跃用户超过2亿，是全球下载量排名第三的移动发行商（仅次于Google和Meta）。

工作地点：北京（成都可协商），需全职到岗办公。

团队介绍

Voodoo 游戏团队汇聚了混合休闲、休闲和中重度游戏领域的专家。其中，“Core ”游戏团队与全球内部及外部工作室合作，创造、开发并发行新的爆款游戏；“Live” 游戏团队则专注于提升现有成功产品的长线运营。

我们正在北京组建一个全新的中重度游戏工作室。团队小而精，由前后端研发、策划和美术组成，并由 Voodoo 欧洲的工作室及美术团队提供支持，共享工具和经验。你将在项目起步阶段加入，深度参与并影响游戏的美术表现和团队的内容生产方式。

岗位职责

作为 2D 美术设计师，你将负责游戏中角色、建筑和场景等核心美术内容的设计与绘制。

1. 负责英雄等角色的设计与绘制，包括立绘、头像及不同等级的外观变化；

2. 制作等距视角（斜 45 度）的建筑和场景元素，以及图标等游戏内 2D 资源，确保资源规范、可直接接入 Unity；

3. 遵循并参与确立游戏的美术风格；

4. 与开发配合，在 Unity 中完成资源接入，并根据游戏内实际效果迭代调整；

5. 参与搭建美术生产流程，沉淀资源规范和文档，支撑大批量资源的高效产出；

6. 在保证品质的前提下，保持稳定的产出节奏；

7. 逐步参与运营活动、新功能和新玩法模式的美术制作。

任职要求

1. 本科及以上学历，5 年以上游戏美术经验，至少参与过 1 款已上线的手游项目；

2. 全能型 2D 美术，角色、建筑、场景元素、图标等各类资源均能独立完成，绘制功底扎实；作品集需体现可直接用于游戏的成品；

3. 熟悉 2.5D 等距视角（斜 45 度）的建筑与场景绘制，能处理好透视、比例和遮挡关系；

4. 有大批量资源量产经验，能在统一风格下高效产出系列化资源，如同一建筑或角色的多个等级外观、成套图标等；

5. 熟悉移动端 2D 资源规范（如图集打包、尺寸控制、命名规范等），有为 Unity 准备资源或自行接入资源的经验；

6. 能遵循并延展既定美术风格，在手机小屏上保证画面清晰、辨识度高；做事有条理、交付可靠，乐于接受反馈和反复迭代。

加分项

- 有中重度手游项目经验；

- 有地块（Tile）类地图素材或大场景拼接素材的制作经验；

- 有 2D 动画制作经验（如 Spine）；

- 有运营活动美术经验，如活动主视觉、礼包和商城界面等；

- 熟练使用 AI 绘图工具辅助创作和提效；

- 英语加分但非必需，可全程中文面试。
