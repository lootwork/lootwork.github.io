关于 VOODOO

Voodoo 成立于2013年，总部位于法国巴黎，是一家以“用娱乐点亮世界”为使命的全球领先娱乐科技公司。我们通过打造标志性的手机游戏和应用，持续影响全球数亿用户的日常娱乐体验。目前公司在全球范围内拥有约1000名员工，年收入近8亿美元。公司旗下拥有Paper.io http://公司旗下拥有Paper.io、Mob Control、Hole.io http://Hole.io、Marble Sort、Castle Buster等经典爆款游戏，以及BeReal、Wizz等热门社交应用。累计下载量已突破80亿次，每月活跃用户超过2亿，是全球下载量排名第三的移动发行商（仅次于Google和Meta）。

团队介绍

Voodoo 游戏团队汇聚了混合休闲、休闲和中重度游戏领域的专家。其中，“Core ”游戏团队与全球内部及外部工作室合作，创造、开发并发行新的爆款游戏；“Live” 游戏团队则专注于提升现有成功产品的长线运营。

我们正在北京组建一个全新的 4X 游戏工作室。团队小而精，由前后端研发、策划和美术组成，并由 Voodoo 欧洲的工作室及美术团队提供支持，共享工具和经验。你将在项目起步阶段加入，深度参与并影响游戏的美术表现和团队的内容生产方式。

岗位职责

作为 2D 美术设计师，你将负责设计和绘制玩家用来建立帝国的英雄、兵种、建筑和世界。

1. 负责游戏中角色、英雄和兵种的设计与绘制；

2. 制作建筑、大地图元素、图标及其他游戏内 2D 资源，确保资源规范、可直接接入Unity；

3. 遵循并参与确立游戏的美术风格；

4. 与开发配合，在 Unity 中完成资源接入，并根据游戏内实际效果迭代调整；

5. 参与搭建美术生产流程，并沉淀相关规范文档；

6. 在保证品质的前提下，保持稳定的产出节奏；

7. 逐步参与运营活动、新功能和新玩法模式的美术制作。

任职要求

1. 本科及以上学历，5年以上游戏美术相关经验。

2. 有已上线手游项目的 2D 美术经验，有 SLG/4X 或中重度游戏项目经验者优先；

3. 全能型 2D 美术，角色、建筑、场景元素、图标等各类资源均能独立完成，绘制功底扎实；作品集需体现可直接用于游戏的成品；

4. 能遵循并延展既定美术风格，保证画面清晰、有吸引力；

5. 有为 Unity 准备资源或自行接入资源的经验；有 2D 动画经验者加分；

6. 做事有条理、交付可靠，能适应美术生产流程，乐于接受反馈和反复迭代；

7. 英语加分但非必需，可全程中文面试。

工作地点

北京，全职线下办公（成都可议）。
