Toast creates technology to help restaurants and local businesses succeed in a digital world, helping business owners operate, increase sales, engage customers, and keep employees happy.

As a Full-Stack Engineer you will have an opportunity to develop interactive web experiences and build and expand on the Toast Marketing web properties, focusing on our customer online learning experience. The ideal candidate will “lean” to the front-end and possess strong communication in order to be able to effectively deliver on cross-team marketing initiatives.

A day in the life (Responsibilities)

While it is critically important to understand the “how” as a Full-Stack engineer on the marketing team, it is equally important to understand the “why” behind the projects you will be working on. You’re a perfect fit for this role if you are a detail-oriented problem solver, who can work and contribute to the marketing team not only as a developer, but as a resource to help provide feedback and insights into how we meet and exceed our team goals.

  • Develop, test, and deliver clean, production-ready code
  • Build fast, scalable websites and apps using React, Gatsby, and Tailwind CSS
  • Build API integrations to fuel content production
  • Build and maintain a clean and lightweight code repository for all production code
  • Develop and maintain front-end components using our internal design system
  • Ensure sites are accessible, performant, SEO/AEO-friendly, and responsive across all devices
  • Collaborate with project managers, web team members, and other Toast stakeholders as required
  • Help shape technical decisions, tooling, and best practices within the team
  • Participate in code reviews and provide feedback to peers

What you'll need to thrive (Requirements)

  • Proficiency in JavaScript, HTML, and CSS
  • Strong experience (6-8yrs) with React and its ecosystem
  • Strong Experience with Gatsby and its core concepts (e.g., static site generation, GraphQL).
  • Experience with Tailwind CSS and its utility-first approach
  • Excellent problem-solving and communication skills
  • Ability to communicate clearly and professionally
  • CMS Experience – having integrated website designs with a headless CMS
  • Understanding of REST API usage best practices
  • Experience building for multiple regions/languages
  • Strong understanding of web application security principles and best practices
  • Strong knowledge of git, and an understanding of code repository best practices
  • Ability to accurately estimate the time required for a project and keep to timelines
  • Proficiency in rapid prototyping and technical problem-solving using AI-assisted workflows, without comapromising on system reliability or test coverage.

Bonus Ingredients

  • Familiarity with basic backend concepts (Node.js, APIs, serverless functions, etc.)
  • Experience with CI/CD pipelines
  • Experience creating data models
  • Familiarity with Contentful (content modeling, plugins, structured content, etc.) or a comparable CMS
