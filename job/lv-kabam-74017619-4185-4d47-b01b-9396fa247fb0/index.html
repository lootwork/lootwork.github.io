В Kabam мы постоянно поднимаем планку качества free-to-play игр. Мы нанимаем людей за страсть к делу и разнообразие взглядов, чтобы общая сила команды складывалась из навыков каждого. Наши команды объединяют разные характеры и интересы, но их связывают сотрудничество, любовь к весёлой атмосфере и готовность делать всё необходимое для создания отличных игр. И именно здесь нужны вы…

Мы ищем человека, увлечённого созданием и поддержкой сложных игровых систем и инструментов. Работая вместе с другими инженерами и дизайнерами, вы получите значительное влияние на направление игр Kabam. Если вас вдохновляет лидерство и решение сложных задач, эта позиция для вас!

Это позиция с полной занятостью и работой в офисе нашей студии в Монреале 5 дней в неделю.

В ЭТОЙ РОЛИ ВАС ЖДЁТ

  • Проектировать архитектуру одних из самых продвинутых модульных gameplay-систем: надёжных, гибких и высокопроизводительных.
  • Преобразовывать требования в technical designs и выбирать подходящие технологии, frameworks и стратегии cloud infrastructure.
  • Оценивать и выбирать инструменты, библиотеки и технологии под цели проекта.
  • Обеспечивать scalability, performance, security и maintainability software design и базовой server infrastructure.
  • Сотрудничать с кросс-функциональными командами для сбора требований и определения технических спецификаций.
  • Соблюдать и рекомендовать coding standards и best practices для качественного и поддерживаемого кода.
  • Итеративно улучшать software на основе feedback, testing и performance analysis.
  • Проектировать, разворачивать и управлять cloud infrastructure (например, AWS, GCP) через Infrastructure as Code (IaC) для масштабируемых backend services.
  • Проектировать, внедрять и поддерживать надёжные CI/CD pipelines для автоматизации тестирования, deployment и обновлений game servers/API без downtime.
  • Анализировать и отлаживать сложные software и infrastructure issues, определять root cause и внедрять эффективные решения.
  • Проводить тщательное тестирование и verification, обеспечивая соответствие функциональным и нефункциональным требованиям.
  • Исследовать и устранять performance bottlenecks, оптимизировать software и внедрять real-time monitoring и alerting systems (например, Datadog, Prometheus).
  • Работать с product managers, designers и другими engineers над крупномасштабными software solutions.
  • Документировать software designs, код, infrastructure topology и технические процессы для понимания, поддержки и будущего развития.
  • Активно участвовать в code reviews и давать конструктивный feedback для улучшения codebase.
  • Реализовывать server-side logic, включая API, databases, authentication systems и data processing pipelines.

ДЛЯ УСПЕХА В ЭТОЙ РОЛИ НУЖНО

  • Степень бакалавра Computer Science, Engineering или эквивалентный опыт.
  • 10+ лет опыта software development, желательно в gaming.
  • Сильный опыт JavaScript, TypeScript или C#.
  • Глубокое понимание software engineering и back-end/server-side технологий вроде Node.js.
  • Опыт работы с RESTful API systems.
  • Сильный опыт cloud providers (AWS или GCP) и core services для compute, networking и managed databases.
  • Практический опыт containerization и orchestration (Docker, Kubernetes) для deployment и scaling game servers.
  • Сильный опыт non-relational databases, например MongoDB.
  • Опыт real-time multiplayer applications через Sockets/WebSocket.
  • Опыт Infrastructure as Code, например Terraform, будет плюсом.
  • Участие в релизе нескольких online-игр на Console, PC или Mobile.
  • Способность писать чистый, простой и хорошо документированный код по design requirements.
  • Подтверждённый опыт самостоятельной и командной работы в динамичной среде.
  • Сильный опыт source control, например GIT или Perforce.
  • Опыт Android/iOS mobile application development.
  • Опыт построения и поддержки CI/CD pipelines (например, GitHub Actions, GitLab CI, Jenkins).
  • Актуальное знание трендов mobile gaming.
  • Способность эффективно общаться с техническими и нетехническими коллегами.
  • Опыт Agile, Kanban или аналогичных project management methodologies.
  • Двуязычие (французский и английский) считается важным преимуществом.…
