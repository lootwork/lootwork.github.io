Кто мы

Мы — разнообразная команда разработчиков, объединённая любовью к своему делу и общими ценностями. Инклюзивная культура помогает нам создавать выдающиеся игры для игроков по всему миру. Мы стремимся к росту и инновациям в атмосфере безопасности и доверия и верим, что разнообразие взглядов делает сильнее и команду, и игры. Мы ищем нового коллегу, который поможет поднять нашу планку ещё выше.

Кого мы ищем

Нам нужен Lead UI Engineer, который будет задавать техническое направление UI для AAA multiplayer-проекта и руководить командой UI engineers. Вы будете проектировать гибкие, масштабируемые, доступные и производительные UI systems с современными UE5 frameworks — CommonUI, MVVM, Enhanced Input — и тесно работать с инженерами и кросс-дисциплинарными командами. Идеальный кандидат глубоко понимает все аспекты UI development: управление ресурсами без hitching, интеграцию с backend services с задержками, поддержку широкого набора display devices и высоких frame rates, требования консолей и live configuration.

Что вы будете делать

  • Творчески работать с Design и Production над новыми функциями, заранее определяя возможности, сложности и стоимость.
  • Руководить техническим проектированием и реализацией UI игры с использованием хорошо поддерживаемых best-in-class patterns и UE frameworks.
  • Поддерживать надёжные решения для asynchronous asset management и интеграции с backend services с задержками — inventory, matchmaking, live telemetry — сохраняя отзывчивый UX.
  • Управлять бюджетами производительности и памяти UI; при необходимости использовать GPU для конкурентной игры с высоким FPS.
  • Обеспечивать соответствие UI first-party certification requirements.
  • Создавать UI systems для глобального выпуска: dynamic text scaling, разные font sets, сложные string tables и right-to-left languages.
  • Реализовывать полный набор accessibility-функций для инклюзивного UX.
  • Архитектурно проектировать data-driven UI systems с server-side configuration: динамические layouts экранов, удалённая перестановка элементов управления, снижение friction и real-time promotions без client patches.
  • Наставлять UI engineers, проводить code reviews и развивать workflows для повышения эффективности UI/UX design team.

Что поможет вам отлично подойти

  • 7+ лет профессионального game programming и минимум два выпущенных AAA-проекта в Senior или Lead UI роли.
  • Глубокое техническое знание UI systems Unreal Engine: CommonUI, UMG, Slate и MVVM patterns.
  • Экспертный C++, особенно asynchronous data handling, memory management и взаимодействие C++/Blueprint.
  • Практический опыт решения UI-проблем console certification — TRC/TCR — на PlayStation и/или Xbox.
  • Практическое понимание Unreal material pipeline применительно к производительным UI materials и shaders.

Желательные квалификации

  • Live Ops / F2P: опыт live-service или Free-to-Play игр и хорошее понимание commerce UI, dynamic content delivery и player conversion funnels.
  • Action games: опыт multiplayer shooters, action RPG или competitive games.
