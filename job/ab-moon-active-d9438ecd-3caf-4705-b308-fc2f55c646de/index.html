Moon Active — одна из самых быстрорастущих mobile game companies мира, развлекающая миллионы активных пользователей. Штаб-квартира находится в центре Тель-Авива.

Мы ищем опытного и увлечённого Game Engineer, который сыграет ключевую роль в разработке игр следующего поколения. Вы будете глубоко вовлечены в формирование core gameplay experience, создание надёжной client architecture в Unity и end-to-end ownership features — от плавных клиентских взаимодействий до лёгкого масштабируемого backend development.

Обязанности

  • Проектировать, создавать и поддерживать высокопроизводительные, reusable и maintainable game features.
  • Вести features от первоначального technical design до production, отвечая как за client-side logic, так и за необходимые backend endpoints/services.
  • Оптимизировать и масштабировать client-side gameplay и backend systems для миллионов игроков, обеспечивая high-performance seamless experience по всему technical stack.
  • Реализовывать client и server logic с надёжными network protocols, state synchronization и data persistence, способными бесшовно масштабироваться.
  • Тесно работать с Product Managers, Game Designers и Artists, быстро итеративно развивая новые mechanics и features.

Требования

  • 4+ года опыта mobile game development и экспертиза Unity.
  • Сильное понимание Object-Oriented Programming, design patterns и data-driven development principles.
  • Практический опыт Client-Server systems: API, WebSockets, JSON/Protobuf и state synchronization.
  • Глубокое знание mobile optimization, performance profiling и memory management.
  • Опыт local/remote data persistence, unit testing и CI/CD pipelines.
  • Сильная product orientation, problem-solving skills и collaborative mindset.

Преимущества

  • Практический опыт написания backend code/services на Node.js, C#, Go или Serverless functions.
  • Опыт cloud platforms (AWS/GCP/Azure) и managed cloud services.
  • Опыт LiveOps frameworks, A/B testing и remote config pipelines.
