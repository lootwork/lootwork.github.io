В Rockstar Games мы создаём развлекательные продукты мирового уровня.

Станьте частью команды, работающей над одними из самых масштабных и вдохновляющих творческих проектов во всей индустрии развлечений — в инклюзивной, мотивированной среде, где можно учиться и сотрудничать с одними из самых талантливых специалистов отрасли.

Rockstar ищет увлечённого Senior Security Platform Engineer, который умеет глубоко разбираться в сложных архитектурах ПО и выявлять недостатки и уязвимости безопасности.

Это штатная позиция с полной занятостью и работой из офиса в штаб-квартире Rockstar в центре Манхэттена, Нью-Йорк.

ЧЕМ МЫ ЗАНИМАЕМСЯ

- Команда Application Security Rockstar Games сотрудничает с многочисленными командами разработки по всей компании, внедряя практики безопасности на протяжении всего жизненного цикла разработки ПО.

- Мы стремимся понимать ландшафт угроз, влияющих на наши студии разработки, игровую индустрию и мир в целом, чтобы определять стандарты и рекомендации безопасной разработки, защищать бизнес и наших игроков.

- Мы независимо оцениваем код и сборки приложений различными методами — static analysis, dynamic analysis, software composition analysis и др. — чтобы находить потенциальные уязвимости и архитектурные недостатки и совместно с командами разработки устранять их.

ОБЯЗАННОСТИ

- Проектировать и поддерживать операции secure software development lifecycle, встроенные в software development pipelines.

- Предоставлять технические security-рекомендации разработчикам, team leads и producers.

- Продвигать устранение уязвимостей, выявленных внутри компании и публично.

ТРЕБОВАНИЯ

- 5+ лет опыта в профессиональной, академической или исследовательской среде с выявлением и устранением security bugs/flaws при поддержке automated pipelines.

- Знание распространённых web security vulnerabilities, например OWASP Top 10, клиентского security landscape, техник атак и стратегий remediation.

- Опыт эффективного внедрения и настройки SAST, SCA, IaC и Secrets Detection tools, особенно тонкой настройки static analysis detections с custom rule engines, такими как CodeQL и Semgrep.

- Экспертиза развёртывания в CI/CD platforms, например TeamCity или GitHub Actions, и container orchestration frameworks, например Kubernetes, включая настройку соответствующих security controls.

- Опыт организации monitoring и observability для build pipelines и их результатов.

- Опыт работы как с Windows, так и с Linux.

- Уверенное владение C# и Python.

БУДЕТ ПЛЮСОМ

Обратите внимание: перечисленные ниже навыки желательны, но не обязательны для подачи заявки.

- Практический опыт создания или развёртывания security agents с использованием LangChain или LangGraph для автоматизации сложных многошаговых security-задач.

- Знакомство с Infrastructure as Code, например Terraform или Pulumi, для развёртывания безопасной архитектуры.

- Опыт внедрения security guardrails через Policy as Code engines, например OPA, в существующие и новые CI/CD workflows.

- Понимание C++ и соответствующих компиляторов.

- Опыт создания CI/CD controls для cloud-native pipelines и runtime environments.
