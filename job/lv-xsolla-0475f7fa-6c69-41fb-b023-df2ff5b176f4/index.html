Xsolla is a global commerce company with robust tools and services to help developers solve the inherent challenges of the video game industry. From indie to AAA, companies partner with Xsolla to help them fund, distribute, market, and monetize their games. Grounded in the belief in the future of video games, Xsolla is resolute in the mission to bring opportunities together, and continually make new resources available to creators. О роли

We are hiring a Senior Frontend Engineer for two platform products:

  • Xsolla ID is the identity and authentication platform behind sign-in, account management and SSO across Xsolla products.
  • Xsolla ZK is Web3 wallet infrastructure: smart wallets and account abstraction on a zkSync-based L2.

Both products sit on users' most sensitive flows: logging in and signing transactions.

Обязанности

WHAT YOU WILL OWN

  • The frontend of your product area end to end: shaping tasks with Product and Design, implementation, release and production monitoring
  • Technical decisions for that frontend. You make them and justify them in writing, rather than only implementing someone else's
  • The architecture of frontend applications and the shared UI library / SDK that other teams build on
  • Measurable frontend quality: performance, reliability and security of user flows

Что предстоит делать

  • Design and build user flows: sign-in, account management, wallet onboarding and transaction signing
  • Track how these flows behave in production (errors, performance, drop-offs) and act on what you see
  • Make architectural decisions for frontend applications and document them
  • Develop the shared component library and frontend SDKs used by other Xsolla teams
  • Agree API contracts with backend engineers, including error handling, retries and edge cases
  • Own performance budgets: Core Web Vitals and bundle size
  • Improve the engineering environment: build, linters, tests, CI
  • Review code
  • Set up and maintain AI tooling in the repositories (Claude Code, Codex, Cursor: rules, context, harness) so the team uses it effectively

Будет плюсом

Language and platform

  • 5+ years of commercial frontend development
  • TypeScript in strict mode: generics, utility types, discriminated unions, typing module boundaries and external data
  • JavaScript at the platform level: event loop, asynchrony, closures, memory. You can find a leak and explain its cause

Frameworks and state

  • Deep experience with React: rendering model, profiling, eliminating unnecessary re-renders
  • Separating local, server and global state, and justifying the choice of tool; reasoning about when SSR is worth it

UI quality and performance

  • Semantic, responsive, cross-browser layout; modern CSS (CSS Modules, CSS-in-JS)
  • Accessibility: ARIA, keyboard navigation, screen reader support
  • Performance analysis: profiling, bundle analysis, Core Web Vitals

Integration and security

  • REST API integration: error handling, retries, request cancellation, contract alignment with backend
  • Web security fundamentals: XSS, CSRF, CSP, secure handling of tokens, sessions and user data

Engineering practices

  • Testing at the right level: unit, integration, E2E
  • Git, CI, Docker, linters and formatters

AI-assisted engineering

  • Daily hands-on use of AI coding tools (Claude Code, Codex, Cursor) for development and review, including configuring them for a repository

English

  • Reading technical documentation in English
  • Experience in security-sensitive domains: authentication and identity (OAuth2/OIDC flows on the frontend), payments, crypto wallets
  • Web3 frontend: wallet integration (embedded and browser wallets), EIP-1193, EIP-6963, EIP-712; viem, wagmi, ethers.js
  • Next.js or Nuxt, SSR in production
  • Design systems and component API design, UI kits
  • Hybrid applications: WebView, React Native

HOW WE WORK

  • Decisions in writing. Significant technical decisions are written up as an RFC or ADR that lays out the options and trade-offs. We discuss the document, not a blank whiteboard.
  • AI is part of everyday engineering. We use AI coding tools for development and review, and we treat configuring them for a codebase as real engineering work.

HOW WE HIRE

  • Intro call. Your background, your motivation and the role.
  • Technical interview. Built directly on the What you will own and Required sections above. We won't ask about anything this posting doesn't promise.
  • Bar raiser. An engineer from outside the hiring team checks that you raise the overall engineering bar.
