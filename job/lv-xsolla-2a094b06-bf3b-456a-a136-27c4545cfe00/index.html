О ВАС

Мы ищем Senior Software Engineer (React Native) — архитектурно сильного, ориентированного на качество и командного специалиста — в Mobile Engineering team. Вам предстоит лидировать mobile architecture decisions, создавать масштабируемые cross-platform приложения и развивать shared-code стратегии между web и mobile.

Необходимы глубокие React Native и JavaScript/TypeScript, знание mobile architecture patterns и state management, а также опыт выпуска коммерческих mobile apps от concept до launch. Важны способность проектировать scalable architecture, строить надёжные testing strategies, включая E2E, оптимизировать performance и менторить других developers.

О КОМПАНИИ

Xsolla — глобальная commerce компания для игровой индустрии. Подробнее: xsolla.com.

ОБЯЗАННОСТИ

  • Разрабатывать и поддерживать React Native приложения для iOS и Android.
  • Внедрять best practices mobile development, code review, testing и CI/CD.
  • Создавать scalable и maintainable features в существующей architecture.
  • Вместе с product/design реализовывать technical solutions под business goals.
  • Интегрировать mini-apps и virtual currency systems с Xsolla App.
  • Работать с developers, QA и PM в cross-functional teams.
  • Участвовать в technical discussions и согласовывать development с business objectives.
  • Эффективно работать в распределённых командах.
  • Вовремя выпускать качественные features по всему lifecycle.

АРХИТЕКТУРА И ДИЗАЙН

  • Проектировать scalable React Native architecture с фокусом на maintainability, performance и developer experience.
  • Лидировать решения по shared code между React web и React Native mobile.
  • Устанавливать coding standards, design patterns и best practices.
  • Создавать technical specs и architecture documentation для сложных systems/features.

MONOREPO MANAGEMENT

  • Строить и поддерживать monorepo на Nx, Turborepo или аналогах.
  • Настраивать и оптимизировать build pipelines, dependency management и workspace configs.
  • Использовать efficient caching и incremental builds для CI/CD.
  • Управлять versioning, publishing и dependencies между packages.

COMPONENT ECOSYSTEM & CODE SHARING

  • Создавать shared component library для React и React Native.
  • Создавать platform-agnostic business logic, utilities и services для web/mobile.
  • Реализовывать adaptive components с platform-specific implementation при unified API.
  • Формировать patterns для shared types, hooks, contexts и state management.
  • Создавать tooling/documentation для лёгкого использования shared code.

DEVELOPMENT & DELIVERY

  • Создавать production-ready React Native apps для iOS/Android.
  • Реализовывать pixel-perfect responsive UI по design specifications.
  • Оптимизировать performance, bundle size и startup time.
  • Интегрировать native modules, когда React Native API недостаточно.

END-TO-END TESTING & QUALITY ASSURANCE

  • Проектировать comprehensive E2E strategies на Detox, Maestro или Appium.
  • Создавать надёжные maintainable test suites для iOS/Android.
  • Формировать reusable testing patterns/utilities между apps monorepo.
  • Настраивать E2E в CI/CD с корректным device/simulator management.
  • Строить test infrastructure для critical user flows, edge cases и platform-specific behavior.
  • Использовать visual regression и snapshot testing там, где это оправдано.
  • Определять стандарты unit, integration и E2E tests.

COLLABORATION & MENTORSHIP

  • Вместе с web developers искать возможности code sharing и architecture alignment.
  • Менторить junior/mid developers по React Native и monorepo patterns.
  • Проводить глубокие code reviews по architecture, patterns и maintainability.
  • Тесно работать с product, design и backend для цельного user experience.…
