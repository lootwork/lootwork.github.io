Senior Staff Cloud Network Security Engineer (AWS / GCP)

Madrid - Hybrid - 4 days on site, 1 day remote

About the role You’ll join Ebury’s Security Engineering team as the technical lead for network security across our multi-cloud infrastructure. In this role, you will set the architectural direction for how we secure our cloud environments, drive our transition to zero-trust networking, and pioneer how autonomous AI agents safely interact with internal and external networks.

What you’ll work on

  • Multi-Cloud Architecture: Define and own the network security strategy across our AWS and GCP environments, including IP address management (IPAM) and subnetting standards.
  • Connectivity & Edge Security: Secure inter-cloud, multi-account, partner, and internet connectivity, alongside our edge stack (CDN, DNS, load balancers, WAF, and DDoS protection).
  • Zero Trust Transformation: Lead the organization-wide shift from perimeter-based models to zero-trust, identity-based network access.
  • AI Agent Containment: Design and enforce network controls governing how AI agents—and the code they execute—access internal services and external APIs.
  • Workload & Container Security: Establish network controls for cloud, Kubernetes, and containerized workloads, focusing on micro-segmentation, egress filtering, and encryption in transit.
  • Infrastructure as Code (IaC): Author, review, and maintain the core Terraform networking and security modules used by engineering teams across Ebury.
  • Detection & Incident Response: Own network detection and response (NDR) capabilities and serve as the technical escalation lead during high-severity network security incidents.
  • Technical Leadership: Drive cross-team architectural decisions through clear design documents and mentor senior engineers across the organization.

What you’ll need

  • Experience: 12+ years in network, infrastructure, or security engineering, including at least 5 years designing and operating production public cloud environments.
  • Cloud Platforms: Deep hands-on expertise in AWS networking alongside strong experience in a second public cloud (GCP strongly preferred).
  • Core Networking: Mastery of IP networking fundamentals—TCP/IP, CIDR planning, routing, BGP, NAT, DNS, and TLS.
  • Hybrid & Multi-Cloud Connectivity: Proven experience designing hub-and-spoke/transit architectures, VPC peering, VPNs, and private endpoints.
  • Defensive Network Controls: Practical expertise in segmentation, next-gen firewalls, WAF, DDoS mitigation, strict egress filtering, and least-privilege access.
  • Zero Trust & Identity: Hands-on experience implementing zero-trust architectures and identity-based access controls (SSO, OIDC, mTLS, and workload identity).
  • AI & LLM Security: Solid understanding of AI agent and LLM threat vectors (such as prompt injection, tool misuse, and credential/data exfiltration) and how to mitigate them at the network layer.
  • Edge & Delivery: Experience managing CDNs, origin protection, TLS termination, and global load balancing.
  • Infrastructure as Code: Strong proficiency in Terraform (or equivalent IaC tools) for automating network and security infrastructure at scale.
  • Troubleshooting & Diagnostics: Ability to isolate complex latency, routing, and security issues using packet captures, VPC flow logs, and telemetry.
  • Influence & Communication: Track record of taking org-wide architectures from RFC to production, backed by strong written and verbal English communication skills.

Будет плюсом

  • Experience securing MCP servers, AI agent gateways, or isolated sandboxes for LLM-generated code.
  • Familiarity with commercial zero-trust network access (ZTNA) solutions.
  • Software engineering or automation skills in Python or Go.
  • Experience managing multi-account AWS Organizations and GCP Organization Policies.
  • Background in threat modeling and architecture security reviews for cloud and AI systems.
  • Experience operating within regulated environments (e.g., PCI DSS, ISO 27001, SOC 2) or high-volume fintech/payments platforms.
  • Relevant certifications, such as AWS Certified Advanced Networking, AWS Certified Security – Specialty, or GCP Professional Cloud Network Engineer.
