О роли

We are hiring a Tech Lead, Parental Controls. You will build the team and the service that checks a player's age and gets a parent's consent before a child can buy.

This is a coding role. You write production code at least half of your week, you make the architecture decisions, and you hire the engineers who build this with you.

Обязанности

Что предстоит делать

  • Write production Go and TypeScript: the status API, token validation, consent rules, the standalone widget and the web SDK
  • Own the architecture and write it down
  • Hire and grow a team of about six backend, frontend and QA engineers: write the role profiles, run the interviews, onboard each person
  • Set up how the team works: code review, CI, releases, on-call, AI coding tools in the repositories
  • Keep children's data safe: token validation, consent records, no decision from a result that only the browser reports
  • Work with Legal, Security teams on requirements, dependencies and release gates

WHAT YOU WILL WORK WITH

Go, go-kit, gRPC and REST, PostgreSQL, Redis, RabbitMQ, Temporal; TypeScript with Angular and React; OpenTelemetry and Datadog; Docker, Kubernetes, GitLab CI; a third-party age-verification and consent vendor.

Обязательно

  • 7+ years in software engineering, Go as your main language for the last 3+ years. You still write and ship code
  • 2+ years as a tech lead or team lead of 4+ engineers, with hiring experience: you have built a team or a large part of one
  • Backend depth: API design, PostgreSQL, message queues, idempotent integrations with third-party APIs, workflow orchestration (Temporal or similar)
  • TypeScript: enough to review React or Angular code and design a small embeddable web SDK
  • Security basics for identity flows: JWT, OAuth2, webhook signatures, XSS, CSRF, CSP
  • Operations: Docker, Kubernetes, CI/CD, tracing and metrics, on-call for a service you own
  • Daily use of AI coding tools (Claude Code, Codex, Cursor), including their setup for a repository
  • English at B2 or higher
