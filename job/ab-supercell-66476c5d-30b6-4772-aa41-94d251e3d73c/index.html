ЭТО ВАША ВОЗМОЖНОСТЬ РАБОТАТЬ НАД CLASH ROYALE В SUPERCELL — ОДНОЙ ИЗ САМЫХ ЛЮБИМЫХ МОБИЛЬНЫХ ИГР В МИРЕ — И ПРОДОЛЖАТЬ РАДОВАТЬ МИЛЛИОНЫ ИГРОКОВ КАЖДЫЙ ДЕНЬ.

Мы ищем опытного и увлечённого Senior UI Artist в команду Clash Royale.

Это hands-on art role, сосредоточенная на создании красивого polished UI art для постоянно развивающейся live game. Вы будете тесно работать с небольшой командой developers, UX designers и game designers, превращая features, events и game systems в ясные, приятные и высококачественные visual experiences.

Вы будете напрямую влиять на внешний вид и ощущения интерфейса игры, делая его более readable, beautiful, responsive и satisfying для игроков.

Мы ищем человека, которому комфортно в маленькой highly collaborative team. Нужно уметь работать самостоятельно, принимать сильные visual decisions, проактивно искать alignment с art direction игры и приносить идеи, двигающие player experience дальше.

ЧТО ВЫ БУДЕТЕ ДЕЛАТЬ

- Создавать high-quality UI screens, elements и assets для live mobile game.

- Создавать polished UI animations и motion treatments, делающие interface responsive, satisfying и живым.

- Тесно работать с Designers и превращать wireframes, flows и feature designs в visually polished production-ready UI.

- Сотрудничать с developers, обеспечивая правильную и эффективную implementation UI assets и animations в игре.

- Понимать и согласовывать работу с feature goals, player needs, community feedback и live game priorities.

- Поддерживать и развивать UI visual language игры, уважая существующее art direction и established game conventions.

- Проактивно искать feedback и alignment от relevant stakeholders: art direction, design, development, marketing и community.

- Улучшать quality, consistency, readability и polish существующего UI live game.

- Вносить идеи и feedback, улучшающие игровой опыт.

- Эффективно создавать assets и iterations в ответ на live-game needs, team feedback, player feedback и changing priorities.

- Помогать создавать и поддерживать reusable UI components, visual standards и production practices, ускоряющие и улучшающие будущую UI-работу.

ЧТО У ВАС ЕСТЬ

- Более 5 лет опыта UI Artist, Game Artist, 2D Artist или аналогичной роли в games.

- Сильное портфолио с отличным UI art, craft, visual polish, readability и attention to detail.

- Сильное понимание layout, composition, color, typography, visual hierarchy, iconography и readability.

- Опыт UI animations, transitions, interaction feedback или другого motion design для game interfaces.

- Уверенное владение Photoshop или аналогичными 2D art production tools.

- Опыт animation tools или готовность изучить Adobe Animate/Flash и другие tools UI production pipeline.

- Способность самостоятельно работать в маленькой team, организовывать собственную работу и двигать features без heavy process.

- Способность адаптироваться к существующему art direction и создавать UI, естественный для игры.

- Опыт работы с multiple stakeholders и driving alignment по visual quality и direction UI.

- Сильные collaboration и communication skills.

- Любовь к mobile games.

БУДЕТ ПЛЮСОМ, ЕСЛИ У ВАС ЕСТЬ

- Знакомство с live game environment.

- Знакомство с Clash Royale и любовь к игре.

- Опыт Adobe Animate/Flash.

- Опыт 3D software.

- Background Game Artist, Graphic Designer или Marketing Artist.

- Опыт LiveOps features, events, offers, shops, rewards или другого live-game UI.

- Опыт создания/поддержки UI style guides, component libraries или reusable asset systems.

- Опыт ответственного использования AI-assisted tools для повышения efficiency, iteration speed или production quality.

Supercell — игровая компания из Хельсинки, Финляндия, с офисами https://supr.cl/jd-offices также в Сан-Франциско, Сеуле, Шанхае и Лондоне.
