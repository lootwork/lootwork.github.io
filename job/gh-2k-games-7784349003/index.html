Кто мы

2K издаёт одни из самых популярных игровых франшиз в мире, включая Mafia, Borderlands, BioShock, NBA 2K, WWE 2K, Evolve, XCOM и Sid Meier’s Civilization.

Группа 2K Tech отвечает за выявление общих проблем компании и создание решений для них. В команду мы ищем людей, которым нравятся сложные задачи, быстрый темп и ответственность за продукты. Если вам интересна игровая индустрия и реализация классных функций для наших игровых продуктов — присоединяйтесь.

О роли

Мы ищем Staff Software Engineer, который станет главным техническим голосом семейства наших cross-platform и cross-language SDK. Наш tooling используется почти во всех играх 2K и обеспечивает first-class support для Unreal, Unity, native C++, Go, JavaScript и других технологий. Нам нужен специалист, который сможет видеть общую архитектурную картину между всеми этими вариантами.

Это individual contributor role без прямых подчинённых, но вы будете отвечать за технические решения в SDK и Cloud направлениях и тесно сотрудничать с engineering managers по вопросам направления, найма и роста команды. Примерно половину времени предполагается писать код, а вторую половину — задавать техническое направление: проводить design review, повышать планку качества и устранять блокеры для других engineers.

Главная задача с первого дня — обеспечить архитектурную согласованность между вариантами для разных языков и движков. SDK для Unreal, Unity, native C++, Go и JavaScript должны ощущаться как продукт одной команды и следовать одинаковым стандартам API design, versioning, performance и reliability.

Эта роль строится вокруг AI-first подхода. Вы будете использовать large language models и AI-powered tooling как важную часть ежедневной работы — для prototyping API designs, генерации cross-language bindings, подготовки RFC, исследования refactors и создания tooling, масштабирующего производительность команды. Мы ожидаем, что вы будете расширять границы возможного, встраивая AI во все аспекты senior engineering work.

Что предстоит делать

  • Принимать ключевые технические решения в направлениях SDK и Cloud в рамках курса, заданного Director, и совместно с командой. Отстаивать архитектурное направление того, как наши инструменты проектируются, разбиваются по слоям, версионируются и развиваются для Unreal, Unity, native C++, Go, JavaScript и других targets
  • Обеспечивать архитектурную согласованность между вариантами для разных языков и движков, чтобы каждая студия получала предсказуемый и целостный developer experience независимо от выбранного SDK или API
  • Оставаться hands-on: писать production code, первыми прототипировать самые сложные задачи, вести наиболее трудные реализации и регулярно участвовать в code review
  • Быть естественным collaborator, который ведёт через влияние, а не формальную власть: выстраивать доверие между командами, вовлекать людей в технические решения и усиливать окружающих engineers через эмпатию и ясную коммуникацию
  • Определять и поддерживать стандарты API design, documentation, backward compatibility, performance и reliability и делать эти стандарты понятными для всей команды
  • Ежедневно использовать LLM и AI-powered workflows для ускорения работы: prototyping дизайнов, генерация boilerplate для разных языков, исследование refactors, подготовка technical proposals и автоматизация повторяющихся инженерных задач
  • Создавать AI-assisted tooling, масштабируя вклад каждой команды: code generation pipelines, automated review assistants, intelligent search по поверхности платформы и другие инструменты, увеличивающие общий output
  • Сотрудничать с engineering managers по technical strategy, hiring и team growth, не беря на себя people management
  • Напрямую работать с studio engineering leads, понимать реальное использование наших tools в production и возвращать эти знания в roadmap
  • Наставлять engineers в команде, повышая технический потолок без превращения себя в bottleneck
  • Представлять команду SDK и Cloud verticals в cross-functional technical discussions внутри Technology group и студий

Что вы привнесёте

  • 10+ лет software engineering опыта, значительная часть которого связана с проектированием и выпуском SDK, libraries, tools и platform APIs, от которых зависят другие engineers
  • Уверенное владение C++ и как минимум одним из C# (Unity), Go или JavaScript/TypeScript, а также способность быстро осваивать остальные. Не требуется быть экспертом во всех языках, но нужно удерживать общую архитектурную картину между ними
  • Практический опыт с Unreal и/или Unity, включая интеграцию движков с внешними native libraries
  • Сильное понимание API design, versioning, deprecation и backward compatibility и опыт, показывающий, как избежать типичных ошибок в этих областях
  • Практический опыт использования LLM tools — Claude, ChatGPT, GitHub Copilot, Cursor или аналогов — как части ежедневного engineering workflow, не только для экспериментов, а с реальным ростом продуктивности и сформированным пониманием, где AI полезен, а где нет
  • Комфорт в роли технического decision-maker: способность иметь сильную позицию, защищать её фактами и менять её при изменении доказательств
  • Ясная и доброжелательная коммуникация: design docs, которые действительно читают, code review feedback, развивающий команду, и способность объяснять trade-offs неинженерам
  • Подтверждённый опыт эффективной работы между командами без формальных полномочий
