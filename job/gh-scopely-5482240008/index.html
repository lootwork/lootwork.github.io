Senior Game Security Engineer

Scopely is looking for a Senior Game Security Engineer to join the team developing an unannounced AAA cross-platform game remotely in the US or Hybrid in our Culver City office.

In this role, you will build and improve the security systems that protect our game and its players from cheating, tampering, automation, and other forms of abuse. You will work across prevention, detection, investigation, and response by developing client-side protections, analyzing real-world cheats, improving telemetry, and helping the development team design systems that are resilient against attack.

This is a senior individual-contributor position. You will own substantial technical features and investigations, influence security architecture, and mentor other engineers while remaining closely involved in implementation, testing, and live operations.

At Scopely, we care deeply about what we do and want to inspire play, every day—whether in our work environments alongside our talented colleagues or through our deep connections with our communities of players. We are a global team of game lovers developing, publishing, and innovating across the games industry, connecting millions of people around the world daily.

Что предстоит делать

  • Design, implement, test, and maintain client-side anti-cheat and game-security systems for Windows, console, and mobile platforms.
  • Develop high-performance, production-quality C and C++ code for security-sensitive game components, runtime protections, integrations, and supporting tools.
  • Analyze suspected cheats, exploits, automation tools, and malicious software using static analysis, dynamic analysis, debugging, and reverse-engineering techniques.
  • Translate cheat research into resilient detections, including signatures, integrity checks, heuristics, behavioral signals, and telemetry-based detection strategies.
  • Prototype and harden anti-tamper, anti-debugging, code-integrity, process-protection, and runtime-validation techniques.
  • Investigate attacks involving code injection, process tampering, API hooking, memory modification, DLL manipulation, automation, packet manipulation, and related techniques.
  • Help secure communication between game clients, security components, and backend services, including authentication, integrity protection, replay resistance, and safe failure behavior.
  • Build tools, scripts, test harnesses, and automated simulations that improve cheat research, detection validation, regression testing, and incident response.
  • Monitor security telemetry, detection pipelines, dashboards, and operational alerts.
  • Tune detections to improve coverage while minimizing false positives, unnecessary performance impact, and disruption to legitimate players.
  • Support the response to emerging cheats and security incidents by analyzing root causes, developing mitigations, validating hotfixes, and contributing to post-incident reviews.
  • Share knowledge and provide technical guidance to engineers, QA, data analysts, production teams, and other partners.

Кого мы ищем

  • Significant professional software-engineering experience, including experience working on security-sensitive, systems-level, or performance-critical software.
  • Demonstrated experience developing or operating anti-cheat, anti-tamper, anti-malware, endpoint-security, fraud-prevention, or comparable adversarial systems.
  • Strong C and C++ programming skills, including experience debugging complex native applications and reasoning about memory, concurrency, performance, and undefined behavior.
  • Practical knowledge of Windows internals, including processes, threads, virtual memory, modules, handles, access controls, executable formats, and inter-process communication.
  • Experience reading and analyzing x64 assembly.
  • Experience with reverse-engineering and debugging tools such as IDA Pro, Ghidra, Binary Ninja, WinDbg, x64dbg, Frida, or comparable tools.
  • Understanding of common cheating and tampering techniques, such as code injection, API hooking, manual mapping, DLL hijacking, memory editing, process manipulation, automation, spoofing, and network manipulation.
  • Understanding of secure-software-development principles, threat modeling, defensive programming, least privilege, cryptographic fundamentals, and secure client-server communication.
  • Experience designing security signals or detections and evaluating their effectiveness, reliability, operational cost, and false-positive risk.
  • Strong collaboration skills and experience working across engineering, QA, production, operations, data, legal, privacy, or player-support teams.
  • A player-focused approach to security that balances effective protection with privacy, accessibility, stability, and application performance.
