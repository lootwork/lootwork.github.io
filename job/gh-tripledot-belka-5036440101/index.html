О роли

We're hiring a Software Quality and Automation Engineer to own our automated testing setup for mobile games. You'll help support and work with QA, the game engineers and technical leadership to run and grow our physical device lab, an automated gameplay harness and the AI tools that support our testing.

We expect you to use AI coding agents, LLMs and vision models every day to build and maintain this tooling, and not to hand-write large suites of fragile UI scripts. A big part of the job is finding testing work the team currently does by hand, like performance checks, memory profiling and hardware compatibility runs, and automating it so it runs reliably without supervision.

No games background? That's fine. If you've built strong mobile test automation in another industry, such as e-commerce, fintech or consumer apps, we'd love to hear from you.

Основные обязанности

  • Set up and run our iOS and Android device lab. This covers automated build deployment, overnight runs, device health and thermal recovery, and coordinating tests across devices.
  • Build AI-assisted testing workflows. You'll use LLMs, vision models and agent harnesses to play through the game automatically, spot visual and UI problems, sort crash logs and write regression reports people can act on.
  • Automate performance, memory and compatibility profiling. That means collecting frame times, memory use, thermal state and GPU data across a wide range of devices, then comparing each result against that device's own baseline.
  • Write and extend the in-game automation hooks, debug bridges and telemetry exporters in Unity (C#), plus the host-side scripts that drive them. If you haven't worked in Unity before, we'll help you get up to speed.
  • Make it easy for QA analysts to start, review and extend automated tests. Work directly with developers to get reliable repro steps for crashes, OOMs and device-specific bugs before they ship.
  • Wire smoke, compatibility and performance regression tests into our build pipeline so every release candidate gets checked on our minimum-spec and legacy devices

Обязательные навыки и опыт

  • 4+ years of professional software engineering or technical QA automation experience, in mobile apps, games or device testing.
  • Real, day-to-day experience working with AI. You use coding agents (Claude Code, Cursor, Codex or your own setup) to prototype, refactor and debug quickly, and you've built LLM APIs, structured outputs or vision models into automation or triage pipelines.
  • Strong programming skills in at least one compiled language such as C#, Java, Kotlin or Swift, and the ability to read, extend and debug unfamiliar codebases.
  • Comfort with Python, TypeScript/Node.js and Bash for orchestration, data processing and reporting.
  • Hands-on experience with iOS and Android tooling: adb, xcrun/devicectl, iOS provisioning and signing, crash symbolication, and mobile profilers such as Perfetto, Xcode Instruments or Android Studio Profiler.
  • Experience automating tests on real mobile devices, not only emulators or simulators.
  • Experience with Git, CI/CD (GitHub Actions, Jenkins, TeamCity or similar), automated builds and storing test metrics.
  • A practical attitude. You care about catching bugs, crashes, OOMs and performance drops that users would actually hit, and you'd rather build something simple that keeps working than add process for its own sake.

Будет плюсом

  • Professional experience at a game studio or on a shipped game, ideally casual free-to-play mobile games.
  • Solid C# and Unity experience, or experience in another game engine plus the ability to read, extend and debug existing game and editor code.
  • Experience with game profiling tools such as the Unity Profiler and RenderDoc, and game performance metrics such as frame times and 1% lows.
  • Knowledge of Vulkan, OpenGL ES or Metal, shader compilation and PSO caching, and GPU and shader profiling.
  • Experience building automated gameplay bots, replay systems or harnesses that play through a game.
  • Experience building MCP servers, custom agent skills or bot frameworks for game testing.
