Что нам нужно

The Data Platform Engineer is responsible for designing and evolving the core architectural foundation of 2K’s data ecosystem. While Data Engineers build pipelines and DataOps Engineers manage reliability, the Data Platform Engineer focuses on building the underlying platforms—including Snowflake, Databricks, Kafka, and internal frameworks—that enable self-service data capabilities across the organization. this role ensures high-performance environment scalability for billions of global player events and creates seamless interoperability between complex data systems.

Что предстоит делать

  • Platform Architecture & Development: Lead the design, implementation, and optimization of core data platform components, including Snowflake, Databricks, and AWS S3 Data Lakes.
  • Streaming Infrastructure: Manage and scale high-throughput streaming systems using Kafka or Kinesis to support real-time game telemetry and low-latency analytics.
  • Self-Service Enablement: Develop "Data-as-a-Service" (DaaS) features that allow Business Units and Studios to onboard data and manage access with minimal friction.
  • Distributed Systems Optimization: Optimize Spark and PySpark applications for performance and cost-efficiency across large-scale distributed clusters.
  • Security & RBAC Architecture: Design and automate granular access control models to ensure data security and compliance with global regulations (e.g., GDPR, CCPA).
  • Interoperability & Standards: Ensure seamless data flow and interoperability between disparate platforms (utilizing technologies like Apache Iceberg) to maintain a Single Source of Truth (SSOT).
  • Technical Leadership: Serve as a subject matter expert for the data platform, translating complex business needs into scalable technical requirements and platform features.

Кто нам подойдёт

  • Architectural Depth: Demonstrates a deep understanding of how platform components interact and scale within a global data ecosystem.
  • Innovation & Efficiency: Drives the adoption of new technologies and methodologies to improve platform performance and reduce operational overhead.
  • Problem Solving: Resolves complex, high-impact technical issues related to distributed systems and data availability.
  • Collaboration: Partners effectively with Data Scientists, Data Engineers, and Studio Leads to provide a high-quality developer experience.
  • Strategic Thinking: Anticipates future platform needs and aligns architectural decisions with long-term business goals.

Обязательные требования и навыки

  • Education: Bachelor’s or Master’s degree in Computer Science, Engineering, or a related technical field.
  • Experience: 6+ years of professional experience in data platform or distributed systems engineering in high-volume environments.
  • Core Technical Stack: Mastery of SQL and Python; expert knowledge of big data processing frameworks like Spark.
  • Cloud Ecosystem: Deep proficiency in AWS services (S3, EKS, IAM, SNS/SQS) and extensive experience with Snowflake or Databricks.
  • Orchestration: Experience building or extending workflow orchestration platforms like Apache Airflow.
  • Architecture Mindset: Strong understanding of data modeling methodologies (Kimball, Inmon, Data Vault) and how they apply to modern cloud data platforms.

Будет плюсом

  • Experience handling high-velocity telemetry from massive live-service ecosystems (e.g., gaming or high-volume consumer tech).
  • Experience with Infrastructure as Code (Terraform) for provisioning data stacks.
  • Knowledge of data observability and cataloging tools (e.g., Monte Carlo, DataHub, or Soda).
  • Experience with containerization (Docker, Kubernetes) in a data platform context.
  • AI Infrastructure: Experience building and scaling Vector Databases (e.g., Pinecone, Weaviate, or Milvus) to support Retrieval-Augmented Generation (RAG).
  • Interoperability: Knowledge of the Model Context Protocol (MCP) to enable secure, standardized data sharing between 2K’s data repositories and LLM applications.
  • LLM Data Tooling: Familiarity with data preparation and governance for fine-tuning Large Language Models.
