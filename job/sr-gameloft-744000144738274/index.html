Главная задача

Эта роль подходит тем, кто хочет изучить основы game design и полный game development process. Вы получите базовые навыки и знания, а затем примените их в реальных design-задачах live-проектов, одновременно развивая карьеру.

Что это означает в ежедневной работе

- Изучать fundamentals game design и анализировать разные аспекты игр — design concepts, controls, fun factors — в разных жанрах

- Изучать процесс создания игры на live-проекте и помогать основному Game Designer с небольшими задачами

- Участвовать в design discussions и принятии решений

- Писать и поддерживать game design documents для небольших функций, простого gameplay и улучшений существующих features и content — missions, quests, levels — под руководством project game designer

- Учиться находить и исправлять design-related bugs с помощью внутренних tools

- Участвовать в playtests builds вместе с командой

С кем вы будете работать

- Studio Game Designer Lead, Senior Game Designers и Game Designer Project Leads

- Producers, Artists и Programmers

- Кросс-функциональные game development teams
