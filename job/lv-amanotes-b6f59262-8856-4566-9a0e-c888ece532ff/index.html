Мы нанимаем Android Developer!

Присоединяйтесь к Uplive в нашей миссии сделать мир музыкальнее. Мы ищем талантливого Android Developer, который превратит смелые product ideas в отполированные и производительные native mobile experiences.

В этой роли вы глубоко погрузитесь в современную Android architecture, будете создавать бесшовные user interfaces и помогать расширять возможности mobile audio processing. Если вы любите clean code, сложные технические задачи и хотите создавать apps, которыми пользуются миллионы любителей музыки по всему миру, мы хотим видеть вас в команде.

ЧТО ПРЕДСТОИТ ДЕЛАТЬ

  • Feature Development: создавать и оптимизировать features для масштабных music applications в соответствии с product priorities и Agile/Scrum
  • Architecture & Clean Code: участвовать в technical brainstorming, проектировать robust technical solutions и проводить code review для высокого code quality и scalability
  • R&D & Innovation: исследовать и прототипировать emerging Android technologies и audio frameworks под меняющиеся product requirements
  • Collaboration & Mentorship: активно работать в cross-functional Scrum teams, помогая engineers с logic solutions и technical hurdles
  • DevOps & Tooling: эффективно управлять workflow с помощью Git, JIRA и современных CI/CD pipelines
  • Production Ownership: отвечать за app stability, отлаживать сложные issues и обеспечивать high availability для глобальной аудитории

КВАЛИФИКАЦИИ

Ключевые technical requirements

  • Experience: 2+ года профессиональной Android-разработки
  • Language Proficiency: уверенное владение Kotlin, включая idiomatic style, Coroutines, Flow и Kotlin Serialization
  • Modern UI: production-опыт Jetpack Compose, State Hoisting и Material Design 3
  • Architecture: глубокое понимание Clean Architecture — Data/Domain/Presentation layers — и MVVM с StateFlow, sealed class state machines и repository pattern
  • Jetpack Ecosystem: уверенное владение Jetpack Navigation, Room и DataStore
  • Dependency Injection: опыт Hilt или Dagger
  • Networking & Backend: опыт интеграции REST APIs через Ktor или Retrofit
  • Testing: знакомство с unit testing — JUnit, MockK — и базовыми UI tests
  • Cloud & Ads: уверенный опыт Firebase — Analytics, Crashlytics, Remote Config — и AdMob SDK
  • Next-Gen Workflow: уверенное ежедневное использование AI Coding Agents, например Claude Code или GitHub Copilot, для ускорения разработки

Дополнительные преимущества

  • Опыт Media3 / ExoPlayer и core audio processing
  • Знакомство с GLSL shaders и advanced graphics rendering
  • Знание background processing через WorkManager
  • Опыт Supabase или Ktor backend environments
  • Опыт optimization через ProGuard/R8 и KSP (Kotlin Symbol Processing)
  • Hands-on опыт Ad Mediation platforms — AppLovin MAX, Meta, ironSource

Soft Skills & Mindset

  • Product Mindset: вы не просто выполняете specs, а думаете о user experience и понимаете «зачем» нужна функция
  • Problem Solving: сильная логика, troubleshooting и проактивность в устранении blockers
  • Ownership: самостоятельный подход к time management, дисциплине и delivery проекта
  • Passion: искренняя любовь к mobile apps и музыке
