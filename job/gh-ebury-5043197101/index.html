Senior Security Engineer

Office León, Spain - Hybrid: 4 days in the office, 1 day working from home

О роли

Ebury is investing heavily in product security across its global financial services. Security engineering is a technical, hands-on team that works with software and platform engineers to build security into what they ship.

We don't own security policies, internal audit or other GRC work, IT security (such as anti-malware) or security operations, including incident response.

We work on engineering problems: vulnerability management, AI threat modelling, SSDLC, DRP, infrastructure hardening and other security engineering projects.

We are seeking a Senior Security Engineer to build security into our product development lifecycle. You'll work directly with engineering teams to identify and mitigate security risks through threat modeling, secure code reviews, and integrated security tooling across our web and mobile applications.

Key responsibilities

Secure development lifecycle (SDLC) implementation

  • Design and implement secure software development practices.
  • Integrate security gates into CI/CD pipelines following DevSecOps principles.
  • Develop custom security linters and pre-commit hooks.
  • Develop secure coding standards based on OWASP guidelines, and security architecture patterns and reference implementations.
  • Review AI-generated code and add CI checks for it.
  • Build security dashboards and metrics reporting.

Security code reviews and testing

  • Conduct in-depth security code reviews for critical features, including cryptographic, authentication and authorization implementations.
  • Implement automated security testing (SAST, DAST, IAST, SCA) and secrets scanning, and configure and tune the scanning tools.
  • Add supply chain checks for dependencies, models, MCP servers and pipelines.
  • Ensure compliance with OWASP ASVS (Application Security Verification Standard).

Threat modeling and risk assessment

  • Lead threat modeling sessions using STRIDE, PASTA, or similar frameworks, and create threat models for new products and architectural changes.
  • Threat model LLM and agent features (prompt injection, tool misuse, excessive agency, MCP).
  • Review implemented business logic for non-technical flaws.
  • Identify attack vectors specific to web and mobile platforms, and develop abuse cases and security test scenarios.
  • Maintain threat intelligence for fintech-specific risks.
  • Document security requirements derived from threat models.

Platform-specific security

  • Guide the implementation of defenses against OWASP Top 10 vulnerabilities in web applications, OWASP MASVS and platform-specific guidelines in mobile applications, and API security best practices (rate limiting, authentication, input validation).
  • Guide cross-platform session management and secure data storage.

Required qualifications

Technical expertise

  • 5+ years of application security experience.
  • Programming skills in at least one language, preferably Python or Golang.
  • Strong understanding of security vulnerabilities across web and mobile platforms
  • Hands-on experience with security testing tools and methodologies, including static and dynamic analysis tools.
  • Strong knowledge of secure coding practices, design patterns, and secure architecture patterns and anti-patterns.
  • Knowledge of modern mobile development frameworks (preferably React Native).

Security domain knowledge

  • Knowledge of OWASP standards (Top 10, ASVS, SAMM, MASVS, LLM Top 10, Agentic Top 10).
  • Understanding of cryptographic principles and secure implementations.
  • Experience with threat modeling methodologies.
  • Knowledge of authentication standards (OAuth2, OIDC, WebAuthn).
  • Familiarity with PCI-DSS, PSD2, DORA, and Strong Customer Authentication requirements.
  • Understanding of cloud-native security patterns.
  • Understanding of security risks in LLM and agent-based features.

Code review and analysis skills

  • Ability to identify security vulnerabilities through manual code review, and understanding of common vulnerability patterns across languages.
  • Ability to provide actionable remediation guidance.

Professional requirements

  • Experience in financial services or high-security environments.
  • Strong communication skills to explain security risks to developers.
  • Ability to balance security requirements with development velocity.
  • Collaborative approach to working with engineering teams.
  • Technical writing skills for documentation and guidelines.

Будет плюсом

  • Experience with payment systems and transaction security.
  • Knowledge of mobile app protection.
  • Experience building security champions programs.
  • Background in penetration testing or security research.
  • Relevant certifications (security, cloud, etc.).
